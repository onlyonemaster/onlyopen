문제 — 후보자마다 2~3시간 수동 설정

원챗에 새 후보자가 들어올 때마다 관리자가 직접 모든 걸 설정해야 했습니다

⚡ 기존 방식의 고통

  • 후보자 정보(경력·공약·이슈)를 일일이 검색하고 정리
  • 4계층 프롬프트(L1~L4)를 손으로 직접 작성 — 한 세트당 30~40분
  • RAG 학습 데이터(뉴스·SNS·홈페이지)를 수동으로 수집·업로드
  • 챗봇별 설정(Gn_aievent_ms_info + Gn_onechat_settings) DB 레코드 수동 생성
  • 후보자 10명이면? → 30시간 순수 노동. 선거 기간엔 불가능

해결책 — AI 비서 3인방 투입!

관리자는 후보자 이름만 입력하고 버튼 하나만 누르면 끝납니다. 나머지는 AI가 알아서.

01 🌐
AI 비서 1호
웹 조사관 (Web Researcher)

후보자 이름을 받으면 인터넷을 샅샅이 뒤집니다. 뉴스 기사, SNS 피드, 공식 홈페이지, 선관위 공보까지 — 사람이 2시간 걸릴 일을 30초 만에 해치웁니다.

02 ✍️
AI 비서 2호
프롬프트 작가 (Prompt Writer)

수집된 정보를 바탕으로 4계층 프롬프트를 자동 작성합니다. L1(페르소나), L2(정책), L3(상호작용), L4(안전장치)까지 — 사람이 40분 걸리던 작업을 1분 만에 완료합니다.

03 💉
데이터 주입기 (Data Injector)

완성된 프롬프트와 학습 데이터를 RAG 서버에 자동 주입합니다. DB 레코드(Gn_aievent_ms_info, Gn_onechat_settings)도 자동 생성. 아바타 학습까지 일괄 처리합니다.

전체 처리 흐름 — 초등학생도 이해하는 알고리즘

서버 안에서 실제로 어떤 순서로 돌아가는지 단계별로 설명합니다

①

관리자가 폼에 후보자 이름 입력 → [자동 생성] 버튼 클릭

예: "민형배" 입력 → POST 요청이 api/scenario/create.php 로 전송됩니다. DeepSeek API 키를 이용해 AI 호출을 시작합니다.

POST /api/scenario/create.php Body: { "title": "민형배 통합특별시장 후보", "sms_idx": 3365 }
②

AI 비서 1호 작동 → 인터넷 조사 개시

검색 대상: 뉴스(네이버·다음), SNS(페이스북·인스타그램), 공식 홈페이지, 선관위 공보, 국회의원 이력

수집 정보: 학력·경력·주요 공약·소속 정당·지역구·최근 이슈·유권자 반응

// lib/scenario_prompt_builder.php → buildStep1Prompt() // DeepSeek API 호출로 웹 검색 + 요약 $deepseek->generate_manual([ 'system' => '당신은 정치인 정보 수집 전문가입니다...', 'content' => "후보자 '민형배'에 대한 모든 공개 정보를 수집해주세요." ]);
③

AI 비서 2호 작동 → 4계층 프롬프트 자동 생성

수집된 정보를 4계층 구조로 정리하여 DB에 저장

// ai_generate.php → _build_system_prompt() // 4계층 자동 생성 결과: L1 (페르소나): "당신은 전남·광주 통합특별시장 후보 민형배입니다. 30년 정치 경력, 더불어민주당 소속, 전남·광주 상생 발전이 핵심 가치..." L2 (정책): "핵심 공약 — ① 행정통합 3단계 로드맵 ② 특별시 위상 확보 ③ 광역 교통망 확충 ④ 균형발전기금 5천억 조성..." L3 (상호작용): "말투 — 친근하고 따뜻한 구어체 유권자 이름 호칭, 지역 맞춤형 응답, 이모지 활용..." L4 (안전장치): "비방·욕설 감지 시 정중하게 차단 허위사실 유포 방지, 개인정보 보호, 선거법 준수..."
④

AI 비서 3호 작동 → DB 저장 + RAG 학습 + 완료

생성된 모든 데이터를 실제 DB 테이블에 기록하고, RAG 서버에 학습 데이터를 주입합니다.

// 3개의 DB 테이블에 자동 기록: INSERT INTO Gn_aievent_ms_info -- 챗봇 마스터 정보 (sms_idx, customer_id, chatbot_name, chatbot_prompt, ...) INSERT INTO Gn_onechat_settings -- 요청별 상세 설정 (sms_idx, request_idx, prompt_l1_persona, prompt_l2_policy, ...) INSERT INTO Gn_scenario -- 시나리오 마스터 (title, campaign_goal, target_audience, ...) // RAG 서버에 학습 데이터 주입 POST /api/learn.php Body: { sms_idx, documents: [뉴스기사, SNS, 공약집...] }
✅

결과: 5분 만에 완성!

기존에는 관리자가 2~3시간 걸려서 하던 설정 작업이, 이제는 폼 하나 입력 → 버튼 클릭 → 5분 대기로 끝납니다. 모든 DB 레코드가 자동 생성되고, 프롬프트가 완성되며, RAG 학습까지 완료된 상태로 챗봇이 준비됩니다.

🖥️ 어느 메뉴로 들어가나요?

  1. 원챗 로그인 — https://onechat.kiam.kr 접속 후 로그인
  2. 왼쪽 메뉴에서 "시나리오" (또는 "AI 시나리오") 탭 클릭
  3. 상단 "+ 새 시나리오" 버튼 클릭
  4. 팝업에 후보자 이름 입력 (예: "민형배")
  5. 캠페인 목표(예: "통합특별시장 선거") 선택적으로 입력
  6. "AI 자동 생성" 버튼 클릭!

⚙️ 버튼 누르면 무슨 일이?

  1. AI가 인터넷에서 후보자 정보를 자동 수집 (30초~1분)
  2. 수집된 정보로 4계층 프롬프트 자동 작성 (1~2분)
  3. 채널별 메시지(카카오·SMS·인스타)도 자동 생성
  4. 생성된 내용을 미리보기로 확인
  5. 마음에 들면 "저장" → "활성화" 버튼 클릭
  6. 끝! 이제 챗봇이 유권자와 대화 시작합니다 🎉

소스코드로 보는 실제 작동 원리

서버에서 실제로 돌아가는 PHP 파일들과 데이터 흐름

📁 파일 #1 — 시나리오 생성 진입점

api/scenario/create.php
// 관리자가 [AI 자동 생성] 버튼을 누르면 이 파일이 실행됩니다
$input = json_decode(file_get_contents('php://input'), true);
$title   = trim($input['title']);   // "민형배 통합특별시장 후보"
$sms_idx = (int)($input['sms_idx']); // 챗봇 ID

// 1. DB에 시나리오 레코드 생성 (status='draft')
INSERT INTO Gn_scenario (title, customer_id, campaign_goal, ...)
VALUES ('민형배 통합특별시장 후보', ...);

// 2. 생성된 scenario_id 반환 → 프론트엔드가 이어서 AI 호출

📁 파일 #2 — AI 메시지 생성 엔진

api/scenario/ai_generate.php
// 이 파일이 핵심 — DeepSeek API를 호출하여 모든 메시지를 생성합니다
$sys_prompt = _build_system_prompt($step, $sc, $context, ...);

// STEP 1: 카카오+SMS 메시지 생성 (max_tokens=2048)
$deepseek = new DeepSeekAPI();
$res1 = $deepseek->generate_manual([
  'system'  => $sys_prompt,
  'content' => "위 지침에 따라 JSON만 출력하세요."
]);

// 인스타 DM은 별도 호출 (max_tokens=8192, 더 긴 메시지)
$insta_sys = _build_insta_prompt(...);
$res2 = $deepseek->generate_manual([
  'system' => $insta_sys,
  'content' => "인스타 DM 메시지를 2200자로 작성해주세요."
]);

// 결과를 JSON으로 파싱 → 프론트엔드에 반환
$response_data = _normalize_response($step, $parsed, ...);

📁 파일 #3 — 시나리오 활성화 (챗봇에 적용)

api/scenario/activate.php
// 관리자가 "활성화" 버튼을 누르면 실행
// 1. 기존 active 시나리오 → paused 처리
UPDATE Gn_scenario SET status='paused' WHERE status='active';

// 2. 챗봇 프롬프트 업데이트
UPDATE Gn_aievent_ms_info
SET chatbot_prompt = '{시나리오에서 생성한 전체 프롬프트}'
WHERE sms_idx = $sms_idx;

// 3. 시나리오 상태 → active
UPDATE Gn_scenario SET status='active', activated_at=NOW();

🗄️ 관련 DB 테이블

Gn_aievent_ms_info — 챗봇 마스터 (이름·프롬프트)
Gn_onechat_settings — 요청별 상세 (L1~L4 프롬프트)
Gn_scenario — 시나리오 마스터 (캠페인 정보)
Gn_scenario_step — 단계별 데이터 (JSON)
Gn_scenario_revision — 버전 관리 (모든 변경 기록)

🤖 사용 AI 모델

DeepSeek Chat (deepseek-chat)

• max_tokens 8192: 인스타 DM 긴 메시지
• STEP 2~5: max_tokens 4096
• 총 소요시간: 약 3~5분 (API 호출 2~3회)
