# 원챗(ONE Chat) 시스템 설명 페이지 — 설계도 v2

---

## 🎯 설계 의도

**목적**: 후보자에게 "원챗 시스템이 내 고통을 어떻게 해결하는가"를 **한 편의 스토리처럼** 보여주는 시스템 설명 자료.
(※ 이 자료는 동기부여성 피치덱과 함께 제시하는 **시스템 설명 자료**입니다.)

**형식**:
- 세로 스크롤 단일 페이지 (길이 제한 없음)
- **왼쪽 컬럼 (40%)**: 절차 번호 + 설명 텍스트
- **오른쪽 컬럼 (60%)**: 실제 챗봇 UI 미리보기 — 각 Phase마다 **동적 애니메이션** 적용

**핵심 원칙**: "기능 나열"이 아니라 "한 명의 후보가 시스템을 세팅하고, 유권자가 반응하는 전 과정"을 시간 순서대로 따라간다.

---

## 🎬 Phase별 동적 챗봇 이미지/애니메이션 기획

각 Phase의 오른쪽 컬럼 챗봇 UI는 **정적 이미지가 아니라 살아있는 미리보기**로 동작한다.

| Phase | 챗봇 이미지 상태 | 애니메이션 효과 |
|-------|-----------------|----------------|
| **Phase 0 (준비)** | 🤖 기본 아바타 (중립 표정) | 타이핑 인디케이터 점멸, 말풍선이 순차적으로 나타나는 fade-in |
| **Phase 1 (배포)** | 📱 QR코드 + 링크가 챗봇 화면 위에 overlay | QR코드가 반짝이는 glow 효과, 링크 복사 애니메이션 |
| **Phase 2 (유권자 경험)** | 👤 활성화된 챗봇 (웃는 표정) | 실시간 타이핑 효과, 말풍선 슬라이드인, "입력 중..." dot 애니메이션, 메시지 자동 스크롤 |
| **Phase 3 (분석)** | 📊 대시보드 전환 | 차트 grow-up 애니메이션, 숫자 카운트업, 데이터 바 차오르는 효과 |
| **Phase 4 (팬덤)** | 💜 영구 연결된 아바타 | 하트 floating 애니메이션, 팬 카운트 증가하는 숫자, 관계 지속도 게이지 차오르기 |

### 애니메이션 구현 방식
- **CSS `@keyframes`** + `IntersectionObserver`로 뷰포트 진입 시 트리거
- **타이핑 효과**: JavaScript로 한 글자씩 출력 (50~80ms 간격)
- **말풍선 appear**: `transform: translateY(20px)` → `translateY(0)` + `opacity: 0→1`
- **차트 애니메이션**: SVG/CSS 기반 bar-chart grow

## 🔢 각 STEP별 상세 설계

---

### PHASE 0 — 준비 (후보 측 설정)

> **오른쪽 챗봇 UI 애니메이션**: 🤖 기본 아바타 상태. 말풍선이 순차적으로 fade-in 되며, 타이핑 인디케이터(...)가 점멸한다.

---

### STEP 1 — 계정 생성 & 챗봇 만들기

| 구분 | 내용 |
|------|------|
| **왼쪽 설명** | • "MY 챗봇 만들기" 버튼 한 번이면 끝<br>• 앱 설치 없이 웹에서 바로 생성<br>• 챗봇 이름은 자동 생성 (예: "민형배 후보 챗봇")<br>• 1분 만에 완성되는 첫걸음 |
| **오른쪽 미리보기** | 챗봇 생성 완료 화면 — ✅ 체크 아이콘 + "민형배 후보 챗봇이 생성되었습니다!" 토스트 메시지가 위에서 slide-down 되는 애니메이션 + 하단에 "채팅 시작하기" 버튼이 pulse 효과 |

### STEP 2 — 아바타 학습 (후보 정보 주입)

| 구분 | 내용 |
|------|------|
| **왼쪽 설명** | • 후보의 프로필·경력·공약·정책을 AI에게 학습<br>• 텍스트 복붙 or 파일 업로드로 간편 입력<br>• AI가 자동으로 핵심 키워드를 추출하고 학습<br>• 정보가 많을수록 AI 답변의 품질이 올라감 |
| **오른쪽 미리보기** | 학습 데이터 입력 폼 (textarea에 텍스트가 하나씩 채워지는 타이핑 효과) → "학습 완료! 🎉 15개 정책 키워드 추출됨" 토스트 |

### STEP 3 — 시스템 프롬프트 / 응답 스타일 설정 (4-Layer)

| 구분 | 내용 |
|------|------|
| **왼쪽 설명** | • **L1 페르소나**: 챗봇 이름, 말투, 페르소나 정의<br>• **L2 정책**: 정책 설명 방식, 핵심 공약 강조<br>• **L3 인터랙션**: 유권자 응대 패턴, 질문 유도 방식<br>• **L4 안전**: 민감 질문 대응, 선거법 컴플라이언스<br>• 한 번 설정하면 선거 기간 내내 일관된 응대 |
| **오른쪽 미리보기** | 챗봇 설정 패널 — 4개 탭(L1~L4)이 순차적으로 활성화되며 각 입력 필드에 텍스트가 채워지는 애니메이션 |

### STEP 4 — 시나리오(퍼널) 설계

| 구분 | 내용 |
|------|------|
| **왼쪽 설명** | • 몇 회에 걸쳐 어떤 메시지를 보낼지 설계<br>• 회차별 주제 설정: 첫인사 → 정책 소개 → 공감 → 지지 호소<br>• 발송 주기와 시간대 자동화 (AI가 최적 시간 분석)<br>• 퍼널 끝까지 오는 유권자 = 확실한 지지층 |
| **오른쪽 미리보기** | 시나리오 카드 리스트 — "1회차: 첫인사 🤝", "2회차: 교육정책 📚", "3회차: 지역현안 🏙️" 등이 카드 flip 애니메이션으로 순서대로 나타남 |

---

### PHASE 1 — 배포

> **오른쪽 챗봇 UI 애니메이션**: 📱 챗봇 화면 위에 QR코드가 overlay 되고, 반짝이는 glow 효과. 링크 복사 버튼이 ripple 효과.

---

### STEP 5 — 🔟가지 창의적 유권자 유입 전략

**개념**: QR코드와 공유 링크를 단순히 "뿌리는" 것이 아니라, 유권자가 **궁금해서 스스로 클릭하게 만드는** 전략 설계.

오른쪽 미리보기에는 각 전략별로 **실제 적용 예시 미리보기**(QR코드 디자인 시안, 링크 배치 예시, 채팅창 랜딩 화면)가 슬라이드 쇼로 순환된다.

---

#### 🥇 1순위 전략 — "궁금하면 찍어보세요" 현수막·전단지 QR

| 항목 | 설명 |
|------|------|
| **방식** | 후보 정보를 전부 적지 않고 핵심 질문 하나와 QR코드만 배치 |
| **예시** | "교육감이 뭘 하는 사람인지 아세요? → QR 찍고 30초 대화" |
| **기대 효과** | 호기심 유발 → 클릭률 3~5배 상승. 정보 과잉 시대에 '비움'이 전략 |
| **미리보기** | 전단지 시안 — "이 후보, 당신 동네 위해 뭐할까? 🤔" + QR코드 |

#### 🥈 2순위 전략 — SNS 숏폼 영상의 "댓글 대신 채팅"

| 항목 | 설명 |
|------|------|
| **방식** | 유튜브 쇼츠·인스타 릴스·틱톡 영상 말미에 "더 궁금하면 여기서 대화해요" + 링크 |
| **예시** | 30초 정책 숏폼 → "이 영상 30초로 부족하시죠? AI 아바타와 1:1 대화하세요" |
| **기대 효과** | 숏폼 시청자(1,000~10,000뷰) 중 5~10% 채팅 전환 |
| **미리보기** | 숏폼 마지막 프레임 — 말풍선 + "지금 대화하기" 버튼 |

#### 🥉 3순위 전략 — 문자·카톡 선거운동의 "말벗 링크" 전환

| 항목 | 설명 |
|------|------|
| **방식** | 전통적 문자 홍보에서 "이야기 들어보실래요?"로 링크 유도 |
| **예시** | "안녕하세요 OOO후보입니다. 공약 궁금하시면 여기서 편하게 물어보세요: onechat.kr/xxx" |
| **기대 효과** | 기존 문자비의 1/10 비용으로 10배 긴 소통. 클릭 시 5분간 평균 체류 |
| **미리보기** | 카톡 메시지 예시 — 친근한 말투 + 원챗 링크 프리뷰 |

#### 4순위 전략 — 유세 현장 "실시간 Q&A 월"

| 항목 | 설명 |
|------|------|
| **방식** | 유세 차량·부스에 대형 QR코드 월 설치. "지금 바로 질문하세요" |
| **예시** | "말로 다 못한 이야기, AI 아바타가 설명해드립니다. 여기 QR 찍어보세요!" |
| **기대 효과** | 오프라인 유세 참석자 → 온라인 팬덤 전환율 20%+ |
| **미리보기** | 유세 부스 이미지 — 대형 QR 배너 + "실시간 Q&A" |

#### 5순위 전략 — "당신의 궁금증 TOP 10" 바이럴 카드뉴스

| 항목 | 설명 |
|------|------|
| **방식** | 유권자가 가장 많이 물어본 질문 TOP 10을 카드뉴스로 제작, 각 질문에 QR/링크 |
| **예시** | 인스타그램 10장 슬라이드 — "1위: 교육 예산 얼마나 늘어나나요?" → 답변은 채팅에서 |
| **기대 효과** | 바이럴 최적화 포맷. 공유율 높고, 클릭 후 바로 1:1 대화 연결 |
| **미리보기** | 카드뉴스 시안 — 질문 텍스트 + "AI에게 직접 물어보세요" 버튼 |

#### 6순위 전략 — 동네 카페·식당 테이블 스티커

| 항목 | 설명 |
|------|------|

| **기대 효과** | 일상적 공간에서 자연스러운 접촉. 젊은 층 도달률 특히 높음 |
