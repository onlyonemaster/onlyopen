이 데모는 로컬 시뮬레이션 모드입니다 — 모든 데이터는 사용자 기기 안에만 저장됩니다.

🗺️ 추천 동선 (5분 투어)

① 📥 라이프 인박스 — 데모로 미리 들어와 있는 5건의 신호를 확인하고, ⭐ 고정·🎯 의사결정 카드로 변환·🗑 삭제를 눌러보세요.
② 🎯 의사결정 어시스턴트 — 질문 → 선택지 2개 → 예측 → 한 장 카드 → 결정 → 회고. 한 사이클 돌려보세요. 매칭률 KPI가 자라는 게 핵심.
③ 🧠 매일의 나 — 30일 히트맵 + 오늘 요약 만들기 + 수정 모달.
④ 🛡️ 위험 신호 워치독 — "지금 점검" 버튼으로 신호 발생 시뮬레이션, 룰 토글.
⑤ 💸 API 사용량 가드 — 월 캡 설정 + "데모 $0.50 추가" 버튼으로 미터·임계치 알림 체험.
⑥ 🪪 디지털 유산 — 신뢰 1인 정보·전달 범위·마지막 메시지 → 묶음 미리보기.
⑦ 📱 폰 자동 동기화 — 소스별 정책, 취침 시간, Daily Self-Sync 옵션.
⑧ 🎓 통합 학습 (learn-v2) — 14 채널 × 5 입력 방식. 📱 폰 데이터 자동채움 모달.
⑨ 💾 저장소·BYO API 키 — 서버/온디바이스/하이브리드, 4 제공자 키 마스킹.

💡 시뮬레이션 모드란?

이 데모는 백엔드 DB 없이 localStorage로만 동작합니다.
• 데이터는 사장님 브라우저에만 저장됩니다 (서버에 안 갑니다)
• 새로고침해도 유지됩니다
• 다 봤으면 아래 전체 초기화로 깨끗하게 지울 수 있습니다
• API 호출은 모두 폴백 처리되어 UX는 정상 동작합니다
