🧠 아바타 학습시키기 0 chunks

후보자의 연설문, 정책자료, SNS, 뉴스, 유튜브 등 모든 데이터를 RAG(Retrieval-Augmented Generation) 기반으로 학습시켜 AI 아바타가 근거 있는 답변을 하도록 합니다.

📔 캠프 일일 브리핑 / 대화 기록

매일의 캠프 활동, 주요 미팅, 유권자 대화 내용을 기록합니다. 템플릿을 선택하면 더 빠르게 작성할 수 있습니다.

템플릿:

📝 대용량 텍스트 직접 입력

연설문, 인터뷰 녹취록, 정책 제안서 등을 직접 텍스트로 입력합니다. 최대 10만자까지 지원하며 마크다운 문법을 사용할 수 있습니다.

🎙️ 음성 녹음 → STT 자동 변환

연설·인터뷰·토론회 음성을 녹음하거나 업로드하면 Whisper STT 엔진이 자동으로 텍스트로 변환하여 RAG 학습합니다.

또는

📁 파일 업로드 (PDF·DOCX·PPTX·XLSX·TXT·ZIP)

정책백서, 보도자료, 보고서 등 각종 문서 파일을 업로드합니다. 최대 500MB/파일, ZIP 일괄 업로드를 지원합니다.

📂

파일을 여기에 드래그하거나 클릭하여 업로드

지원: PDF, DOCX, PPTX, XLSX, TXT, CSV, ZIP

🌐 URL 크롤링 — 뉴스·블로그·웹사이트

후보자 관련 뉴스 기사, 블로그 포스트, 공식 웹사이트 URL을 입력하면 자동으로 텍스트를 추출하여 RAG 학습합니다.

📺 YouTube 동영상 — 자막 추출 → 학습

후보자의 공식 채널 영상, 토론회, 인터뷰 영상 URL을 입력하면 자동으로 자막을 추출하여 RAG 학습합니다.

💬 SNS 계정 연동 — 자동 포스트 수집
