Panic Lock — 안전망 설계

  • 긴급 차단 1초: 빨간 버튼 한 번 누르면 모든 외부 공개 데이터가 즉시 비공개로 전환됩니다. 외부 아바타가 즉시 그 데이터를 못 쓰게 됩니다.
  • 복원 가능: 차단 이력이 남고, 복원 버튼으로 이전 상태로 한 번에 되돌릴 수 있습니다.
  • 필터: 전체 / 나만 / 외부공개 / 태그별로 빠르게 필터링. 카테고리 일괄 변경 가능.
  • 변경 이력: 누가(본인) 언제 어떤 데이터의 공개 범위를 바꿨는지 모두 로그로 남습니다.
  • 적용 대상 파일: 신규 페이지 aimessage/onechat/me_scope.html + API /api/me/data/{id}/scope
