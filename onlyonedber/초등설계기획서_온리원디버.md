## 1. 개요 및 목적

### 1.1 프로젝트 개요

**온리원디버(OnlyoneDBer)**는 네이버의 다양한 서비스(블로그, 카페, 지도, 쇼핑, 웹사이트, 포스트, 뉴스, 동영상)에서
휴대폰 번호(010)와 이메일 주소를 자동으로 수집하는 Windows Forms 기반의 데이터 수집 도구이다.

개발자 김지광이 2021년 2월부터 개발하였으며, 온리원연구소(obmms.net)에서 서비스하는 상용 솔루션이다.

### 1.2 시스템 구성

전체 시스템은 두 개의 실행 파일로 구성된다:

| 구성요소 | 파일명 | 역할 |
|---------|--------|------|
| **온리원디버 업데이터** | `onlyonedber.exe` | 자동 업데이트, ChromeDriver 관리, 메인 프로그램 실행 |
| **온리원 메인 프로그램** | `온리원.exe` | 실제 네이버 데이터 수집(크롤링) 수행 |

### 1.3 분석 대상 소스

| 디렉토리 | 설명 | 상태 |
|---------|------|------|
| `decompiled/210531크롬버전업/` | 2021년 5월 31일 크롬 버전업 대응 버전, 원본 디컴파일 소스 | **핵심 소스** - 풀 소스코드 |
| `decompiled/source_recovered/` | onlyonedber.exe에서 ILSpy로 복구한 업데이터 소스 | 빌드 가능하나 부분적 (95.2%) |

### 1.4 설계 목표

1. 두 소스 디렉토리의 모든 중요 파일을 통합 분석
2. 다이버 매뉴얼에서 요구하는 모든 기능을 완전히 구현
3. .NET 8.0 / .NET Framework 4.6.2 이상에서 빌드 및 실행 가능한 솔루션 제공
4. 상용 라이선스 관리, 광고 시스템, 자동 업데이트를 포함한 완전한 제품 구현
