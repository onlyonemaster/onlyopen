4-Layer 시스템 프롬프트
응답 스타일 설정

  • L1 페르소나: 챗봇의 이름·말투·역할 정의. 통합특별시장 후보에 어울리는 전문성과 진정성.
  • L2 정책: 핵심 공약을 AI가 항상 인지. 행정통합 로드맵, 균형발전 전략 등.
  • L3 인터랙션: 유권자 응대 방식 설계. 공감 → 구체적 사례 → 추가 질문 유도.
  • L4 안전: 민감 질문 대응 원칙, 선거법 컴플라이언스, 개인정보 보호.

유권자 첫 접속 &
3회 대화 → 팬 등록

  • QR 스캔 또는 링크 클릭 → 앱 설치 없이 1초 안에 채팅창 열림. 회원가입·로그인 없음.
  • AI 정책 도우미가 즉시 첫인사 + 핵심 비전 전달. 첫 30초 안에 유권자 마음 사로잡기.
  • 핵심 알고리즘: 3회 대화 시 저장 다이얼로그 팝업 → 수락하면 영구 팬 등록.
  • 등록된 팬에게는 이후 시나리오 메시지, Hi공지, AI동행이 모두 자동 적용됩니다.
⚡ 3회 대화 = 팬 전환 트리거

시스템 알고리즘상, 유권자가 3번째 메시지를 보내는 순간 "대화를 저장하시겠습니까?" 다이얼로그가 표시됩니다. 수락 시 영구 팬으로 등록되어 지속적 소통이 가능해집니다.

STEP 07 / 13

AI 동행 —
먼저 말을 거는 챗봇

  • 대화가 멈추면 AI가 먼저 말을 건넵니다. 유권자가 기억하지 않아도, 챗봇이 기억합니다.
  • 시스템 알고리즘: 마지막 대화 후 설정된 시간 경과 → 맥락 기반 자동 메시지 생성 & 발송.
  • 이전 대화 내용을 분석해 맥락에 맞는 새 정보를 전달 — 스팸이 아닌 가치 있는 소식.
  • 알림은 푸시로 전달되어 열람률 90% 이상. 문자 이탈률 80%+와 비교 불가.
🔄 Push가 아닌 Pull 소통

전통 선거운동의 일방적 발송(Push)이 아닌, 관계를 유지하는 Pull 방식. 유권자는 "아, 챗봇이 또 연락 왔네. 읽어볼까?"라는 긍정적 감정을 갖게 됩니다.

STEP 08 / 13

관리자 Hi 공지 —
전체 팬 일괄 발송

  • 관리자 페이지에서 단 한 번의 클릭으로 전체 팬에게 공지 일괄 발송.
  • 문자비 0원, 열람률 90%+. 기존 문자보다 열람 가능성 9배.
  • 활용: 공식 발표, TV토론회 안내, 위기 대응 반박자료, 투표 당일 독려.
  • 시뮬레이션: 관리자가 작성 → 전체 팬의 채팅창에 실시간 도착.
📢 위기 대응 3분 컷

허위정보가 퍼질 때, 기자회견+보도자료는 최소 하루. 원챗 Hi공지는 3분 안에 모든 팬에게 반박 자료를 전송합니다.
