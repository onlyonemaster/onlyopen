📢 연동 시스템 & AI 공지 변환

소스 개선 항목을 AI 공지로 변환하는 시스템과 버전 관리(vermanager)와의 연동 구조를 분석합니다.

공지 변환 링크

목록 테이블의 액션 컬럼에서 notice_id가 NULL인 항목에만 공지 버튼이 표시됩니다:

<?php if (!$row['notice_id']): ?>
  <a href="notice_ai-write.php?source_id=<?php echo $row['id']; ?>"
     class="btn-sm btn-notice">공지</a>
<?php endif; ?>

이미 공지로 변환된 항목(notice_id가 존재하는 경우)은 공지 버튼이 사라집니다.

액션 버튼 로직

버튼링크색상조건
보기admin_source_improvements_form.php?id=N&action=view청록항상 표시
수정admin_source_improvements_form.php?id=N&action=edit노랑항상 표시
공지notice_ai-write.php?source_id=N초록notice_id == NULL

버전 관리 시스템과의 연동

vermanager에서 릴리즈를 실행할 때, 연결된 소스 개선 항목(linked_improvements)이 CHANGELOG에 기록됩니다. 또한 auto_register_*.php 스크립트가 이 테이블에 직접 INSERT합니다.

vermanager → source_improvements 연동 경로
─────────────────────────────────────────
1. [관리자] admin_source_improvements.php 에서 등록
2. [vermanager] improvements 페이지에서 개선 항목 확인
3. [vermanager] release 페이지에서 릴리즈 실행
   └── linked_improvements: ["imp_4", "imp_5"]
4. [vermanager] CHANGELOG에 포함 내역 자동 기록
5. [관리자] 공지 버튼으로 AI 공지 변환 (선택)

상태 생명주기

개발중 → 작업 시작 (기본 상태)   ↓
테스트중 → QA 검증 단계   ↓
완료 → 구현 완료, 배포 대기   ↓
배포됨 → 실제 서버에 반영됨 ✅

⚠️ 롤백 → 문제 발생 시 이전 상태로 복귀
💡 핵심 포인트: 소스 개선 관리 시스템은 단독으로도 완전하지만, 버전 관리 시스템(vermanager)과 연동하면 릴리즈 → CHANGELOG → 공지까지의 완전한 DevOps 파이프라인이 구축됩니다.
