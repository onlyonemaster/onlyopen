✏️ 수정 & 보기 모드

동일한 admin_source_improvements_form.php에서 edit/view 모드로 동작하는 방식과 보기 전용(readonly) UI의 차이를 분석합니다.

데이터 로드

// edit / view 모드 공통
$id = intval($_GET['id']);
$sql = "SELECT * FROM source_improvements WHERE id = {$id}";
$result = mysqli_query($self_con, $sql);
$data = mysqli_fetch_array($result);

if (!$data) {
    echo '<script>alert("존재하지 않는 항목입니다.");history.back();</script>';
    exit;
}

보기 전용 vs 편집 가능

$_GET['action'] 값에 따라 폼 요소의 readonly/disabled 속성이 동적으로 설정됩니다:

구분action=viewaction=edit
inputreadonly편집 가능
selectdisabled선택 가능
textareareadonly편집 가능
제출 버튼숨김표시
목록으로 버튼표시표시

UPDATE SQL

UPDATE source_improvements SET
    date = '{$date}',
    project = '{$project}',
    category = '{$category}',
    title = '{$title}',
    description = '{$description}',
    developer = '{$developer}',
    files_changed = {$files_changed},
    lines_added = {$lines_added},
    lines_deleted = {$lines_deleted},
    status = '{$status}',
    test_result = '{$test_result}',
    environments = '{$environments}',
    impact_level = '{$impact_level}',
    updated_at = NOW()
WHERE id = {$id}

UI 흐름

[목록 페이지] → "보기" 버튼 클릭
    │  href="admin_source_improvements_form.php?id=N&action=view"
    ▼
[보기 모드] → 모든 필드 readOnly · 저장버튼 없음
    │  "수정" 버튼 클릭 (또는 목록에서 "수정" 직접)
    ▼
[수정 모드] → 기존 값 pre-filled · 편집 가능 · 저장 시 UPDATE
    │  "목록으로" 버튼
    ▼
[목록 페이지] → 변경사항 즉시 반영
💡 핵심 포인트: view/edit은 동일한 PHP 파일에서 action=view일 때만 readonly/disabled를 적용해 구분합니다. action=edit이거나 action 파라미터가 없으면 편집 가능 상태로 렌더링됩니다.
