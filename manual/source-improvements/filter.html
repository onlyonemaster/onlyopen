🔍 필터 & 검색 시스템

4가지 차원(날짜범위, 프로젝트, 상태, 키워드)으로 소스 개선 항목을 필터링하는 시스템의 쿼리 빌딩 로직을 분석합니다.

필터 변수 초기화

$filter_date_from = isset($_GET['date_from']) ? $_GET['date_from']
    : date('Y-m-d', strtotime('-30 days'));   ← 기본: 30일 전
$filter_date_to = isset($_GET['date_to']) ? $_GET['date_to']
    : date('Y-m-d');                           ← 기본: 오늘
$filter_project = isset($_GET['project']) ? $_GET['project'] : '';    ← 기본: 전체
$filter_status  = isset($_GET['status'])  ? $_GET['status']  : '';    ← 기본: 전체
$filter_search  = isset($_GET['search'])  ? trim($_GET['search']) : ''; ← 기본: 없음

WHERE 조건 빌더

필터 값이 있으면 동적으로 WHERE 절을 조립합니다:

$where = "WHERE 1=1";  ← 항상 참인 기본 조건

if ($filter_date_from) $where .= " AND date >= '{$filter_date_from}'";
if ($filter_date_to)   $where .= " AND date <= '{$filter_date_to}'";
if ($filter_project)   $where .= " AND project = '{$filter_project}'";
if ($filter_status)    $where .= " AND status = '{$filter_status}'";
if ($filter_search)    $where .= " AND (title LIKE '%{$filter_search}%'
                                    OR description LIKE '%{$filter_search}%')";

1=1로 시작하는 이유: 모든 필터가 비어 있을 때도 SQL 문법 오류 없이 WHERE 1=1만 남아 전체 데이터가 조회됩니다.

$per_page = 20;                          ← 한 페이지당 20건
$offset   = ($page - 1) * $per_page;     ← OFFSET 계산

// 전체 건수
$count_sql = "SELECT COUNT(*) as cnt FROM source_improvements {$where}";

페이지 링크 상태 유지

모든 페이지네이션 링크에는 현재 필터 상태가 쿼리스트링으로 포함됩니다:

href="?page=N
     &date_from=
     &date_to=
     &project=
     &status=
     &search="

이렇게 하면 페이지를 이동해도 필터 조건이 그대로 유지됩니다.

페이지 범위: 현재 페이지 ±2

for ($i = max(1, $page - 2); $i <= min($total_pages, $page + 2); $i++):
    // 현재 페이지 → <span class="active">
    // 다른 페이지  → <a href="...">
endfor;
💡 핵심 포인트: 필터 상태는 GET 파라미터로 유지되므로 URL을 복사해 공유하면 동일한 필터 화면을 볼 수 있습니다. 검색어의 경우 urlencode()로 URL-safe 하게 인코딩됩니다.
