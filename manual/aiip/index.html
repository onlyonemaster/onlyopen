AI변리사 매뉴얼

ps.kiam.kr — AI가 특허·상표·저작권 컨설팅을 도와드리는 서비스입니다.
이 매뉴얼은 서비스의 모든 기능을 단계별로 안내합니다.

ps.kiam.kr 바로가기 →

서비스 개요

AI변리사는 ps.kiam.kr에서 제공하는 지식재산권(IP) 전문 AI 컨설팅 서비스입니다. 특허 출원, 상표 등록, 저작권 보호 등 복잡한 지식재산권 분야를 AI가 분석하고 전략을 제시합니다.

⚡
빠른 분석

자료 업로드 후 수 분 내에 AI 분석 결과를 받아볼 수 있습니다. 특허청(KIPRIS) 데이터와 실시간 연동되어 최신 선행기술 문헌을 분석합니다.

📄
문서 자동 생성

분석 결과를 바탕으로 특허 전략서, 출원서 초안 등 문서를 생성합니다.

🎯
맞춤 요청

AI 요청사항 도우미로 전문적인 컨설팅 요청을 쉽게 작성할 수 있습니다.

🔒
안전한 보관

의뢰 기록과 생성 문서는 대시보드에서 언제든 다시 열람 가능합니다.

빠른 시작

  1. 회원가입 → 로그인 — ps.kiam.kr에서 회원 가입 후 로그인
  2. 요금제 선택 — 무료 체험 또는 유료 구독으로 분석 크레딧 확보
  3. 자료 업로드 — 특허·상표 관련 자료 파일 첨부 또는 텍스트 직접 입력
  4. 요청사항 작성 — 원하는 분석 방향을 입력 (AI 도우미 활용 가능)
        * 생성 모드 선택 가능: Single (빠른 요약) / Split (상세 분할 생성)
        * 생성 모드 선택 가능: Single (빠른 요약) / Split (상세 분할 생성)
  5. 결과 확인 — AI 분석 리포트와 생성 문서 다운로드
