📥 생성 문서 다운로드

AI 분석 후 자동 생성된 전략서·출원서 초안 등 문서를 다운로드하는 방법을 안내합니다.

생성되는 문서 종류

분석 완료 후 분석 유형과 요금제에 따라 아래와 같은 문서가 자동 생성됩니다.

분석 유형생성 문서제공 플랜
⚖️ 특허 특허 전략 보고서 (PDF) 스탠다드 이상
청구항 초안 (DOCX) 스탠다드 이상
선행기술 분석표 (PDF) 프로
🏷️ 상표 상표 등록 가능성 보고서 (PDF) 스탠다드 이상
유사 상표 비교표 (PDF) 프로
©️ 저작권 저작권 보호 범위 보고서 (PDF) 스탠다드 이상
침해 위험 분석 보고서 (PDF) 프로
💡 무료 플랜에서는 분석 요약 텍스트만 제공되며, 문서 파일 다운로드는 스탠다드 이상 플랜에서 이용 가능합니다.

다운로드 방법

분석 결과 페이지에서 다운로드

  1. 분석 완료 후 결과 화면 하단의 "생성 문서" 섹션을 찾습니다.
  2. 생성된 문서 목록이 표시됩니다.
  3. 원하는 문서의 📥 다운로드 버튼을 클릭합니다.
  4. 파일이 로컬 컴퓨터에 저장됩니다.

의뢰 목록에서 다운로드

  1. 의뢰 목록(/result) 페이지로 이동합니다.
  2. 다운로드할 의뢰를 찾아 클릭합니다.
  3. 상세 페이지 하단의 생성 문서 섹션에서 다운로드합니다.

문서 미리보기

다운로드 전 문서 내용을 먼저 확인하려면 파일명을 클릭합니다. 브라우저 내에서 PDF 미리보기가 열리거나, 텍스트 기반 문서는 모달 창으로 표시됩니다.

문서 보관 기간

플랜문서 보관 기간만료 후
무료(Free)7일자동 삭제
스탠다드(Standard)90일자동 삭제
프로(Pro)무제한구독 해지 시까지 보관
⚠️ 중요한 문서는 즉시 다운로드하여 로컬에 보관하세요. 보관 기간이 만료되면 서버에서 영구 삭제되며 복구할 수 없습니다.

다운로드 문제 해결

상황원인조치

문서가 보이지 않음보관 기간 만료기간 내 재의뢰 필요
