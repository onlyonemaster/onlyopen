⚙️ 내 계정 설정

마이페이지(/mypage)에서 계정 정보 수정, 비밀번호 변경, 구독 관리 방법을 안내합니다.

마이페이지 접속

로그인 후 상단 내비게이션의 사용자 이름을 클릭하면 드롭다운 메뉴가 나타납니다. "마이페이지"를 선택하거나, ps.kiam.kr/mypage로 직접 접속합니다.

프로필 정보 수정

마이페이지의 "프로필 정보" 섹션에서 계정 정보를 수정할 수 있습니다.

항목수정 가능 여부비고
이름✅ 가능언제든지 변경 가능
이메일❌ 불가로그인 ID로 사용되므로 변경 불가
  1. 이름 입력 필드에서 새로운 이름을 입력합니다.
  2. "저장" 버튼을 클릭합니다.
  3. "프로필이 업데이트되었습니다" 메시지가 표시되면 완료입니다.

비밀번호 변경

마이페이지의 "비밀번호 변경" 섹션에서 변경합니다.

  1. 현재 비밀번호를 입력합니다.
  2. 새 비밀번호를 입력합니다. (8자 이상, 영문+숫자 조합 권장)
  3. 새 비밀번호 확인을 동일하게 입력합니다.
  4. "비밀번호 변경" 버튼을 클릭합니다.
  5. "비밀번호가 변경되었습니다" 메시지가 표시되면 완료입니다.

구독 관리

마이페이지의 "구독 관리" 섹션에서 현재 플랜 정보와 구독 해지를 관리합니다.

구독 해지

구독을 해지하려면 "구독 해지" 버튼을 클릭합니다. 해지 확인 모달이 나타나면 내용을 확인 후 "해지 확인"을 클릭합니다.

⚠️ 구독 해지 시 주의사항
- 해지 후에도 현재 구독 기간 만료일까지는 플랜 혜택이 유지됩니다.
- 만료일 이후에는 자동으로 무료 플랜으로 전환됩니다.
- 무료 플랜에서는 문서 보관 기간이 7일로 단축됩니다.

계정 탈퇴

마이페이지 하단의 "계정 탈퇴" 버튼을 통해 계정을 삭제할 수 있습니다. 탈퇴 시 모든 의뢰 내역, 생성 문서, 계정 정보가 영구 삭제됩니다.

⚠️ 계정 탈퇴는 되돌릴 수 없습니다. 탈퇴 전 필요한 문서를 모두 다운로드하세요.
