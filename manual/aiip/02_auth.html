👤 회원가입 & 로그인

ps.kiam.kr 계정을 만들고 로그인하는 방법을 안내합니다.

회원가입

ps.kiam.kr/register에 접속하거나, 홈 화면의 "시작하기" 버튼을 클릭하면 회원가입 페이지로 이동합니다.

입력 항목

항목설명필수 여부
이름서비스 내에서 표시될 이름필수
이메일로그인 ID로 사용되는 이메일 주소필수
비밀번호8자 이상, 영문+숫자 조합 권장필수
비밀번호 확인위 비밀번호와 동일하게 입력필수

가입 절차

  1. 이름, 이메일, 비밀번호를 입력합니다.
  2. "회원가입" 버튼을 클릭합니다.
  3. 가입이 완료되면 자동으로 로그인 상태가 됩니다.
  4. 이미 가입된 이메일이라면 "이미 사용 중인 이메일입니다" 메시지가 표시됩니다.
💡 이메일 중복 확인 — 이미 가입된 이메일로 회원가입을 시도하면 안내 메시지가 표시됩니다. 이 경우 로그인 페이지로 이동하세요.

로그인

ps.kiam.kr/login에 접속하거나, 상단 내비게이션의 "로그인" 버튼을 클릭합니다.

로그인 방법

  1. 가입 시 사용한 이메일을 입력합니다.
  2. 비밀번호를 입력합니다.
  3. "로그인" 버튼을 클릭합니다.
  4. 로그인 성공 시 대시보드 또는 이전에 머물던 페이지로 이동합니다.

로그인 오류 유형

오류 메시지원인해결 방법
이메일 또는 비밀번호가 일치하지 않습니다잘못된 이메일 또는 비밀번호입력 정보 재확인
존재하지 않는 계정입니다해당 이메일로 가입된 계정 없음회원가입 진행

로그인 유지 & 로그아웃

로그인 상태는 브라우저 세션 기간 동안 유지됩니다. 로그아웃하려면 상단 내비게이션의 사용자 이름 클릭 → "로그아웃"을 선택합니다.

💡 보안 팁 — 공용 컴퓨터에서 사용한 경우 반드시 로그아웃하세요. 브라우저를 닫아도 세션이 유지될 수 있습니다.

비밀번호 변경

비밀번호를 변경하려면 로그인 후 마이페이지(/mypage)로 이동합니다. 자세한 방법은 10장 내 계정 설정을 참고하세요.
