📋 대시보드

로그인 후 대시보드(/dashboard)에서 전체 컨설팅 현황을 한눈에 확인하는 방법을 안내합니다.

대시보드 접속

로그인 후 상단 내비게이션의 "대시보드"를 클릭하거나, ps.kiam.kr/dashboard로 접속합니다.

대시보드 구성

대시보드는 다음 섹션으로 구성됩니다.

① 통계 카드

상단에 주요 수치를 요약한 카드가 배치됩니다.

카드표시 내용
📊 총 의뢰 수지금까지 제출한 AI 컨설팅 의뢰 총 건수
✅ 완료된 의뢰분석이 완료된 의뢰 건수
⏳ 진행 중현재 AI가 분석 중인 의뢰 건수
💳 남은 크레딧현재 플랜에서 사용 가능한 남은 분석 횟수

② 최근 의뢰 목록

가장 최근에 제출한 의뢰 5~10건이 간략하게 표시됩니다.

표시 항목설명
의뢰 번호각 의뢰의 고유 번호
분석 유형특허 / 상표 / 저작권
의뢰 일시의뢰를 제출한 날짜와 시간
상태분석 중 / 완료 / 실패
바로가기해당 의뢰의 상세 결과 페이지로 이동

③ 구독 정보

현재 이용 중인 플랜과 만료일, 남은 크레딧 정보를 확인할 수 있습니다.

항목설명
현재 플랜Free / Standard / Pro
구독 만료일현재 구독 기간의 만료 날짜
사용 크레딧이번 달 사용한 분석 횟수
플랜 업그레이드요금제 페이지로 이동하는 버튼

빠른 작업

대시보드에서 아래 작업을 빠르게 실행할 수 있습니다.

버튼/링크동작
🔍 새 컨설팅 의뢰컨설팅 의뢰 페이지(/diagnosis)로 이동
📜 전체 의뢰 보기의뢰 목록 페이지(/result)로 이동
⚙️ 계정 설정마이페이지(/mypage)로 이동
💡 크레딧 부족 시 대시보드에 경고 알림이 표시됩니다. 플랜 업그레이드 링크를 클릭하여 더 많은 크레딧을 사용하세요.
