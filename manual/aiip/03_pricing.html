💳 요금제 & 결제

💳 토스페이먼츠 연동 안내:
이제 모든 결제는 토스페이먼츠(TossPayments) 실시간 결제 위젯을 통해 안전하고 빠르게 진행됩니다. 신용카드, 간편결제(토스페이 등), 계좌이체를 모두 지원합니다.

AI변리사 서비스의 요금제 종류와 결제 진행 방법을 안내합니다.

안내: 모든 결제는 토스페이먼츠(TossPayments) 실시간 결제 위젯을 통해 빠르고 안전하게 진행됩니다.

구독 신청 방법

  1. 로그인 후 요금제 페이지로 이동합니다.
  2. 원하는 플랜의 "구독하기" 버튼을 클릭합니다.
  3. 결제 페이지(/payment)로 이동합니다.
  4. 결제 정보를 확인한 후 "결제하기" 버튼을 클릭합니다.
  5. 카드 정보를 입력하고 결제를 완료합니다.
  6. 결제 완료 후 즉시 해당 플랜이 적용됩니다.

결제 수단

현재 지원하는 결제 수단은 다음과 같습니다.

결제 수단설명
💳 신용카드 / 체크카드국내외 주요 카드사 모두 지원 (토스페이먼츠 연동)

결제 흐름

결제는 토스페이먼츠를 통해 안전하게 처리됩니다.

  1. 요금제 선택 → "구독하기" 클릭
  2. 결제 페이지에서 플랜 정보 확인
  3. "결제하기" 클릭 → 토스페이먼츠 결제창 팝업
  4. 카드 번호, 유효기간, CVC 입력 후 결제 승인
  5. 결제 완료 → 구독이 즉시 활성화됩니다

결제 실패 & 오류

상황원인조치
결제창이 열리지 않음팝업 차단 또는 브라우저 호환 문제팝업 허용 후 다시 시도 / 다른 브라우저 사용
카드 결제 실패한도 초과, 카드 정보 오류카드사 확인 후 다른 카드로 시도
결제 완료 후 플랜 미적용네트워크 오류로 처리 지연마이페이지에서 구독 상태 확인, 5분 후 재확인

구독 해지

구독을 해지하려면 마이페이지(/mypage)의 "구독 관리" 섹션에서 해지할 수 있습니다. 해지 후 현재 구독 기간 만료일까지는 해당 플랜 혜택을 계속 이용할 수 있습니다.

⚠️ 구독 해지 시 주의사항
- 해지 후 남은 분석 크레딧은 소멸됩니다.
- 생성된 문서는 보관 기간(무료: 7일, 스탠다드: 90일) 이후 삭제됩니다.
- 프로 플랜의 무제한 보관 혜택은 해지 즉시 종료됩니다.
