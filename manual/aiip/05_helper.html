✨ AI 요청사항 도우미

✨ AI 도우미 업데이트:
KIPRIS API와 실시간 연동되어 선행기술 검색 결과를 바탕으로 더욱 정확하고 전문적인 요구사항을 제안합니다.

전문 법률 용어를 몰라도 AI가 자연어 설명을 전문 컨설팅 요청문으로 변환해 드립니다.

도우미란?

AI 요청사항 도우미는 IP(지식재산권) 컨설팅에 익숙하지 않은 분들도 쉽게 전문적인 분석을 요청할 수 있도록 도와주는 기능입니다.

예를 들어 "내가 만든 앱의 핵심 알고리즘을 보호받고 싶어요"라고 일상 언어로 설명하면, AI가 이를 "본 발명은 △△ 기술을 활용한 알고리즘으로서, 특허 청구항 구성 및 선행기술 대비 신규성·진보성 분석을 요청합니다"와 같은 전문 요청문으로 변환합니다.

도우미 열기

컨설팅 의뢰 페이지(/diagnosis)의 요청사항 입력 박스 오른쪽 상단에 있는 "✨ AI로 요청사항 만들기" 버튼을 클릭합니다.

버튼을 클릭하면 요청사항 박스 위에 도우미 입력 박스가 펼쳐집니다.

도우미 사용법

  1. 도우미 박스의 텍스트 입력창에 원하는 내용을 자연어로 입력합니다.
    예: "새로운 배터리 충전 기술을 발명했는데 특허를 낼 수 있는지 분석해 주세요"
  2. "🤖 요청사항 자동 생성" 버튼을 클릭합니다.
  3. AI가 입력 내용을 분석하여 전문 컨설팅 요청문을 생성합니다.
  4. 생성된 요청문이 아래 요청사항 입력창에 자동으로 채워집니다.
  5. 생성된 내용을 직접 수정하거나 그대로 사용할 수 있습니다.
💡 입력 팁
- 보호받으려는 기술·브랜드·창작물의 핵심 특징을 구체적으로 설명하세요.
- 우려되는 상황(유사 기술 존재, 경쟁사 동향 등)을 함께 언급하면 더 정확한 요청문이 생성됩니다.
- 분석 유형(특허/상표/저작권)에 맞는 맥락으로 설명하면 더 좋습니다.

입력 예시

분석 유형자연어 입력 예시생성되는 전문 요청문 방향
특허 "AI가 사용자 수면 패턴을 분석해서 최적의 수면 시간을 추천하는 앱을 만들었어요" AI 기반 수면 패턴 분석 및 최적 수면 시간 추천 알고리즘에 대한 특허 가능성 검토, 선행기술 조사, 청구항 구성 요청
상표 "'그린리프'라는 이름으로 유기농 식품 브랜드를 시작하려 하는데 상표 등록이 될까요?" '그린리프' 상표의 식품류(제30류 등) 등록 가능성 검토, 유사 등록 상표 비교 분석 요청
저작권 "내가 작성한 소설의 일부가 다른 소설에 그대로 나와 있는 것 같아요" 저작물 동일성·유사성 분석 및 저작권 침해 여부 검토 요청

재생성 & 수동 수정

생성된 요청문이 마음에 들지 않으면 도우미 입력창 내용을 수정한 뒤 "🤖 요청사항 자동 생성" 버튼을 다시 클릭하면 새로운 요청문이 생성됩니다.

또한 요청사항 입력창에 채워진 내용을 직접 편집하여 원하는 대로 다듬을 수 있습니다.

도우미 닫기

"✨ AI로 요청사항 만들기" 버튼을 다시 클릭하면 도우미 박스가 닫힙니다. 요청사항 입력창에 이미 채워진 내용은 그대로 유지됩니다.
