📜 의뢰 결과 목록

지금까지 제출한 모든 AI 컨설팅 의뢰 내역과 결과를 조회하는 방법을 안내합니다.

의뢰 목록 접속

상단 내비게이션의 "의뢰 목록"을 클릭하거나, ps.kiam.kr/result로 접속합니다.

목록 구성

의뢰 목록 페이지에는 제출한 모든 의뢰가 최신 순으로 표시됩니다.

목록 표시 항목

항목설명
의뢰 번호각 의뢰의 고유 식별 번호
분석 유형특허 / 상표 / 저작권 아이콘과 텍스트로 표시
의뢰 일시의뢰 제출 날짜와 시간
상태분석 중 / 완료 / 실패로 표시 (색상 배지)
요약AI 분석 결과의 핵심 한 줄 요약
상세 보기전체 분석 결과 페이지로 이동하는 버튼

상태 배지 의미

상태색상의미
분석 중🟡 노란색AI가 현재 분석을 진행 중입니다. 잠시 기다려주세요.
완료🟢 초록색분석이 완료되어 결과를 확인할 수 있습니다.
실패🔴 빨간색분석 중 오류가 발생했습니다. 다시 의뢰해 주세요.

필터 & 검색

목록 상단의 필터와 검색 기능을 활용하면 원하는 의뢰를 빠르게 찾을 수 있습니다.

기능설명
유형 필터전체 / 특허 / 상표 / 저작권 중 선택하여 해당 유형만 표시
상태 필터전체 / 분석 중 / 완료 / 실패 중 선택
날짜 필터특정 기간의 의뢰만 표시
텍스트 검색요청사항 내용으로 의뢰 검색

상세 결과 보기

목록에서 의뢰 항목 또는 "상세 보기" 버튼을 클릭하면 해당 의뢰의 전체 분석 결과 페이지로 이동합니다. 분석 결과 내용은 6장 AI 분석 결과 읽기를 참고하세요.

재의뢰

이전 의뢰와 동일한 자료로 다시 분석을 받으려면 상세 결과 페이지의 "다시 의뢰하기" 버튼을 클릭합니다. 이전 입력 내용이 미리 채워진 의뢰 페이지로 이동합니다.

💡 실패한 의뢰가 있다면 해당 의뢰의 상세 페이지에서 오류 내용을 확인하고 재의뢰하세요. 파일 형식이 지원되지 않거나 파일 크기가 초과된 경우 실패할 수 있습니다.

의뢰 삭제

목록에서 불필요한 의뢰를 삭제할 수 있습니다. 상세 결과 페이지 하단의 "의뢰 삭제" 버튼을 클릭합니다.

⚠️ 삭제된 의뢰와 생성 문서는 복구할 수 없습니다. 신중하게 삭제하세요.
