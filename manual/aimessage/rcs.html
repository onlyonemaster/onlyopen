RCS란?

RCS(Rich Communication Services)는 기존 SMS/LMS를 대체하는 차세대 문자 서비스입니다. 이미지, 동영상, 버튼, 카드 등 풍부한 콘텐츠를 문자처럼 발송할 수 있어 브랜드 마케팅에 최적화되어 있습니다.

특징: 별도 앱 설치 없이 기본 문자 앱에서 수신 가능 (Android 8.0 이상, 통신 3사 지원)

SMS vs RCS 차이

항목SMS/LMSRCS
글자 수최대 2,000바이트제한 없음
이미지MMS만 가능기본 지원
버튼불가최대 3개 버튼
브랜딩발신번호만로고 + 브랜드명
카드 형식불가가로/세로 카드
건당 비용0.7원~별도 단가 (통신사 계약)

RCS 신청 방법

⚠️ 사전 등록 필요: RCS는 사업자 등록과 통신사 브랜드 승인 절차가 필요합니다. 개인 사용은 불가합니다.
  1. 1
    https://rcs.kiam.kr 접속
  2. 2
    브랜드 등록 신청서 작성 (사업자등록증, 브랜드명, 로고 첨부)
  3. 3
    통신 3사 심사 진행 (5~10 영업일)
  4. 4
    승인 완료 후 RCS 발송 기능 활성화

RCS 발송하기

  1. 1
    AI 메시지 → [발송 채널] 탭에서 RCS 선택
  2. 2
    템플릿 종류 선택 (기본형 / 카드형 / 버튼형)
  3. 3
    내용 입력 — AI 자동 생성 또는 직접 입력
  4. 4
    수신자 목록 업로드 → 미리보기 확인
  5. 5
    [발송하기] → 포인트 차감 후 즉시 또는 예약 발송

RCS 템플릿 종류

템플릿구성적합한 용도
기본형브랜드명 + 텍스트공지, 알림
이미지형이미지 + 텍스트 + 버튼 1개이벤트, 프로모션
세로 카드형이미지 + 제목 + 설명 + 버튼 3개상품 소개
가로 카드 슬라이드여러 카드 가로 스크롤카탈로그, 다중 상품
