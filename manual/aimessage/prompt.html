프롬프트 설정

AI가 어떤 방향으로 메시지를 생성할지 지시하는 핵심 설정입니다. 프롬프트 품질이 곧 메시지 품질을 결정합니다.

프롬프트란?

프롬프트(Prompt)는 AI에게 주는 지시 사항입니다. "어떤 목적으로, 어떤 대상에게, 어떤 방식으로 메시지를 보낼지"를 AI에게 알려줍니다. 발신자 정보와 함께 AI가 메시지를 생성하는 데 사용됩니다.

🤖

발신자 정보를 바탕으로 AI가 프롬프트를 자동 작성. 편리하고 빠름
✍️
직접 입력
원하는 방향을 직접 상세하게 입력. 더 세밀한 메시지 생성 가능

AI 자동 프롬프트 생성

발신자 정보를 미리 입력해 두면 AI가 자동으로 최적 프롬프트를 생성합니다.

  • 1
    AI 메시지 화면 → [프롬프트 설정] 탭 선택
  • 2
    [AI 프롬프트 자동 생성] 버튼을 클릭합니다
    등록된 발신자 정보(사업체명, 업종, 소개 내용)를 분석하여 6단계 퍼널에 맞는 프롬프트를 자동 작성합니다.
  • 3
    생성된 프롬프트를 확인하고 필요 시 수정합니다
    자동 생성된 내용을 그대로 사용해도 되고, 부분적으로 수정할 수도 있습니다.
📌 발신자 정보가 부실하면 프롬프트 품질이 낮아집니다
자동 생성 전에 반드시 발신자 정보를 상세하게 입력해 두세요.

프롬프트 직접 작성

더 구체적이고 세밀한 메시지를 원한다면 프롬프트를 직접 작성합니다.

효과적인 프롬프트 구조

구성 요소설명예시
발신자 소개 나는 누구인가 "저는 10년 경력 부동산 전문가 홍길동입니다"
수신자 특성 메시지를 받는 대상 "수도권 이사를 고려 중인 30~40대 직장인"
메시지 목적 이 메시지로 무엇을 하고 싶은가 "AI 챗봇 상담으로 유도, 물건 정보 제공"
톤 & 스타일 어떤 분위기로 쓸 것인가 "친근하고 전문적으로, 과장 없이"
금지 사항 쓰지 말아야 할 내용 "가격 숫자 직접 언급 금지, 경쟁사 비교 금지"

업종별 프롬프트 예시

💡 부동산 중개업 예시
"저는 10년 경력의 부동산 중개사 홍길동입니다. 수도권 아파트 매매·전세를 전문으로 합니다. 수신자는 최근 1년 내 이사를 고려 중인 분들입니다. 메시지는 친근하고 신뢰감 있는 톤으로, 챗봇 링크 클릭을 유도합니다. 과장된 표현이나 확정적 수익 언급은 피합니다."
💡 교육·코칭업 예시
"저는 독서·자기계발 코치 김선생입니다. 수신자는 직장에서 성장하고 싶지만 방법을 모르는 30대 직장인입니다. 메시지는 공감적이고 따뜻한 톤으로, 독서 습관 형성의 필요성을 일깨워 AI 상담으로 연결합니다."

6단계 퍼널별 프롬프트

각 발송 단계(훅→케어)별로 다른 목적의 메시지를 생성합니다. AI가 자동으로 각 단계에 맞는 내용을 조절하지만, 단계별 방향을 지정할 수도 있습니다.

단계프롬프트 포인트
1단계 Hook호기심 자극. 질문형으로 시작. 수신자 고민을 정확히 건드리기
2단계 Analysis공감 표현. "이런 분들이 많습니다" 형식. 문제 현실화
3단계 Insight핵심 정보·인사이트 제공. 가치 있는 내용 포함
4단계 Solution명확한 CTA 포함. 챗봇 링크 클릭 유도. 혜택 강조
5단계 Retention이전 메시지 자연스럽게 언급. 재참여 유도
6단계 Care장기 관계 유지. 부담 없이 연락 가능한 느낌

메시지 생성 실행

  • 1
    프롬프트 작성 또는 자동 생성 완료 후 [메시지 생성] 버튼 클릭
    AI가 6단계 × 최대 5회 = 최대 30개 메시지를 한 번에 생성합니다.
  • 2
    생성된 메시지 목록을 확인합니다
    각 메시지를 미리보기하고, 마음에 들지 않는 항목은 개별 재생성하거나 직접 편집합니다.
  • 3
    확인 완료 후 [발송 설정] 탭으로 이동합니다
