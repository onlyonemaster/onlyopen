발신자 정보 설정

AI가 나를 대신해 메시지를 생성하려면 먼저 발신자(나·우리 사업체)에 대한 정보를 입력해야 합니다. 이 정보가 AI 메시지 품질에 직접 영향을 줍니다.

기본정보 탭 접속

  • 1
    AI 메시지 화면으로 이동합니다
    https://kiam.kr/list_funnelmessages_details.php
  • 2
    상단 [기본정보] 탭을 선택합니다
    AI 메시지 설정 화면의 첫 번째 탭입니다. 처음 접속 시 이 탭이 자동 선택됩니다.

발신자 기본 정보 입력

AI가 메시지를 생성할 때 발신자를 어떻게 표현할지 결정하는 핵심 정보입니다.

항목설명AI 활용 방식
발신자 이름 수신자에게 표시될 보내는 사람 이름 메시지 서두에 자동 삽입 (예: "홍길동입니다")
사업체명 회사·브랜드·팀 이름 소개 문구, 신뢰감 형성에 활용
업종·카테고리 부동산, 교육, 건강, 보험 등 업종에 맞는 어휘와 톤 자동 적용
발신 번호 사전 등록된 휴대폰·사무용 번호 폰문자 발신 번호로 사용
챗봇 링크 원챗에서 발급받은 챗봇 URL 메시지 본문에 자동 삽입 (단축 URL 변환)
💡 챗봇 링크 입력 방법
원챗 → 상단 아바타 이미지 클릭 → [챗봇 설정] → 공유 링크를 복사하여 붙여넣으세요.
형식 예시: https://chatbot.kiam.kr/s/내아이디

사업체 소개 정보

AI가 사업체에 대해 더 잘 이해할수록 메시지 품질이 높아집니다. 아래 항목을 최대한 상세하게 입력하세요.

소개 텍스트

사업체의 핵심 가치·서비스·강점을 자유롭게 입력합니다.

추천 입력 내용예시
핵심 서비스·상품"저는 10년 경력의 부동산 전문가로, 수도권 아파트 매매·전세를 전문으로 합니다."
차별화 포인트"다른 업체와 달리 고객이 원하는 지역을 직접 발로 뛰며 찾아드립니다."
고객 성공 사례"지난 6개월간 30가구의 이사를 도와드렸으며, 재방문율 90%입니다."
서비스 지역·운영 시간"서울·경기 전 지역 담당. 평일 오전 9시~오후 8시, 주말 상담 가능."

소개 파일 업로드

이미 만들어진 회사 소개서, 상품 안내서, 서비스 제안서가 있다면 파일로 업로드합니다. AI가 파일 내용을 직접 참고하여 더 정확한 메시지를 생성합니다.

지원 형식활용 예시
PDF회사 소개서, 서비스 안내서, 상품 카탈로그
TXTFAQ 목록, 서비스 설명 텍스트
CSV상품 목록, 가격표
📌 파일을 업로드하면 마이페이지 → 사업체 정보의 소개 파일과 동일하게 공유됩니다. 업로드한 파일은 AI 메시지 생성 시 자동으로 참고합니다.

발송 기본 설정

메시지 발송 방식에 관한 기본 설정입니다.

설정 항목설명
발송 채널 폰문자(SMS/LMS/MMS) 또는 웹문자(RCS) 선택
수신거부 번호 (080) 수신거부 처리용 080 번호. 미입력 시 시스템 공용 번호 사용
발송 예약 시간 즉시 발송 또는 날짜·시간 지정 예약
메시지 생성 수량 기본 30회치 자동 생성. 퍼널 단계별 1회씩 자동 발송
