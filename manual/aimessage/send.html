메시지 발송하기

수신자 목록을 업로드하고 채널을 선택해 AI 메시지를 발송합니다. 즉시 발송과 예약 발송을 모두 지원합니다.

퍼널 발송 채널 탭

발신자 정보·프롬프트 설정 완료 후 [퍼널 발송 채널] 탭으로 이동합니다.

📱
폰문자 (SMS/LMS/MMS)
일반 휴대폰 문자. 수신자의 문자함으로 전달. 가장 높은 도달률
💬
웹문자 (RCS)
인터넷 기반 문자. 이미지·버튼 포함 가능. 스마트폰 전용

수신자 목록 업로드

발송할 대상의 전화번호 목록을 파일로 업로드합니다.

파일 형식

형식권장 열 구성비고
Excel (.xlsx) A열: 전화번호 / B열: 이름 (선택) 가장 일반적인 형식
CSV (.csv) phone,name 헤더 또는 번호만 DB에서 추출한 파일
직접 입력 번호를 줄바꿈으로 구분하여 입력 소량 발송 시 편리
📌 전화번호 형식
01012345678 또는 010-1234-5678 모두 허용됩니다. 하이픈(-) 유무와 관계없이 자동 처리됩니다.

업로드 방법

  • 1
    [수신자 목록 업로드] 버튼을 클릭합니다
  • 2
    파일을 드래그하거나 클릭하여 선택합니다
    업로드 후 전화번호 열을 매핑(지정)합니다. 이름 열이 있으면 메시지에 수신자 이름이 자동 삽입됩니다.
  • 3
    업로드된 수신자 수를 확인합니다
    중복 번호·잘못된 형식은 자동 필터링됩니다. 수신거부 번호는 자동 제외됩니다.

발송 옵션 설정

옵션설명
발송 시작 단계 1단계(Hook)부터 시작하거나 특정 단계부터 발송
발송 간격 각 단계 메시지 사이 대기 일수 설정 (기본 3~7일)
발송 시간대 오전 9시~오후 9시 사이로 자동 제한 (스팸 방지)
즉시/예약 지금 즉시 발송 또는 특정 날짜·시간 예약

발송 미리보기 & 확인

  • 1
    [미리보기] 버튼으로 실제 발송될 메시지를 확인합니다
    수신자 이름이 삽입된 형태와 챗봇 링크 단축 URL을 포함한 최종 메시지를 미리볼 수 있습니다.
  • 2
    예상 포인트 소비량을 확인합니다
    수신자 수 × 단계 수 × 건당 단가로 계산됩니다. 잔여 포인트가 부족하면 발송이 중단됩니다.
  • 3
    [발송 시작] 버튼을 클릭합니다
    예약 발송 시에는 설정한 날짜·시간에 자동으로 발송됩니다.
⚠️ 발송 취소는 발송 전에만 가능합니다
발송이 시작된 메시지는 취소가 불가능합니다. 미리보기와 수신자 목록을 반드시 확인하세요.

발송 결과 확인

발송 완료 후 결과를 확인합니다.

확인 항목위치내용
발송 내역 kiam.kr → 폰문자 → 발신내역 발송 성공·실패 건수, 발송 시간
수신 현황 kiam.kr → 폰문자 → 수신내역 수신자별 수신 여부, 링크 클릭 여부
챗봇 유입 원챗 → 발신 탭 (퍼널) 메시지 링크를 클릭한 고객 목록 자동 등록
포인트 차감 마이페이지 → 이용 내역 발송 건당 차감된 포인트 확인

발송 후 관리

AI 메시지 링크를 클릭한 방문자는 원챗 발신 탭(퍼널)에 자동 등록됩니다. 이후 AI 동행·시나리오 캠페인으로 자동 후속 관리가 이어집니다.

📌 원챗과의 연계 흐름
AI 메시지 발송 → 수신자 링크 클릭 → 원챗 발신탭 자동 등록 → AI 동행 자동 인사 → 시나리오 캠페인으로 장기 관계 유지
