🎬 VAG 영상팩토리

주제 한 줄만 입력하면 AI가 스크립트 · 이미지 · 음성 · 영상 클립을 모두 자동 생성합니다.
최대 8개 AI 엔진을 선택해 5분 만에 SNS 완성 영상을 제작하세요.

서비스 주소: https://vag.kiam.kr

전체 영상 생성 파이프라인

1
AI 스크립트 생성

주제와 방향을 입력하면 DeepSeek AI가 장면별 나레이션 · 자막 · 환경음 타입이 포함된 JSON 스크립트 자동 생성

2
이미지 준비

Pexels API로 장면별 이미지 자동 다운로드, 또는 사용자 업로드 이미지 사용

3
TTS 나레이션 생성

OpenAI TTS로 장면별 한국어 음성 파일 자동 합성 (키 없을 시 무음 진행)

3.5
환경음 트랙 생성

nature · ocean · rain · wind · city · indoor · dramatic · default 8가지 환경음을 장면 길이에 맞춰 concat하여 단일 ambient_track.mp3 생성

4
AI 영상 클립 생성

선택한 AI 엔진(Kling / WAN / MiniMax / Luma 등)으로 이미지→동영상 변환. 실패 시 FFmpeg 폴백

5
최종 합성 & 완성

클립 concat + TTS 나레이션(100%) + 환경음(35%) + 배경음(10%) 3트랙 믹싱 → final.mp4 + thumb.jpg
