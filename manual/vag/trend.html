📈 YouTube 트렌드 분석 솔루션

YouTube 인기 영상 데이터를 수집하고 Claude AI가 패턴을 분석하여
최적의 콘텐츠 전략과 영상 제작 아이디어를 자동으로 도출합니다.

연동 방식: 트렌드 분석 결과를 바탕으로 VAG 영상 생성의 주제·방향을 자동 설정할 수 있습니다.

핵심 기능

🔍
카테고리별 분석
건강, 재테크, 라이프스타일 등 원하는 카테고리의 YouTube 인기 영상 실시간 수집
🧠
Claude AI 인사이트
수집된 데이터를 Claude Sonnet이 분석하여 성공 패턴·키워드·최적 영상 길이 도출
🌟
바이럴 잠재력 점수
각 트렌드 주제에 바이럴 잠재력 점수(1~10)를 자동으로 부여
🎯
즉시 영상 제작
분석 결과에서 원클릭으로 VAG 영상 생성 페이지로 이동하여 바로 영상 제작

분석 프로세스 (6단계)

1
카테고리 선택

분석할 YouTube 카테고리를 선택합니다.
건강·재테크·라이프스타일·기술·음식·여행·교육 등 지원

2
YouTube Data API 수집

YouTube Data API v3으로 해당 카테고리 인기 영상 최대 50개를 수집합니다.
제목 · 설명 · 조회수 · 좋아요수 · 구독자수 · 영상 길이 수집

3
데이터 전처리

수집된 영상 데이터를 정규화하고 분석용 구조로 변환합니다.
중복 제거 · 이상치 처리 · 참여율(engagement rate) 계산

4
Claude AI 분석

전처리된 데이터를 Claude Sonnet API에 전달하여 심층 분석을 요청합니다.
성공 패턴 · 공통 키워드 · 최적 제목 구조 · 영상 길이 분포 분석

5
트렌드 주제 생성

분석 결과를 바탕으로 현재 트렌딩 주제 목록을 생성합니다.
각 주제에 바이럴 잠재력 점수(1~10)와 추천 영상 길이를 부여

6
결과 확인 & 영상 제작

분석 결과를 대시보드에서 확인하고, 마음에 드는 트렌드 주제를 선택하면
해당 주제가 자동으로 VAG 영상 생성 폼에 입력됩니다.

분석 결과 구성

Claude AI 분석 보고서 구성
🌟 성공 영상 패턴
조회수·좋아요 상위 영상의 공통 요소 (제목 패턴, 썸네일 키워드, 도입부 구조)
📝 핵심 키워드
고참여율 영상에서 반복 등장하는 키워드 TOP 10 (제목·설명·태그 기준)
⏳ 최적 영상 길이
카테고리별 참여율이 가장 높은 영상 길이 구간 분석
🌟 트렌드 주제 TOP 5
현재 가장 높은 바이럴 잠재력을 가진 콘텐츠 주제와 점수
