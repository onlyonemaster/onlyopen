💵 요금제 안내

VAG 영상팩토리의 비용 구조는 크게 두 부분으로 나뉩니다.
플랫폼 이용료(구독) + AI 엔진 API 비용(종량제)

플랫폼 이용 요금

플랜 월 영상 생성 수 가격 포함 기능
Free 월 5편 무료 FFmpeg 엔진만, Pexels 이미지, TTS 포함
Basic 월 30편 ₩19,900/월 모든 AI 엔진, 업로드 이미지, 트렌드 분석
Pro 월 100편 ₩49,900/월 Basic 포함, 우선 처리, 갤러리 무제한
Enterprise 무제한 별도 문의 전용 서버, 화이트라벨, API 제공

AI 엔진 API 비용 (종량제)

AI 엔진(Kling, WAN, MiniMax, Luma)을 사용할 경우 외부 API 비용이 추가로 발생합니다.
FFmpeg 엔진은 서버 자체 처리로 추가 비용이 없습니다.

* 비용은 참고치이며 API 제공사 요금 정책에 따라 변동됩니다. 최신 요금은 각 API 제공사 공식 사이트를 참고하세요.
