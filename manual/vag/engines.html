🤖 AI 엔진 비교

VAG는 7가지 엔진 중 하나를 선택하여 영상을 생성합니다.
목적과 예산에 맞는 엔진을 선택하세요.

폴백 원칙: AI 엔진 선택 시 API 오류나 파일 크기 미달(10KB 미만)이 발생하면 자동으로 FFmpeg로 폴백합니다. 완전히 실패하는 영상은 없습니다.

엔진별 상세 설명

⚙ FFmpeg (로컬)

서버에 설치된 FFmpeg로 이미지를 Ken Burns 효과(줌인 + 패닝) 동영상으로 변환합니다.
외부 API 없이 즉시 처리되므로 비용이 없고 빠릅니다.

  • 이미지 → 10초 MP4 (지속시간은 장면 duration_sec 적용)
  • scale → zoompan (Ken Burns) → drawtext (자막 burn-in)
  • API 키 불필요

🎬 Kling 3.0 / PiAPI

중국 콰이쇼우(Kuaishou)의 Kling AI 모델을 PiAPI를 통해 사용합니다.
현재 가장 높은 영상 품질을 제공하는 image-to-video 모델 중 하나입니다.

  • 필요 키: [PIAPI API 키] (서버 설정)
  • 대기 폴링: 최대 120초, 5초 간격
  • 지원 비율: 16:9, 9:16, 1:1

🎬 Kling 2.1 Standard / Pro — fal.ai

fal.ai 플랫폼을 통해 Kling 2.1 모델을 사용합니다.
Standard는 비용 효율, Pro는 최고 품질을 목표로 합니다.

  • 필요 키: [fal.ai API 키] (서버 설정)
  • 엔진 ID: [엔진식별자-std] / [엔진식별자-pro]
  • 비동기 큐 방식 — 요청 후 결과 URL 폴링

🎬 WAN 2.1 / fal.ai

Wan2.1은 자연스러운 물체 움직임과 배경 모션에 특화된 모델입니다.
풍경, 자연, 건물 등 정적인 이미지를 생동감 있게 만들어줍니다.

  • 필요 키: [fal.ai API 키] (서버 설정)
  • 엔진 ID: [엔진식별자-wan]

🎬 MiniMax Video / fal.ai

인물 표정과 행동을 자연스럽게 표현하는 데 강점이 있습니다.
인터뷰 형식, 강의 영상, 스토리텔링에 적합합니다.

  • 필요 키: [fal.ai API 키] (서버 설정)
  • 엔진 ID: [엔진식별자-minimax]

🎬 Luma Dream Machine / fal.ai

영화적이고 몽환적인 분위기의 영상 생성에 특화된 모델입니다.
브랜드 영상, 뮤직비디오, 감성적 콘텐츠에 어울립니다.

  • 필요 키: [fal.ai API 키] (서버 설정)
  • 엔진 ID: [엔진식별자-luma]
