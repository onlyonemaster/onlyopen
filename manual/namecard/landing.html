인포랜딩이란?

인포랜딩은 이벤트 상품이나 서비스를 소개하는 랜딩페이지(상세 페이지)를 직접 만들고 리스트로 관리하는 기능입니다. 코딩 없이 드래그&드롭으로 전문적인 랜딩페이지를 제작할 수 있습니다.

활용 예시: 부동산 매물 상세 페이지, 신상품 론칭 페이지, 세미나·강연 신청 페이지, 이벤트 쿠폰 페이지

랜딩페이지 만들기

  1. 1
    마이페이지 → 인포랜딩 목록 접속
  2. 2
    [+ 새 랜딩페이지 만들기] 클릭
  3. 3
    템플릿 선택 (빈 페이지 또는 업종별 템플릿)
  4. 4
    섹션 추가 및 내용 편집
  5. 5
    제목 입력 → [공개] 설정 → [저장]
  6. 6
    생성된 URL을 명함이나 문자에 삽입

구성 요소

요소설명
📸 이미지 배너상단 메인 이미지 또는 슬라이드
📝 텍스트 블록제목, 부제목, 본문 내용
📋 신청 폼이름, 전화번호, 이메일 수집 폼
🖼️ 갤러리다중 이미지 그리드
📹 동영상YouTube 또는 직접 업로드
🔘 CTA 버튼챗봇 링크, 전화 연결, 외부 URL
💬 댓글방문자 댓글 기능 (ON/OFF)

랜딩 목록 관리

인포랜딩 목록 페이지에서 아래 정보를 확인할 수 있습니다:

항목설명
제목랜딩페이지 이름
조회수총 페이지 방문 횟수
댓글수누적 댓글 개수
신청수폼 제출 횟수
노출/중지공개 상태 ON/OFF 토글
수정/삭제편집 및 삭제 버튼

명함 & 챗봇 연동

  • 명함 연동: 명함 편집 → [콘텐츠 추가] → 인포랜딩 블록 선택 → 게시 중인 랜딩 목록에서 선택
  • AI 챗봇 연동: 신청 폼 제출 시 고객 정보가 원챗에 자동 등록됩니다.
  • 문자 발송 연동: 랜딩 URL을 폰문자·AI메시지 본문에 삽입하여 직접 공유하세요.
  • 공유 URL 형식: https://kiam.kr/landing/내아이디/랜딩ID
