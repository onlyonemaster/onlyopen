명함 수정 & 관리

등록한 명함 내용을 수정하고, 여러 장의 명함을 관리하는 방법을 설명합니다.

명함 수정

  • 1
    kiam.kr 로그인 후 내 명함 화면으로 이동합니다
    메인 화면 상단 우측 ⋮ (더보기 메뉴) 또는 명함 편집 버튼을 클릭합니다.
  • 2
    수정할 항목을 클릭하고 변경합니다
    이름·직책·사진·연락처·SNS 링크 등 모든 항목을 개별 수정할 수 있습니다.
  • 3
    [저장] 버튼을 클릭합니다
    저장 즉시 명함 URL에서 변경 내용이 반영됩니다.

멀티 명함 관리

kiam.kr에서는 여러 장의 명함을 등록하여 상황에 맞게 전환할 수 있습니다. 예를 들어 개인 명함 / 사업 명함 / 특정 프로젝트용 명함을 분리하여 운영할 수 있습니다.

명함 추가

  • 1
    마이페이지 → [명함 목록] 이동
    https://kiam.kr/mypage_chatbot_list.php
  • 2
    [명함 추가] 버튼을 클릭합니다
    새로운 명함을 처음부터 만들거나 기존 명함을 복사하여 시작할 수 있습니다.
  • 3
    명함 이름(식별용)을 입력하고 저장합니다
    각 명함에는 고유한 URL이 부여됩니다.

대표 명함 전환

여러 명함 중 대표 명함을 지정할 수 있습니다. 대표 명함이 메인 URL(kiam.kr/내아이디)에 표시됩니다.

명함 상태설명
대표 명함 ★메인 URL에 표시. 기본 챗봇 링크로 연결됨
추가 명함고유 URL로 개별 접속 가능. 용도별 운영
비공개 명함링크를 알고 있는 사람만 접근 가능

명함 드롭다운 메뉴

각 명함 카드의 우측 상단 ⋮을 클릭하면 명함별 관리 메뉴가 열립니다.

메뉴 항목기능
✏️ 편집명함 내용 수정 모드 진입
🔗 링크 복사해당 명함 URL을 클립보드에 복사
📷 QR코드QR코드 이미지 다운로드 또는 공유
★ 대표 설정이 명함을 대표 명함으로 지정
📋 복사이 명함을 복사해서 새 명함 생성
🗑️ 삭제명함 영구 삭제 (복구 불가)
⚠️ 명함 삭제 시 주의
삭제된 명함의 URL은 더 이상 열리지 않습니다. 해당 명함 링크를 이미 공유한 경우 수신자가 접근 불가능해집니다.

그룹 명함

팀·조직을 대표하는 그룹 명함을 만들어 여러 명이 함께 관리할 수 있습니다.

  • 1
    kiam.kr 메인 → [그룹 페이지] 메뉴 선택
    https://kiam.kr/?cur_win=group-con
  • 2
    [그룹 만들기] 클릭 → 그룹 이름 입력
  • 3
    멤버를 초대하여 함께 관리합니다
    그룹 관리자는 멤버 초대·추방·이름 변경·그룹 해체 권한을 가집니다.
