위스토리란?

위스토리는 kiam.kr 명함 페이지에 SNS 스토리처럼 사진, 동영상, 텍스트 콘텐츠를 게시할 수 있는 기능입니다. 고객이 명함 링크를 방문했을 때 최신 소식이나 프로모션을 바로 보여줄 수 있습니다.

인스타그램 스토리처럼 일정 기간(24시간~30일) 후 자동으로 만료되거나 상시 게시로 설정할 수 있습니다.

스토리 작성

  1. 1
    명함 편집 화면 → [콘텐츠 추가] → 위스토리 선택
  2. 2
    또는 마이페이지 → 위스토리 관리로 바로 접속
  3. 3
    [+ 새 스토리 작성] 클릭
  4. 4
    콘텐츠 유형 선택 → 내용 입력 → 공개 기간 설정
  5. 5
    [게시하기] 클릭 → 명함 페이지에 즉시 반영

콘텐츠 유형

유형설명규격
📝 텍스트공지, 한 줄 소식, 인용문최대 500자
🖼️ 이미지사진, 포스터, 제품 이미지JPG/PNG, 최대 5MB
🎥 동영상소개 영상, 튜토리얼MP4, 최대 50MB, 3분 이하
🔗 링크 카드외부 링크를 카드 형태로 표시URL 입력 시 자동 미리보기
🎰 이벤트경품 이벤트, 신청 폼 연동폼 링크 삽입

명함에 표시

위스토리는 명함 페이지 하단에 가로 스크롤 카드 형태로 표시됩니다.

  • 최신 스토리가 가장 앞에 표시됩니다.
  • 만료된 스토리는 자동으로 숨겨집니다.
  • 핀 고정 기능으로 특정 스토리를 항상 상단에 노출할 수 있습니다.
  • 스토리 클릭 시 상세 페이지 또는 지정 링크로 이동합니다.

활용 팁

  • 📅 정기 업데이트: 주 1~2회 새 스토리를 올리면 재방문율이 높아집니다.
  • 🎯 이벤트 활용: "링크 클릭 후 AI 챗봇에 '이벤트' 입력 시 쿠폰 발급" 같은 챗봇 연동 이벤트를 활용하세요.
  • 📊 조회수 확인: 각 스토리별 조회수와 클릭수를 대시보드에서 확인할 수 있습니다.
  • 🔔 알림 발송: 새 스토리 게시 시 구독 고객에게 알림 문자를 자동 발송할 수 있습니다.
