🔗 링크 신청

kiam.kr 명함에 외부 서비스 링크, 신청 폼, 예약 버튼 등을 추가하는 방법을 안내합니다. 명함 방문자가 원클릭으로 신청·예약·구매 등을 바로 할 수 있습니다.

링크 신청이란?

명함에 외부 URL·신청 폼·예약 시스템 등의 링크를 클릭 가능한 버튼 형태로 추가하는 기능입니다. 명함 방문자가 버튼을 탭하면 바로 해당 페이지로 이동합니다.

📌 활용 예시
• 세미나 신청 → naver.me/xxx 연결
• 상담 예약 → 카카오 예약 링크 연결
• 설문 참여 → 구글 폼 링크 연결
• 제품 구매 → 스토어 링크 연결
• 오픈채팅방 → 카카오 오픈채팅 URL 연결

추가 가능한 링크 종류

링크 유형설명예시
일반 URL 웹 페이지, 블로그, 유튜브 등 모든 http/https URL 홈페이지, 유튜브 채널, 블로그 포스팅
카카오 오픈채팅 오픈채팅방 참여 링크 고객 소통방, 커뮤니티 초대
네이버 폼 네이버 설문·신청 폼 행사 신청, 강의 등록
구글 폼 Google Forms 링크 설문 조사, 피드백 수집
예약 서비스 네이버 예약, 카카오 예약 등 상담 예약, 방문 예약
파일 다운로드 PDF, 이미지, 문서 직접 다운로드 링크 카탈로그, 제품 소개서
인포랜딩 kiam.kr 인포랜딩 페이지 링크 이벤트 랜딩 페이지, 서비스 소개

링크 추가 방법

  • 1
    kiam.kr 로그인 후 명함 편집 화면으로 이동합니다
    메인 화면에서 [편집] 또는 ⋮ → 명함 수정을 클릭하세요.
    https://kiam.kr/?cur_win=my_info
  • 2
    [링크 추가] 버튼을 클릭합니다
    명함 편집 화면의 SNS 링크 / 외부 링크 섹션에서 링크 추가 버튼을 찾으세요.
  • 3
    링크 유형과 정보를 입력합니다
    항목설명
    링크 이름버튼에 표시될 텍스트 (예: "세미나 신청하기")
    URL연결할 웹 주소
    아이콘버튼 앞에 표시될 아이콘 선택 (선택 사항)
    색상버튼 배경색 설정 (선택 사항)
  • 4
    [저장]하면 명함에 버튼이 생성됩니다
    명함 방문자가 버튼을 탭하면 지정한 URL로 바로 이동합니다. 링크는 최대 10개까지 추가 가능합니다.

신청 폼 연동

kiam.kr 자체 신청 이벤트 폼을 명함에 직접 삽입할 수 있습니다. 외부 폼 링크와 달리 명함 내부에서 바로 신청이 가능합니다.

  • 1
    명함 편집 → [콘텐츠 추가] → [신청 이벤트] 선택
    신청 이벤트 블록을 명함에 추가합니다.
  • 2
    신청 폼 항목을 설정합니다
    항목설명
    이벤트 제목신청 버튼 위에 표시되는 행사명
    수집 항목이름, 전화번호, 이메일, 주소 등 원하는 정보 선택
    마감 날짜신청 기간 설정 (기간 초과 시 자동 마감)
    최대 인원선착순 마감 인원 설정 (선택)
    완료 메시지신청 완료 후 표시되는 메시지
  • 3
    신청자 목록을 확인합니다
    마이페이지 → 신청 이벤트 관리에서 신청자 목록을 CSV로 다운로드할 수 있습니다. 신청자는 원챗 수신탭에도 자동 등록됩니다.
