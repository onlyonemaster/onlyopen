아바타 학습 방법

텍스트, 파일, 음성, 일기 4가지 방법으로 AI 아바타를 학습시키는 상세한 방법을 안내합니다.

학습 화면 접속

  • 1
    원챗 상단 아바타 이미지 클릭
    우측 상단 내 아바타 이미지(이니셜 원)를 클릭합니다.
  • 2
    드롭다운에서 [🧠 아바타 학습시키기] 선택
    AI 아바타 학습 화면으로 이동합니다.

① 텍스트 직접 입력

가장 기본적인 학습 방법입니다. 직접 타이핑하거나 붙여넣기로 내용을 입력합니다.

  • 1
    학습 화면에서 [텍스트 입력] 탭을 선택합니다
  • 2
    입력창에 내용을 작성합니다
    추천 입력 내용예시
    자기소개"저는 10년 경력의 마케팅 전문가입니다. 중소기업 디지털 전환을 돕고 있습니다."
    자주 묻는 질문 (FAQ)"Q: 상담 비용은 얼마인가요? A: 초기 상담은 무료이며 이후 프로젝트별 견적을 드립니다."
    서비스·상품 설명제공하는 서비스의 특징, 가격, 사용 방법
    업무 시간·연락 방법"평일 오전 9시~오후 6시에 운영합니다."
  • 3
    [저장 & 학습] 버튼을 클릭합니다
    저장 후 동기화 아이콘이 🔄 → ✅로 바뀌면 적용 완료입니다.
💡 효과적인 텍스트 작성 팁
• 질문-답변 형식으로 작성하면 AI가 더 정확하게 답변합니다
• 핵심 키워드를 반복적으로 포함시키세요
• 하나의 주제를 짧고 명확하게 여러 번 나눠서 입력하는 것이 좋습니다

② 파일 업로드

이미 작성된 문서가 있다면 파일로 한 번에 업로드합니다.

지원 형식활용 예시
PDF회사 소개서, 상품 카탈로그, 서비스 안내서
TXT텍스트로 작성된 FAQ, 스크립트
CSV상품 목록, 가격표, 데이터 테이블
Word (DOCX)제안서, 보고서, 메뉴얼
  • 1
    학습 화면 → [파일 업로드] 탭 선택
  • 2
    파일을 드래그하거나 클릭하여 업로드합니다
    파일 크기 제한: 최대 10MB. 여러 파일을 동시에 업로드할 수 있습니다.
  • 3
    업로드 완료 후 AI가 자동으로 내용을 분석·학습합니다
    파일이 크거나 내용이 많으면 동기화에 수십 초~수 분이 소요될 수 있습니다.
⚠️ 개인정보가 포함된 파일 주의
고객 개인정보, 비밀 계약서 등 민감한 정보가 담긴 파일은 업로드하지 마세요. 업로드된 내용은 AI 응답 생성에 활용됩니다.

③ 음성 입력

타이핑이 어렵거나 말로 설명하는 것이 편하다면 음성 입력을 활용하세요.

  • 1
    학습 화면 → [음성 입력] 탭 선택
  • 2
    🎙️ 마이크 버튼을 눌러 녹음을 시작합니다
    브라우저 마이크 권한 허용이 필요합니다. 조용한 환경에서 명확하게 말하세요.
  • 3
    녹음 완료 후 텍스트로 자동 변환됩니다
    변환된 텍스트를 확인·수정 후 [저장 & 학습]을 클릭합니다.

④ 일기 (Daily) 학습

매일의 경험·생각·인사이트를 일기 형태로 기록하여 AI에게 지속적으로 학습시킵니다. 누적될수록 더 풍부한 AI 아바타가 됩니다.

  • 1
    원챗 사이드바 ☰ → [일기 쓰기] 또는 학습 화면 → [일기] 탭
  • 2
    오늘의 내용을 자유롭게 작성합니다
    업무 경험, 고객과의 대화, 새로 배운 지식, 인사이트 등을 자연스럽게 기록합니다.
  • 3
    저장하면 AI가 자동으로 학습합니다
    날짜별로 기록이 누적되어 AI가 내 최근 경험을 반영한 답변을 생성합니다.
💡 매일 짧게라도 기록하는 것이 좋습니다. 3~5줄의 짧은 메모도 충분합니다.

학습 데이터 관리

입력한 학습 데이터는 목록에서 확인·수정·삭제할 수 있습니다.

작업방법
목록 확인학습 화면 → [학습 데이터] 탭에서 전체 목록 보기
내용 수정항목 클릭 → 내용 수정 → 저장 (재동기화 자동 진행)
항목 삭제항목 우측 🗑️ 버튼 클릭 (삭제 후 재동기화 필요)
전체 초기화설정 → [학습 데이터 초기화] (주의: 복구 불가)
