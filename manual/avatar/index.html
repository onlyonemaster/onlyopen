🤖 AI 아바타 학습

나만의 AI 아바타를 만드는 핵심 기능입니다. 내 경험·지식·말투를 AI에게 학습시켜 24시간 나를 대신해 대화하는 AI를 완성하세요.

AI 아바타란?

AI 아바타는 나의 지식과 성격을 학습한 개인화 AI입니다. 원챗(OneChat) 챗봇에 연결되어 방문자와 자동으로 대화합니다.

🧠
나의 지식 학습
내가 입력한 텍스트·파일·음성을 바탕으로 AI가 학습. 내 전문성을 그대로 재현
💬
나의 말투 구현
프롬프트 설정으로 AI의 톤·스타일을 내 말투에 맞게 조정
🔄
지속적 업데이트
언제든지 새로운 내용을 추가 학습시켜 AI를 계속 발전시킬 수 있음
⚡
24시간 자동 응답
잠자는 동안에도 AI가 방문자 질문에 즉시 답변

동작 원리

AI 아바타는 RAG (Retrieval-Augmented Generation) 방식으로 동작합니다. 내가 입력한 데이터를 벡터로 저장하고, 방문자 질문이 들어오면 관련 내용을 찾아 AI가 답변을 생성합니다.

단계설명
① 데이터 입력텍스트·파일·음성·일기 등 다양한 방식으로 내 정보 입력
② 벡터 인덱싱AI가 입력된 내용을 분석하여 검색 가능한 형태로 저장
③ 동기화아바타 드롭다운의 🔄 아이콘으로 동기화 상태 확인
④ 자동 응답방문자 질문 → 관련 학습 데이터 검색 → DeepSeek AI가 답변 생성

동기화 상태 확인

원챗 상단 아바타 이미지 옆에 표시되는 아이콘으로 학습 상태를 확인합니다.

아이콘상태의미
🔄 회전동기화 중새로 입력한 데이터가 AI에 적용되는 중 (잠시 대기)
✅ 체크동기화 완료최신 학습 데이터로 AI가 응답 중
⚠️ 느낌표동기화 오류학습 화면에서 재시도 필요

학습 데이터 종류

✍️
텍스트 직접 입력
자기소개, 전문 지식, FAQ, 상품 정보 등 직접 타이핑
📄
파일 업로드
PDF·TXT·CSV·Word 문서를 업로드하면 AI가 내용 학습
🎙️
음성 입력
마이크로 직접 말하면 음성을 텍스트로 변환하여 학습
📔
일기 (Daily)
매일의 경험·생각을 일기 형태로 기록 → 누적 학습
📌 학습 데이터가 많을수록 AI 품질이 향상됩니다
처음에는 자기소개·전문 분야 기초 지식부터 입력하고, 이후 고객이 자주 묻는 질문들을 추가로 입력하면 점점 더 똑똑한 AI 아바타가 완성됩니다.

빠른 시작

  • 1
    원챗 → 아바타 이미지 클릭 → [아바타 학습시키기]
    또는 아래 주소로 직접 이동합니다.
    https://kiam.kr/aimessage/onechat/
  • 2
    자기소개 텍스트부터 입력합니다
    이름, 직업, 전문 분야, 고객에게 제공하는 가치를 3~5문단으로 작성하세요.
    → 아바타 학습 방법 상세 보기
  • 3
    저장 후 동기화가 완료되면 AI 테스트
    내 챗봇 링크로 접속하여 방문자처럼 질문해 보세요. AI 응답을 확인하고 부족한 내용을 추가 학습시킵니다.
