챗봇 동작 설정

AI 아바타가 방문자에게 어떻게 응답할지 세부 동작 방식을 설정하는 방법을 안내합니다. 말투·응답 스타일·언어·ON/OFF 제어까지 상세히 설명합니다.

챗봇 설정 접속

  • 1
    원챗 → 아바타 클릭 → [⚙️ 챗봇 설정]
    또는 원챗 사이드바(☰) → [챗봇 설정]으로 이동합니다.

AI 아바타 ON / OFF

챗봇의 AI 자동 응답 기능을 켜고 끌 수 있습니다.

상태동작사용 상황
✅ ON 방문자 메시지에 AI가 자동으로 답변 자리를 비울 때, 24시간 자동 응대가 필요할 때
🔴 OFF AI 자동 응답 중지, 운영자가 직접 답변 직접 상담할 때, 중요한 고객 응대 시
💡 채팅 화면에서도 대화 중 우측 상단 AI 토글 버튼으로 즉시 ON/OFF 전환이 가능합니다. → AI 아바타 ON/OFF 상세 보기

프롬프트 설정

AI의 역할·말투·응답 스타일을 결정하는 핵심 설정입니다.

시스템 프롬프트

AI의 기본 역할과 말투를 정의합니다. 최대 500자.

예시: "당신은 [이름]의 AI 어시스턴트입니다. 방문자에게 친근하고 전문적인 말투로 답변해 주세요. 모르는 내용은 '직접 확인해 보겠습니다'라고 답변하세요."

유저 프롬프트

메시지 내용과 방향을 구체적으로 지시합니다. 최대 2,000자.

예시: "답변은 짧고 명확하게 3문장 이내로 작성하세요. 상담 예약은 전화번호 010-XXXX-XXXX로 안내하세요. 가격 문의는 '상담 후 견적 제공'으로 답변하세요."
📌 프롬프트 자동 생성 기능
설정이 어렵다면 [🤖 프롬프트 자동 생성] 버튼을 클릭하세요. 메시지 예시를 입력하면 AI가 적합한 시스템·유저 프롬프트를 자동으로 생성해 줍니다. → 프롬프팅 설정 상세 매뉴얼

응답 스타일 설정

설정 항목옵션설명
응답 언어 한국어 / 영어 / 자동 감지 방문자 메시지 언어에 맞게 자동 전환 권장
응답 길이 짧게 / 보통 / 상세하게 짧게: 1~2문장, 보통: 3~5문장, 상세: 단락형
말투 스타일 공식적 / 친근한 / 전문적 브랜드 이미지에 맞는 말투 선택
이모지 사용 사용 / 미사용 친근한 느낌의 대화에는 이모지 사용 권장

시나리오 캠페인 연동

시나리오 캠페인을 활성화하면 챗봇 설정 위에 캠페인 프롬프트가 오버레이됩니다. 기존 설정을 유지하면서 캠페인 목표에 맞는 대화 흐름이 자동 추가됩니다.

📌 시나리오 캠페인 비활성화 시 원래 프롬프트 설정으로 자동 복원됩니다. → 시나리오 캠페인 매뉴얼
