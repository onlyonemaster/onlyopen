IAM 콜백이란?

IAM 콜백은 내 스마트폰에 부재중 전화가 왔을 때, 상대방에게 자동으로 문자 메시지를 발송해주는 서비스입니다.

예를 들어 회의 중이라 전화를 못 받았을 때, "지금 회의 중입니다. 곧 연락드리겠습니다" 같은 메시지를 자동으로 보내드립니다. 상대방이 받은 문자 안에는 내 IAM 명함 링크가 포함되어 있어, 자연스럽게 내 프로필을 공유할 수 있습니다.

📌 핵심 포인트: 콜백발송은 온리원문자 앱(Android)이 설치된 스마트폰에서만 동작합니다. 앱이 부재중 전화를 감지하면, 미리 등록해둔 콜백 메시지를 자동 발송하는 구조입니다.

콜백 발송 전체 흐름

  1. 1
    콜백 메시지 등록 — 발송할 메시지 내용(타이틀, 본문, 이미지, 링크)을 미리 만들어둡니다. → 콜백 메시지 만들기 →
  2. 2
    앱 연동 (자동) — 온리원문자 앱이 설치된 폰에서 부재중 전화가 발생하면 콜백 시스템이 자동 감지합니다.
  3. 3
    메시지 자동 발송 — 등록된 콜백 메시지 중 기본(default)으로 설정된 메시지가 상대방에게 문자로 전송됩니다.
  4. 4
    수신 확인 — 발송 내역과 수신 여부를 발신내역/수신내역에서 확인할 수 있습니다.

온리원문자 앱 설치Android 전용 앱. Google Play에서 "온리원문자" 검색 후 설치하세요.✅ 필수

빠른 시작 (5분 만에 끝내기)

  1. 1
    kiam.kr/m 접속 → 하단 [문자발송관리] 영역에서 [콜백발송] 아이콘 클릭
  2. 2
    콜백 메시지 설정하기 팝업에서 [콜백 메시지 설정하기] 버튼 클릭
  3. 3
    콜백 메시지 등록하기 화면에서 제목, 메시지 내용, 이미지, 링크주소 입력 후 [등록하기]
  4. 4
    등록 완료! 이제 부재중 전화가 오면 자동으로 메시지가 발송됩니다.
💡 팁: 콜백 메시지를 여러 개 등록해두고, 콜백리스트에서 상황에 맞는 메시지를 기본값으로 선택할 수 있습니다.
