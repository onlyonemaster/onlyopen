✏️ 3장: 노트 쓰기

노트 편집 화면에서 내용을 입력하고 꾸미는 방법을 알아봅니다. 자동 저장 기능이 있어서 내용을 잃을 걱정이 없습니다!

편집 화면 구성

새 노트 버튼을 누르면 편집 화면이 열립니다. 화면은 두 개 영역으로 나뉩니다.

📌
상단 바
뒤로가기 버튼(←), 노트 제목 입력창, 공유 버튼, 저장 상태 표시가 있습니다.
📝
에디터 영역
실제 내용을 입력하는 흰 공간입니다. 클릭하면 커서가 생겨 입력할 수 있습니다.

제목 입력하기

상단의 제목 입력창을 클릭해 노트 제목을 입력합니다. 제목은 검색과 목록 표시에 사용됩니다.

💡 제목을 꼭 입력하세요!
제목이 없으면 목록에서 "(제목 없음)"으로 보입니다. 나중에 찾기 불편하니 꼭 입력해 주세요.

내용 입력하기

에디터 영역을 클릭하면 바로 글을 쓸 수 있습니다. 일반 워드 프로세서처럼 사용하면 됩니다.

블록 형식 선택하기

에디터에서 Enter를 치면 새 줄이 생깁니다. 줄 왼쪽에 있는 + 버튼을 클릭하면 다양한 형식을 선택할 수 있습니다.

형식용도단축키
📄 일반 텍스트일반적인 글쓰기기본값
📢 제목 1 (H1)큰 제목. 가장 크게 표시됩니다.# + 스페이스
📌 제목 2 (H2)중간 크기 제목## + 스페이스
📍 제목 3 (H3)작은 제목### + 스페이스
✅ 체크리스트할 일 목록. 클릭하면 완료 표시됩니다.[ ] + 스페이스
• 글머리 목록점(•)으로 시작하는 목록- + 스페이스
1. 번호 목록숫자로 시작하는 목록1. + 스페이스
❝ 인용구강조하고 싶은 문장> + 스페이스

글자 꾸미기

글자를 드래그해서 선택하면 작은 메뉴가 나타납니다.

B
굵게 (Bold)
Ctrl + B 또는 메뉴에서 B 클릭. 중요한 내용을 굵게 표시합니다.
I
기울이기 (Italic)
Ctrl + I 또는 메뉴에서 I 클릭. 부드러운 강조에 사용합니다.
U
밑줄
Ctrl + U 또는 메뉴에서 U 클릭
🖍️
형광펜 색상
글자 배경색을 원하는 색으로 칠할 수 있습니다.

자동 저장

아이노트는 자동으로 저장됩니다. 저장 버튼을 따로 누를 필요가 없습니다!

  • ⏱
    3초 후 자동 저장
    글을 입력하고 3초 동안 입력을 멈추면 자동으로 저장됩니다. 상단에 "저장 중..." → "저장됨" 메시지가 잠깐 표시됩니다.
  • 💾
    수동 저장도 가능
    Ctrl + S를 누르면 즉시 저장됩니다. 중요한 내용을 입력했을 때 바로 저장하고 싶으면 사용하세요.
✅ 저장 걱정은 이제 그만!
브라우저를 실수로 닫아도, 갑자기 인터넷이 끊겨도 3초마다 자동 저장되어 있기 때문에 내용을 잃을 염려가 없습니다.

✏️ 에디콘 (EdiCon) 진입점 — 붙여넣기 하나로 모든 형식 자동 변환

아이노트 에디터의 진짜 마법은 에디콘(EdiCon)입니다. AI가 만든 텍스트를 붙여넣기(Ctrl+V) 하는 순간 — 에디콘이 5가지 형식을 자동 감지해 최적의 모양으로 변환합니다.

🎨 아트콘 (아트콘) 시작하기 (미리 보기)

AI로 만든 텍스트(표, 흐름도, 다이어그램 등)를 복사해서 에디터에 붙여넣으면, 아트콘(아트콘) 변환 창이 자동으로 나타납니다!

  • 1
    ChatGPT·SuperAI 등 AI에서 텍스트 복사
    AI가 만들어준 표, 흐름도, 다이어그램 등 ASCII 형태의 내용을 복사합니다.
  • 2
    노트 에디터에 붙여넣기 (Ctrl+V)
    에디터에 붙여넣으면 시스템이 AI 생성 텍스트를 자동으로 감지합니다.
  • 3
    팝업 창 확인 → "아트콘으로 변환" 클릭
    "이 내용을 AI 인포그래픽으로 변환할까요?" 팝업이 뜹니다. "변환" 버튼을 누르면 아트콘이 시작됩니다!
