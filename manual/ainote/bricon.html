📊 브리콘 (BriCon) — 브리핑·시각화 엔진

브리콘(BriCon)은 콘-트리니티의 "열매"입니다. 데이터·노트·문서를 모아서 1페이지 임원 브리핑·인터랙티브 위젯·60페이지 자동 브리핑북으로 만들어주는 엔진입니다. 에디콘이 형식을 잡고, 아트콘이 예술을 더하면, 마지막에 브리콘이 "보여줄 수 있는 결과물"로 완성합니다.

🌱 SEED · TRINITY FINAL STAGE

왜 브리콘인가?

AI가 만들어준 노트가 100개 쌓여도, "투자자한테 5분 안에 보여줘" 라는 요청 앞에서는 다 무용지물입니다. 슬라이드 만들고, 표 정리하고, 차트 그리고… 한나절이 갑니다.

브리콘은 이 마지막 마일을 자동화합니다. 노트들을 모아서 임원 브리핑·HR 대시보드·투자 자료로 버튼 한 번에 변환합니다. 평균 60페이지짜리 브리핑북을 약 3분에 완성합니다.

🎯 핵심 기능 4가지

💼
투자자 브리핑 자동화
노트·표·다이어그램·재무 데이터를 모아 60페이지 PDF로 자동 생성. 특허·기술·시장 분석 섹션 포함.
👥
HR 인사 위젯
조직도·직무·KPI를 실시간 대시보드 위젯으로 표시. 노트 안에 임베드 가능.
📈
1페이지 임원 요약
100페이지 노트를 1페이지 Executive Summary로 압축. 핵심 메트릭·차트·결론.
🤖
자동 시각화 위젯
메트릭 박스·진행률 바·KPI 트래커·로드맵 — 12종 위젯이 데이터에 맞춰 자동 생성.

⚙️ 브리콘 4단계 파이프라인

브리콘은 단순히 "예쁘게 만드는" 게 아닙니다. 4단계 자동화 파이프라인을 거쳐 발표 가능한 수준의 결과물을 만들어냅니다.

1단계
📥
데이터 수집
노트·표·차트·외부 API에서 자동 추출
2단계
🧠
AI 요약·구조화
DeepSeek가 핵심 인사이트 추출, 섹션별 분류
3단계
🎨
위젯 매칭
12종 템플릿 중 데이터에 맞는 위젯 자동 선택
4단계
📤
출력 (HTML/PDF)
웹 임베드·다운로드·공유 링크 즉시 생성

📖 실전 시나리오

💼 시나리오 1 — 투자자 미팅 30분 전
"내일 시리즈 A 투자자 미팅인데, 우리 회사 6개월 데이터·기술 자료·재무 다 보여줘야 해. 자료 만들 시간이 없어."
아이노트 노트 60개를 선택 → "브리콘 → 투자자 브리핑 모드" 클릭. 3분 후 60페이지 PDF가 완성됩니다. 특허·기술 스택·시장 규모·재무 차트·로드맵까지 자동 구성. 표지·목차·페이지 번호 포함. 그대로 인쇄·이메일·발표 가능.
👥 시나리오 2 — CEO 주간 인사 보고
"매주 월요일 9시 임원회의 전에 인사 현황 요약 1페이지 필요. 매주 똑같은 거 만들기 지겨워."
브리콘에서 "HR Weekly" 위젯 한 번 설정. 이후 매주 월요일 8시에 자동 갱신, 노트에 임베드. CEO는 노트 열기만 하면 실시간 인사 대시보드를 봅니다. 인원·이직률·신규 채용·부서별 분포까지 한눈에.
📊 시나리오 3 — 분기 실적 보고서
"분기마다 실적 자료 만드는데, 차트·표 정리만 이틀씩 걸려."
분기 동안 작성한 영업·재무·고객 노트를 모두 선택 → "브리콘 → 분기 보고서 모드". 매출·고객 수·NPS·이슈를 자동 추출해 임원 1페이지 요약 + 상세 30페이지로 구성. 표지·결론 포함.

📤 출력 형식 — 어디서나 사용

🌐
HTML 임베드
노트 안에 직접 임베드, 실시간 갱신. 테마(다크/그래디언트 등)도 자동 적용.
📄
PDF 다운로드
표지·목차·페이지 번호 포함된 인쇄 가능 PDF. 60페이지 보고서도 3분에.
🔗
공유 링크
URL 한 줄로 외부에 공유. 접근 권한·만료일·비밀번호 지원.
📧
자동 이메일 발송
매주·매월 정기 보고서를 임원·팀원에게 자동 발송. 스케줄 설정 가능.

🔱 트리니티 통합 시너지

브리콘이 진가를 발휘하는 순간은 에디콘·아트콘과 결합할 때입니다.

역할엔진예시
📥 데이터 입력에디콘표·코드·다이어그램·수식을 깔끔히 정리
🎨 시각 디자인아트콘차트·인포그래픽으로 변환
📊 최종 합성브리콘여러 노트를 1개 브리핑 문서로 통합
🌟 "노트 → 자료 → 발표"가 한 줄로
에디콘으로 정리하고 → 아트콘으로 꾸미고 → 브리콘으로 묶으면, "내일 발표 자료 만들어야 해"가 "내일 발표 자료 다운로드 받았어"로 바뀝니다.

🚀 시작하기 — 3단계

  • 1
    노트에 위젯 명령 작성
    노트 안에 @bricon:hr-summary q=2026Q2 같은 한 줄을 적습니다. 12종 위젯 중 원하는 것을 선택.
  • 2
    자동 변환·임베드
    에디터가 명령을 감지해 즉시 위젯으로 변환. 데이터는 실시간 갱신됩니다.
  • 3
    브리핑북 모드 또는 공유
    개별 위젯으로 노트 안에서 쓰거나, "브리핑북 만들기" 버튼으로 여러 노트를 묶어 60페이지 PDF로 출력.

🏆 특허·기술 정보

브리콘의 "노트 → 자동 브리핑북" 파이프라인은 특허 출원 중인 독자 기술입니다. 더 자세한 자료는 투자자 브리핑을 참고하세요.
