💻 코드 블록 자동 변환

프로그래밍 코드를 노트에 붙여넣으면 에디콘이 자동으로 코드 블록으로 변환합니다. 어두운 배경 · 고정폭 글꼴 · 구문 강조 · 언어 라벨이 자동으로 적용되어 코드가 한눈에 잘 보입니다.

📥 사용 방법

코드 블록은 두 가지 방식으로 만들 수 있습니다.

📋
방법 1: 백틱 3개로 감싸기
코드 위·아래에 ```을 두고 첫 줄에 언어를 적습니다.
```python ~ ```
📝
방법 2: 들여쓰기 4칸
각 줄을 스페이스 4개로 들여쓰면 코드 블록으로 인식. (마크다운 전통 방식)

⚡ 변환 예시

입력 (백틱 3개)
```javascript
function hello(name) {
  // 인사 출력
  console.log("안녕, " + name);
  return 42;
}
hello("아이노트");
```
→
변환 결과 (구문 강조)
javascript function hello(name) { // 인사 출력 console.log("안녕, " + name); return 42; } hello("아이노트");

🌈 지원 언어

에디콘은 다음 언어들에 대해 자동 구문 강조(Syntax Highlighting)를 적용합니다. 언어를 명시하지 않으면 일반 코드 블록으로 표시됩니다.

분류지원 언어
웹 프론트엔드html, css, javascript(=js), typescript(=ts), jsx, vue
백엔드python, php, java, go, rust, kotlin, swift, ruby
데이터·쿼리sql, json, yaml, toml, xml, csv
셸·스크립트bash(=sh), powershell, dockerfile
마크업markdown(=md), latex, asciidoc
기타c, cpp(=c++), csharp(=c#), r, matlab, lua, perl

🛠️ 문제 해결

증상원인 & 해결
코드 블록이 안 만들어짐여는 백틱과 닫는 백틱이 짝이 안 맞음. 둘 다 정확히 ``` 3개인지 확인.
들여쓰기가 무너짐탭과 스페이스가 섞였을 수 있음. AI에게 "스페이스로만 들여쓰기 해 줘"라고 요청.
구문 강조 색이 이상함언어 식별이 잘못됨. ``` 뒤 언어 이름이 표준 이름인지 확인 (위 표 참조).
한글 주석이 깨짐드물게 UTF-8 BOM 문제. 다른 곳에서 한 번 거친 뒤 다시 붙여넣기.
