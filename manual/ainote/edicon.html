✏️ 에디콘 (EdiCon)

에디콘은 아이노트의 입력 엔진입니다. AI가 만든 텍스트를 붙여넣는 그 순간 형태를 자동으로 알아채고, URL은 카드로 · 표는 표로 · 코드는 코드블록으로 · 수식은 수식으로 · 다이어그램은 다이어그램으로 5종 자동 변환합니다.

EDICON · 5-WAY AUTO DISPATCH

🌐 클립보드의 형태를 읽어내는 엔진

붙여넣는 텍스트의 첫 줄·중간·끝을 빠르게 스캔해 — URL 패턴 / 표 구분자 / 코드 펜스 / LaTeX 기호 / Mermaid 키워드 — 다섯 가지 신호 중 어떤 것이 가장 강한지 판정합니다. 잘못된 변환이 0건이 되도록 안전망 우선순위로 설계되었습니다.

🎯 디스패치 우선순위

에디콘은 충돌이 발생할 수 있는 경우 — 예를 들어 코드 블록 안에 URL이 있는 경우 — 다음 순서로 판정합니다. 이 순서는 "가장 명확한 신호" 우선입니다.

#판정 신호예시
1️⃣URL 패턴 (http://, https://)https://kiam.kr 한 줄이 입력 전체일 때
2️⃣Mermaid 키워드 (graph, flowchart, sequenceDiagram…)```mermaid 또는 첫 줄이 flowchart TD
3️⃣LaTeX 기호 ($...$, $$...$$)본문 어딘가에 수식이 포함된 경우
4️⃣표 구분자 (탭·파이프·콤마의 일관된 행)3행 이상이 같은 개수의 구분자를 포함
5️⃣코드 펜스 (```언어)백틱 3개로 시작·끝나는 블록
💡 핵심: "표 v2 알고리즘"
에디콘 v2의 표 인식은 텍스트 전체를 스캔해 가장 긴 연속된 일관된 구분자 행을 찾습니다. 그래서 표 위·아래에 제목이나 설명 문장이 있어도 표만 깔끔하게 변환하고 나머지는 단락으로 보존합니다. 이전 버전(v1)은 첫 줄을 헤더로 가정해 실패하던 경우가 많았는데, 이제 모두 해결되었습니다.

🛡️ 안전성 보증

위협방어 방법
악성 스크립트(XSS)모든 HTML 출력은 텍스트 이스케이프 후 렌더 — <script>, onerror= 등 무력화
외부 서버 공격(SSRF)URL 미리보기는 화이트리스트 + 사설 IP 차단 + 타임아웃
잘못된 변환5종 디스패치 모두 실패 시 평범한 텍스트로 폴백 (안전망)
외부 CDN 변조Mermaid·KaTeX 라이브러리는 무결성 해시(SRI) 검증

🛠️ 개발자 도구 (콘솔 디버깅)

개발자나 고급 사용자는 브라우저 콘솔(F12)에서 에디콘 엔진을 직접 호출해볼 수 있습니다.

// 표 감지 테스트
EdiCon._test_detectTable("이름\t나이\n홍길동\t30\n임꺽정\t40");
// → { type: 'tsv', rows: [...], separator: '\t', lead: [], trail: [] }

// Mermaid 감지 테스트
EdiCon._test_detectMermaid("flowchart TD\nA --> B");
// → { type: 'mermaid', code: 'flowchart TD\nA --> B' }

// URL 카드 미리 가져오기
EdiCon._test_fetchOg("https://kiam.kr");
// → { title, description, image, ... }
🔍 각 디스패치의 상세 매뉴얼은 좌측 사이드바 또는 위의 5대 디스패치 카드에서 선택해 진입하세요. 모든 매뉴얼은 실전 예시 + 실시간 데모 + 트러블슈팅 가이드를 포함합니다.
