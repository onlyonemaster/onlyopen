📋 2장: 노트 목록 화면

로그인하면 가장 먼저 보이는 화면입니다. 내 노트들이 모두 여기에 모여 있습니다.

화면 구성

노트 목록 화면은 크게 세 부분으로 나뉩니다.

🔝
상단 바
로고, 검색창, 테마 버튼, 새 노트 버튼(+)이 있습니다.
📌
고정 노트 영역
중요한 노트를 고정(핀) 해두면 맨 위에 항상 보입니다.
📄
일반 노트 목록
최근에 수정한 순서대로 카드 형태로 노트가 나열됩니다.
🗑️
삭제된 노트 탭
삭제한 노트가 보관됩니다. 복원도 가능합니다.

노트 카드 이해하기

각 노트는 카드 형태로 보입니다. 카드에서 볼 수 있는 정보는 다음과 같습니다.

항목설명
제목노트 제목. 없으면 "(제목 없음)"으로 표시됩니다.
내용 미리보기노트 내용의 앞부분이 짧게 보입니다.
수정 시간"3분 전", "어제", "2026-05-10" 형식으로 표시됩니다.
아트콘 개수노트 안에 인포그래픽이 몇 개 있는지 숫자로 표시됩니다.
공유 아이콘공유 중인 노트에는 🔗 아이콘이 표시됩니다.

노트 검색하기

상단 검색창에 단어를 입력하면 제목과 내용에서 검색합니다.

  • 1
    검색창 클릭 후 단어 입력
    상단 검색창을 클릭하고 찾고 싶은 단어를 입력합니다. 예: "회의록"
  • 2
    결과 확인
    입력한 단어가 포함된 노트만 목록에 나타납니다. 실시간으로 필터링됩니다.
  • 3
    검색 취소
    검색창의 내용을 지우면 전체 목록이 다시 나타납니다.

새 노트 만들기

두 가지 방법으로 새 노트를 만들 수 있습니다.

➕
상단 + 버튼 클릭
화면 우측 상단의 새 노트 버튼(+)을 클릭합니다. 빈 편집 화면이 바로 열립니다.
👆
기존 노트 카드 클릭
이미 있는 노트 카드를 클릭하면 그 노트의 편집 화면으로 들어갑니다.

노트 고정(핀)하기

중요한 노트를 항상 맨 위에 보이게 고정할 수 있습니다.

  • 1
    노트 카드에서 메뉴 버튼(···) 클릭
    노트 카드 오른쪽 위에 있는 점 세 개(···) 버튼을 클릭합니다.
  • 2
    "고정하기" 선택
    메뉴에서 "고정하기"를 클릭합니다. 해당 노트가 맨 위 고정 영역으로 이동합니다.

노트 삭제 및 복원

작업방법
삭제하기 노트 카드 메뉴(···) → "삭제" 선택. 삭제된 노트 탭으로 이동합니다.
복원하기 "삭제된 노트" 탭 클릭 → 노트 카드 메뉴(···) → "복원" 선택
완전 삭제 "삭제된 노트" 탭에서 → "완전 삭제" 선택. 복원 불가능합니다!
⚠️ 완전 삭제는 되돌릴 수 없어요!
"삭제하기"는 삭제된 노트 탭에 보관되어 복원 가능합니다. 하지만 "완전 삭제"는 완전히 사라져서 되돌릴 수 없습니다. 신중하게 결정하세요.
