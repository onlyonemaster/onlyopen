🔗 URL → 카드 자동 변환

웹 주소(URL)를 노트에 붙여넣으면 에디콘이 자동으로 사이트의 제목·설명·썸네일을 가져와 OG(Open Graph) 미리보기 카드로 변환합니다. 단순한 파란 링크가 아니라 시각적으로 풍부한 카드로 바뀝니다.

📥 사용 방법

  • 1
    웹 주소 복사
    브라우저 주소창에서 URL을 복사하거나, 어떤 웹사이트의 링크를 복사합니다.
  • 2
    노트 에디터에 붙여넣기 (Ctrl+V)
    새 줄에 URL만 단독으로 붙여넣습니다. 에디콘이 URL 패턴을 감지하면 즉시 변환을 시작합니다.
  • 3
    자동 카드 생성 (1초 이내)
    웹사이트의 메타 정보(Open Graph)를 가져와 썸네일·제목·설명·도메인이 들어간 카드가 표시됩니다.

💡 잘 쓰는 팁

상황방법
URL을 그냥 텍스트로 두고 싶을 때같은 줄에 다른 글자와 함께 입력 — 단독 줄이 아니면 카드로 변환되지 않습니다.
카드를 다시 텍스트 링크로카드 위에 마우스를 올리고 "원본 보기" 클릭
썸네일이 안 보일 때일부 사이트는 OG 메타데이터를 제공하지 않습니다. 기본 아이콘으로 표시됩니다.
여러 URL을 한꺼번에각 URL을 줄바꿈으로 구분해 붙여넣으면 모두 개별 카드로 변환됩니다.
변환이 너무 오래 걸릴 때3초 후 자동으로 일반 링크로 폴백됩니다. 외부 사이트가 느린 경우.
⚡ 성능: 콜드 캐시 약 128ms · 워밍업 후 약 52ms. 같은 URL은 1시간 동안 캐시되어 즉시 표시됩니다.

🛡️ 안전성 (SSRF 방어)

외부 URL을 미리 가져오는 기능은 잘못 만들면 SSRF(Server-Side Request Forgery)라는 공격에 취약합니다. 에디콘은 다음과 같이 방어합니다.

위협방어
사설 IP 접근 (10.x, 192.168.x, 127.0.0.1)DNS 결과를 사전 검증해 사설 대역 차단
localhost 우회호스트명 화이트리스트 + IPv4·IPv6 별칭 차단
30x 리디렉션 우회리디렉션마다 재검증 (최대 3회까지만 허용)
거대 응답 폭탄10MB 초과 또는 5초 초과 시 즉시 중단
악성 콘텐츠 타입HTML·이미지·비디오 외 거부

🛠️ 문제 해결

증상원인 & 해결
카드가 안 생기고 그냥 링크로 남음같은 줄에 다른 글자가 있는 경우. 새 줄에 URL만 단독으로 붙여넣기.
썸네일이 깨져서 보임외부 사이트가 OG 이미지를 더 이상 제공하지 않음. 기본 아이콘으로 자동 폴백.
"불러올 수 없습니다" 메시지외부 사이트가 차단되었거나 응답하지 않음. 단순 링크로 표시됨.
YouTube 썸네일이 검은 화면비공개·삭제된 영상이거나 지역 제한. URL을 확인하세요.
