📐 다이어그램 (Mermaid 19종)

에디콘은 19종의 Mermaid 다이어그램을 자동으로 감지해 실시간 SVG로 렌더링합니다. 흐름도·시퀀스·클래스·ER·간트·마인드맵·타임라인 등 — AI가 만들어준 다이어그램 코드를 그대로 붙여넣기만 하면 즉시 시각화됩니다. 이 페이지의 모든 다이어그램은 실제로 작동하는 라이브 데모입니다.

📥 사용 방법

두 가지 방식 모두 자동 감지됩니다.

📋
방법 1: 코드 펜스
```mermaid로 시작하고 ```로 닫기. AI가 가장 자주 만드는 형식.
🪄
방법 2: 바로 입력
첫 줄이 flowchart TD, sequenceDiagram 같은 키워드면 펜스 없이도 자동 인식.

⚡ 첫 예시 — 흐름도

붙여넣은 텍스트
```mermaid
flowchart LR
  A[시작] --> B{조건?}
  B -->|예| C[작업1]
  B -->|아니오| D[작업2]
  C --> E[종료]
  D --> E
```
→
렌더링 결과 (실제 동작)
flowchart LR A[시작] --> B{조건?} B -->|예| C[작업1] B -->|아니오| D[작업2] C --> E[종료] D --> E

🎬 라이브 데모 — 6종 주요 다이어그램

아래 모든 다이어그램은 실제로 이 페이지에서 렌더링되고 있습니다. 코드를 복사해서 노트에 붙여넣으면 똑같이 작동합니다.

1. 시퀀스 다이어그램 sequenceDiagram

sequenceDiagram
  participant 사용자
  participant 에디터
  participant AI
  사용자->>에디터: 표 붙여넣기
  에디터->>AI: 형식 분석
  AI-->>에디터: 표 인식 완료
  에디터-->>사용자: HTML 테이블 표시
sequenceDiagram participant 사용자 participant 에디터 participant AI 사용자->>에디터: 표 붙여넣기 에디터->>AI: 형식 분석 AI-->>에디터: 표 인식 완료 에디터-->>사용자: HTML 테이블 표시

🤖 AI에게 Mermaid 요청하기

ChatGPT·DeepSeek에게 다음과 같이 요청하면 Mermaid 코드로 답변합니다.

프롬프트 예시:
"우리 회사의 고객 응대 프로세스를 Mermaid flowchart로 그려 줘. ```mermaid 코드 블록으로 감싸서."

AI가 코드를 돌려주면 그대로 노트에 붙여넣기 — 자동 렌더링됩니다.

💡 잘 쓰는 팁

상황방법
다이어그램 방향 바꾸기flowchart LR(가로) / TD(위→아래) / BT(아래→위) / RL(가로 역방향)
한글 라벨 사용대부분 OK. 노드 ID는 영문, 라벨에만 한글 권장: A[작업 시작]
다이어그램 크기 조절노트 너비에 자동 맞춤. 모바일에서도 가로 스크롤로 보임.
소스 보기다이어그램 위에 마우스 → "소스보기" 버튼 → Mermaid 코드 표시
다이어그램 → 인포그래픽"🎨 아트콘으로 변환" → ArtCon이 다이어그램을 컬러풀하게 재해석
🎨 다이어그램 → ArtCon 연동
Mermaid 다이어그램을 아트콘(ArtCon)으로 보내면 더 풍부한 색상·스타일의 인포그래픽으로 다시 만들 수 있습니다. 표준 SVG보다 마케팅·발표에 적합한 결과물이 나옵니다.

🛠️ 문제 해결

증상원인 & 해결
다이어그램이 렌더링 안 됨첫 줄이 19개 키워드 중 하나로 시작해야 함. 예: flowchart TD
"Syntax error in graph"코드에 오타. 노드 ID가 중복되거나 화살표(-->)가 잘못된 경우 많음.
한글이 깨짐드물게 라벨 안에 특수문자(괄호·따옴표)가 있을 때. 라벨을 따옴표로 감싸기: A["라벨 (1)"]
너무 복잡한 다이어그램50노드 넘으면 가독성 저하. 더 작게 나눠 여러 다이어그램으로.
모바일에서 너무 작음핀치 줌으로 확대. 또는 다이어그램 우상단 ⛶ 클릭해 전체화면.
