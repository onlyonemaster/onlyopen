🚀 1장: 처음 시작하기

아이노트에 처음 접속하고 로그인하는 방법을 안내합니다. 딱 3단계면 됩니다!

① 아이노트 접속하기

웹 브라우저를 열고 주소창에 아래 주소를 입력하세요.

https://ainote.kiam.kr
💡 어떤 브라우저도 괜찮아요!
크롬, 엣지, 사파리, 파이어폭스 모두 사용할 수 있습니다. 스마트폰으로도 접속할 수 있습니다.

② 로그인하기

접속하면 로그인 화면이 나타납니다. 두 가지 방법으로 로그인할 수 있습니다.

  • 방법 1
    구글(Google) 계정으로 로그인
    "구글로 로그인" 버튼을 클릭합니다.
    평소 쓰는 구글 계정을 선택하면 바로 로그인됩니다.
    가장 빠르고 편한 방법입니다!
  • 방법 2
    이메일 회원가입 후 로그인
    이메일 주소와 비밀번호를 입력해서 회원가입합니다.
    이메일 인증 링크가 발송됩니다 → 이메일 확인 후 인증 클릭 → 로그인 가능

③ 첫 화면 살펴보기

로그인하면 노트 목록 화면이 나타납니다. 처음엔 노트가 없어서 빈 화면이 보여요.

📋
노트 목록 (가운데)
내가 만든 노트들이 카드 형태로 나열됩니다. 처음엔 비어 있습니다.
➕
새 노트 버튼
화면 우측 상단에 있습니다. 클릭하면 새 노트 편집 화면이 열립니다.
🔍
검색창
노트 제목이나 내용으로 검색할 수 있습니다.
🌈
테마 버튼
상단에 있습니다. 클릭하면 화면 색상(테마)이 바뀝니다.

첫 번째 노트 만들어 보기

이제 첫 번째 노트를 만들어 봅시다!

  • 1
    우측 상단 새 노트 버튼 클릭
    버튼을 클릭하면 편집 화면이 열립니다.
  • 2
    제목 입력하기
    화면 위쪽에 "노트 제목" 자리에 원하는 제목을 입력하세요. 예: "오늘 공부한 내용"
  • 3
    내용 입력하기
    제목 아래 흰 공간에 내용을 마음껏 입력하세요. 3초 후 자동으로 저장됩니다!
  • 4
    ← 뒤로 버튼으로 목록으로 돌아가기
    상단 뒤로가기 버튼을 누르면 목록으로 돌아갑니다. 방금 만든 노트가 목록에 나타납니다!
