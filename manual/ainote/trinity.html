🔱 콘-트리니티 (Con-Trinity)

아이노트의 심장에는 세 개의 콘(Con)이 있습니다 — 에디콘(EdiCon), 아트콘(ArtCon), 브리콘(BriCon). 셋은 따로 작동하지만 함께일 때 비로소 완벽한 노트 사이클을 만들어냅니다. 이것이 콘-트리니티입니다.

🌍 왜 "트리니티"인가요?

대부분의 노트 앱은 입력(에디터)만 잘합니다. 일부는 변환(렌더링)을 잘하고, 또 일부는 공유(브리핑)에 강점이 있습니다. 하지만 이 셋을 하나의 노트 안에서 매끄럽게 연결한 시스템은 지구상에 없었습니다.

아이노트는 EdiCon · ArtCon · BriCon을 세 개의 동등한 기둥으로 설계해, 하나의 노트가 입력 → 변환 → 발표 단계를 한 번도 끊기지 않고 흐르도록 만들었습니다. 그래서 "트리니티(三位一體)"입니다.

🎯 세 콘(Con)의 역할

STEP 1 · INPUT
✏️
에디콘 (EdiCon)
Editor Engine · 입력 인식
AI가 쏟아낸 텍스트(URL·표·코드·수식·다이어그램)를 붙여넣는 순간 자동으로 인식해 깔끔하게 정돈된 블록으로 만듭니다. 5종 자동 디스패치 · 210/210 시뮬레이션 통과.
STEP 2 · TRANSFORM
🎨
아트콘 (ArtCon)
Art Engine · 시각화
정돈된 텍스트를 예술 작품 수준의 HTML 인포그래픽으로 다시 만듭니다. SuperAI + 4단계 안전망. 5가지 테마 실시간 전환. 특허 출원 완료.
STEP 3 · DELIVER
📊
브리콘 (BriCon)
Briefing Engine · 전달
노트 한 편을 발표 가능한 브리핑 문서로 자동 구성합니다. 투자자 자료 · 인적자원 분석 · 요약 카드. 공유 링크로 누구든 즉시 열람 가능.

🔄 트리니티 사이클

세 콘은 일방향이 아니라 순환합니다. 브리콘으로 만든 결과를 다시 에디콘에 붙여넣으면 새로운 입력이 되고, 아트콘이 또 다른 시각화를 만들어냅니다. 노트는 끊임없이 발전합니다.

🎬 실전 시나리오 — 트리니티는 이렇게 작동합니다

시나리오 1 · 📊 "SuperAI에게 시장 분석을 받았다"

AI가 만든 TSV 표 · 막대그래프 다이어그램 · 요약 텍스트를 한 번에 복사해 노트에 붙여넣었습니다.

1. EdiCon표를 자동 인식해 깔끔한 m-table로 변환. 다이어그램은 Mermaid 블록으로 자동 렌더링.
2. ArtCon"아트콘으로 변환" 클릭 → 표·그래프가 컬러 인포그래픽으로 통합 시각화.
3. BriCon"브리핑 생성" → 발표용 슬라이드 카드 자동 생성. 공유 링크로 임원진에게 전달.

시나리오 2 · ✍️ "투자자에게 보낼 사업계획 초안을 만든다"

사업계획 텍스트와 SWOT 분석표를 ChatGPT에서 받아왔습니다.

1. EdiCon제목·소제목·표·체크리스트를 자동 식별. 마크다운 단축 입력으로 직접 작성도 가능.
2. ArtConSWOT 표를 4분면 인포그래픽으로 변환. 5가지 테마 중 "딥플로트"로 시연.
3. BriCon60페이지 투자자 브리핑 자동 구성. 공유 링크 즉시 발송.

시나리오 3 · 👥 "팀에 공유할 학습 자료를 만든다"

DeepSeek에게 받은 학습 흐름도(Mermaid)와 핵심 개념 표를 노트에 정리합니다.

1. EdiConMermaid 코드를 자동 감지해 실제 다이어그램으로 렌더링. URL은 OG 카드로 변환.
2. ArtCon전체 노트를 학습용 인포그래픽으로 변환. 다크 테마로 시각화.
3. BriCon학습 카드 모음으로 자동 정렬. 공유 링크를 팀 채팅에 게시.

🤔 왜 이 사이클이 중요한가요?

전통적 노트 앱아이노트 (콘-트리니티)
AI가 만든 표를 그대로 텍스트로 붙임 → 읽기 어려움 EdiCon이 표·코드·수식·다이어그램을 모두 자동 인식·렌더링
예쁘게 만들려면 외부 도구(Canva, PowerPoint)로 다시 작업 ArtCon이 노트 안에서 바로 예술 인포그래픽 생성
발표용으로 만들려면 또 다른 도구(슬라이드)로 옮김 BriCon이 발표용 브리핑을 한 클릭으로 생성
도구 3개 · 파일 3개 · 학습 시간 N시간 노트 한 편 · 도구 하나 · 학습 시간 30분
💡 핵심 통찰
AI가 만들어내는 콘텐츠는 그 자체로는 "덜 다듬어진 원석"입니다. 콘-트리니티는 그 원석을 EdiCon으로 깎고 · ArtCon으로 광내고 · BriCon으로 진열장에 올리는 일관된 시스템입니다.

🚀 트리니티 시작하기

이제 세 개의 콘을 차례로 만나보겠습니다. 각 매뉴얼은 약 5~10분이면 충분합니다.

1
✏️ 에디콘(EdiCon) 매뉴얼
5대 자동 디스패치 — URL · 표 · 코드 · 수식 · 다이어그램이 어떻게 자동 변환되는지 확인합니다.
2
🎨 아트콘(ArtCon) 매뉴얼
아트콘 — 텍스트를 예술 인포그래픽으로 변환하는 세계 최초 기능을 익힙니다.
3
📊 브리콘(BriCon) 매뉴얼
노트를 발표 가능한 브리핑·인포카드로 만드는 방법을 배웁니다.
