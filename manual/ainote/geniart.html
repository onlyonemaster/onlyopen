🎨 아트콘 (ArtCon) — AI 인포그래픽

아트콘(ArtCon)은 콘-트리니티의 "꽃"입니다. 텍스트(표·흐름도·다이어그램)를 AI가 예술 수준의 HTML 인포그래픽으로 자동 변환합니다. Notion·에버노트·MS Teams·네이버 메모 어디서도 구현하지 못한 세계 최초 기능입니다.

🎨 NAMING UNIFICATION · 명칭 통합 (2026-05)
옛 이름 "지니아트(GeniArt)" → 새 이름 "아트콘 (ArtCon)"
2026년 5월 콘-트리니티(에디콘·아트콘·브리콘) 체계 도입과 함께 "지니아트(GeniArt)"는 공식적으로 "아트콘(ArtCon)"으로 명칭이 통합되었습니다. 동일한 엔진·동일한 기능이며 URL(/manual/ainote/geniart.html)과 데이터베이스 슬러그(geniart)는 호환성을 위해 그대로 유지됩니다. 이전 자료에서 "지니아트"라고 표기된 부분이 보이면 모두 "아트콘"으로 읽어 주세요.

🌍 왜 세계 최초인가요?

전 세계 수천만 명이 사용하는 Notion, 에버노트, MS Teams 메모, 네이버 메모 — 이 모든 서비스들이 텍스트를 자동으로 예쁜 인포그래픽으로 바꿔주는 기능을 구현하지 못했습니다. 아이노트는 SuperAI와 독자적인 4단계 안전망 기술을 결합해 이 불가능했던 기능을 세계 최초로 구현했습니다. 특허 출원 완료된 독점 기술입니다.

아트콘이란?

ChatGPT나 SuperAI 같은 AI에게 무언가를 물어보면, AI가 종종 텍스트로 된 표·흐름도·다이어그램을 만들어줍니다. 이런 텍스트들을 보통 그냥 복사해서 노트에 붙여넣으면 예쁘지 않고 읽기도 불편합니다.

아트콘은 이 텍스트를 자동으로 아름다운 인포그래픽 그림으로 바꿔줍니다!

지원하는 콘텐츠 유형
• AI 생성 표 (ASCII 테이블)
• 흐름도 (Flow chart)
• 다이어그램
• 단계별 프로세스
• 비교 분석표

🎨
변환 결과
• 완전한 HTML 인포그래픽
• 5가지 테마 자동 지원
• 반응형 (PC·모바일 모두)
• 원본 내용 100% 보존
• 재변환(↻) 가능
• 원본 텍스트 보기 전환

사용 방법

아주 간단합니다. 딱 3단계입니다!

  • 1
    AI에서 텍스트 복사하기
    ChatGPT, SuperAI, Claude 등 AI에게 질문해서 표나 다이어그램을 받은 후, 그 내용을 전체 선택(Ctrl+A)해서 복사(Ctrl+C)합니다.

    예: "마케팅 전략을 표로 정리해줘"라고 AI에게 물어보고, 받은 표를 복사
  • 2
    아이노트 에디터에 붙여넣기 (Ctrl+V)
    아이노트 편집 화면을 열고 에디터 안에 붙여넣습니다 (Ctrl+V).
    시스템이 AI가 만든 텍스트를 자동으로 감지합니다.
  • 3
    팝업에서 "아트콘으로 변환" 클릭
    "이 내용을 AI 인포그래픽으로 변환할까요?" 팝업이 나타납니다.
    "변환" 버튼을 클릭하면 AI가 자동으로 인포그래픽을 만들어줍니다.
    변환이 완료되면 텍스트가 아름다운 인포그래픽으로 바뀌어 있습니다! 🎉
⏱ 변환 시간은 약 10~30초 정도 걸립니다.
AI가 내용을 분석하고 디자인하는 시간이 필요합니다. 변환 중에 ↻ 버튼 옆에 스피너(로딩 표시)가 보입니다.
🔗 에디콘(EdiCon) ↔ 아트콘(ArtCon) 연동
에디콘이 만든 Mermaid 다이어그램·표·수식도 아트콘으로 다시 변환할 수 있습니다. 에디콘이 형식을 잡고, 아트콘이 예술을 더하는 구조입니다. 두 엔진을 함께 쓰면 결과 품질이 극대화됩니다.

아트콘 4단계 안전망 (내부 작동 원리)

아트콘은 단순히 AI에 한 번 물어보는 게 아닙니다. 4단계 안전망을 거쳐 최고 품질의 인포그래픽을 만들어냅니다.

1단계
🤖
AI 1차 생성
SuperAI가 원본 텍스트를 분석해 HTML 인포그래픽 초안을 만듭니다
2단계
🔧
자동 변수화
고정된 색상 코드를 CSS 변수로 자동 변환. 5가지 테마 지원을 위해 필요합니다
3단계
🔍
색상 검수
고정 색상이 5개를 넘으면 자동으로 3단계 AI 재검수 호출
4단계
✅
테마 주입
5가지 테마 CSS 변수와 테마 전환 스크립트를 최종 삽입해 완성

테마 색상 변수 시스템

완성된 인포그래픽은 5가지 테마 CSS 변수를 모두 포함합니다. 테마가 바뀌면 인포그래픽도 자동으로 함께 바뀝니다!

🌙 다크
📘 클래식
🌊 딥플로트
🌈 그래디언트
🍂 웜

재변환하기 (↻ 버튼)

변환 결과가 마음에 들지 않거나, 다시 생성하고 싶을 때는 재변환을 사용합니다.

  • 1
    인포그래픽 위에 마우스를 올리기
    인포그래픽에 마우스를 가져가면 위쪽에 작은 바(bar)가 나타납니다.
  • 2
    ↻ (재변환) 버튼 클릭
    버튼 옆에 "AI 변환 중..." 표시가 나타나며 재변환이 시작됩니다.
  • 3
    새 인포그래픽 확인
    약 10~30초 후 새로운 디자인의 인포그래픽이 완성됩니다. AI가 매번 조금씩 다른 디자인으로 만들어줍니다!

아트콘 탭 전환

인포그래픽 위에 마우스를 올리면 두 개의 탭이 나타납니다.

🎨
아트콘 탭
AI가 만든 인포그래픽이 보입니다. 기본값입니다.
📄
원본 탭
원래 텍스트가 그대로 보입니다. 내용을 확인하거나 복사할 때 사용합니다.
🔒 원본은 항상 보존됩니다!
아트콘으로 변환해도 원래 텍스트는 삭제되지 않습니다. 언제든지 "원본" 탭에서 확인할 수 있습니다. 재변환도 원본 텍스트를 기반으로 새로 만드는 것입니다.

아트콘 잘 쓰는 팁

상황방법
결과가 마음에 안 들 때 ↻ 버튼으로 재변환. 매번 다른 디자인이 나옵니다.
텍스트 내용을 확인하고 싶을 때 "원본" 탭 클릭
인포그래픽이 너무 좁을 때 자동으로 내용 길이에 맞게 높이가 조절됩니다.
테마와 함께 보고 싶을 때 상단 테마 버튼으로 테마를 바꾸면 인포그래픽도 함께 바뀝니다.
더 좋은 결과를 원할 때 AI에게 더 명확하게 구조화된 내용을 받은 후 붙여넣어 보세요.
