퀵스타트 — 4단계로 시작

1
회원가입 & 로그인

vg.kiam.kr에서 무료 회원가입. 이메일 인증 후 대시보드 접속

2
API 키 발급

대시보드 → API 키 관리에서 키 생성. 무료 플랜은 월 10,000자 제공

3
API 호출

Authorization 헤더에 Bearer 키를 넣고 POST /api/v1/generate 호출

4
데모로 먼저 체험

회원가입 없이도 vg.kiam.kr 메인에서 200자까지 무료 체험 가능
