음성 클로닝

본인 목소리가 담긴 WAV 파일을 업로드하면 AI가 그 음색을 학습해
비슷한 목소리로 음성을 합성합니다. Basic 플랜 이상에서 사용 가능합니다.

📌 지원 플랜: Basic · Pro · Enterprise
Free 플랜은 기본 음성 프리셋만 사용 가능합니다. → 플랜 업그레이드

참조 음성 파일 조건

클로닝 품질은 업로드하는 참조 파일의 품질에 직접 영향받습니다.

항목권장 사양
파일 형식WAV (권장) · MP3 · OGG · FLAC · M4A
길이10초 ~ 2분 (30초~1분이 최적)
샘플링 레이트22,050Hz 이상 (44,100Hz 권장)
파일 크기최대 30MB
배경 소음최대한 없을 것 (조용한 실내 녹음 권장)
발화 내용자연스럽게 읽은 문장. 긴 침묵 구간 없어야 함
⚠ 클로닝 품질에 영향을 주는 요소
· 배경 소음이 있으면 클로닝 품질이 크게 저하됩니다
· 10초 미만 파일은 특징을 충분히 학습하지 못합니다
· 노래·감정이 격한 목소리보다 평상시 말하는 목소리가 적합합니다

사용 방법

1
음성 클로닝 페이지 접속

vg.kiam.kr/clone.php 접속
또는 대시보드 상단 음성 클로닝 메뉴 클릭

2
참조 음성 파일 업로드

파일 업로드 영역에 WAV 파일을 드래그하거나 클릭하여 선택

3
변환할 텍스트 입력

클로닝된 목소리로 읽을 텍스트를 입력합니다

4
음성 생성

🎤 클로닝 음성 생성 버튼 클릭 → 수 초 내에 결과가 출력됩니다

API로 클로닝 호출하기

curl -X POST https://vg.kiam.kr/api/v1/clone   -H "Authorization: Bearer YOUR_API_KEY"   -F "text=안녕하세요. 클로닝 테스트입니다."   -F "audio_file=@/path/to/my_voice.wav"   -F "speed=1.0"   --output cloned_output.wav
⚠ 음성 클로닝 이용 약관
· 본인 또는 사용 허가를 받은 목소리만 업로드할 수 있습니다
· 타인의 목소리를 무단 복제하는 것은 법적으로 금지됩니다
· 생성된 음성을 사기·사칭 목적으로 사용하는 것은 금지됩니다
