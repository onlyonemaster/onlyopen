자주 묻는 질문 (FAQ)

VoiceGen AI 사용 중 자주 받는 질문들을 모았습니다.

Q. 생성된 음성 품질이 좋지 않아요.
  • 구두점·띄어쓰기가 정확할수록 자연스럽게 읽습니다
  • 영어 텍스트에는 영어 음성(en_female_1·en_male_1)을 사용하세요
  • @ # 등 특수문자는 제거하고 텍스트만 입력하세요
  • 용도에 맞는 음성을 선택하세요 → 음성 프리셋 목록
Q. API 호출 시 401 오류가 납니다.
  • 요청 헤더에 Authorization: Bearer YOUR_API_KEY가 포함됐는지 확인
  • API 키가 정확히 복사됐는지 확인 (앞뒤 공백 주의)
  • 대시보드에서 해당 키가 활성 상태인지 확인
Q. 429 오류가 납니다.

월 사용량 한도를 초과했습니다.
대시보드에서 현재 사용량을 확인하고, 계속 사용하려면 플랜을 업그레이드하세요.
→ 요금제 안내

Q. 음성 생성에 시간이 오래 걸려요.

텍스트 길이에 따라 처리 시간이 달라집니다:

  • 100자 이하: 약 2~4초
  • 100~500자: 약 5~15초
  • 500자 이상: 약 15~30초

Pro 플랜은 우선 처리 큐가 적용되어 더 빠르게 처리됩니다.

Q. 음성 클로닝 결과가 원래 목소리와 많이 달라요.
  • 조용한 환경에서 녹음한 파일 사용 (배경 소음 최소화)
  • 30초~1분 분량이 최적입니다
  • WAV 형식, 44,100Hz 권장
  • 긴 침묵 구간 없이 자연스럽게 읽은 문장 사용
→ 음성 클로닝 상세 가이드
Q. 이메일 인증 메일이 오지 않아요.
  1. 스팸(정크) 메일함 확인
  2. 이메일 주소 오타 여부 확인
  3. 5분 이상 기다려도 오지 않으면 로그인 페이지에서 재발송 요청
Q. 생성된 음성을 상업적으로 사용해도 되나요?

유료 플랜(Basic 이상) 가입자는 생성된 음성을 상업적 목적으로 사용할 수 있습니다.
Free 플랜은 개인·비상업적 용도에 한해 사용 가능합니다.

Q. 한국어 이외의 언어도 지원하나요?

현재 한국어·영어를 기본 지원합니다.
OpenAI TTS·Google Cloud TTS·ElevenLabs 엔진을 관리자에서 선택하면 더 많은 언어를 지원합니다.

Q. API 키를 분실했어요.

대시보드 → API 키 관리에서 기존 키를 삭제하고 새 키를 발급받으세요.
기존 키로 연동된 서비스가 있다면 새 키로 교체해 주세요.

Q. 서버 오류(500)가 계속 발생합니다.

일시적인 서버 부하로 발생할 수 있습니다. 잠시 후 다시 시도해 주세요.
지속적으로 발생하면 고객센터로 문의해 주세요.
