회원가입 & 로그인

VoiceGen AI를 사용하려면 vg.kiam.kr에 회원가입이 필요합니다.
가입 즉시 무료 플랜이 활성화되며 API 키를 발급받을 수 있습니다.

1. 회원가입

1
사이트 접속

https://vg.kiam.kr/signup.php 접속 또는
메인 화면 오른쪽 상단 무료 시작 버튼 클릭

2
정보 입력

이름, 이메일 주소, 비밀번호 입력 후 회원가입 클릭
이메일은 실제 사용 중인 주소여야 합니다 (인증 메일 발송)

3
이메일 인증

가입한 이메일로 발송된 인증 메일에서 이메일 인증하기 링크 클릭
스팸함도 확인해 주세요

4
로그인 완료

로그인 페이지에서 이메일·비밀번호 입력 → 대시보드로 이동

💡 이미 kiam.kr 회원이신가요?
VoiceGen AI(vg.kiam.kr)는 kiam.kr과 별도 계정 시스템입니다. 신규 가입이 필요합니다.

API 키 발급

음성 생성 API를 호출하려면 API 키가 필요합니다.

1
대시보드 접속

로그인 후 대시보드로 이동

2
API 키 생성

하단 API 키 관리 섹션 → + 새 키 생성 버튼 클릭
키 이름을 입력하면 즉시 발급됩니다

3
키 보관

⚠ 중요 API 키는 한 번만 전체가 표시됩니다.
복사 버튼으로 즉시 복사하여 안전한 곳에 보관하세요

⚠ API 키 보안 주의
API 키는 외부에 노출되면 무단 사용될 수 있습니다. 클라이언트 사이드 JS 코드에 직접 넣지 마세요. 서버 사이드(PHP, Node.js 등)에서만 사용하거나 환경변수로 관리하세요.

사용량 & 플랜 확인

대시보드 상단에서 이번 달 사용량과 남은 잔여 글자 수를 실시간으로 확인할 수 있습니다.
월 사용 한도 도달 시 API 호출이 429 Too Many Requests로 응답됩니다.
