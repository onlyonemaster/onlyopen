플랜 업그레이드 방법

1

토스페이먼츠로 카드 결제. 매월 자동 갱신됩니다

사용량 확인 방법

대시보드에서 이번 달 사용 현황을 확인할 수 있습니다.

  • 사용한 글자 수: 이번 달 누적 사용량
  • 남은 글자 수: 이번 달 잔여 사용량
  • 사용량 게이지: 한도 대비 사용 비율
  • 최근 사용 내역: 최근 20건의 API 호출 기록
⚠ 한도 초과 시 동작
월 사용량이 한도에 도달하면 429 Too Many Requests가 반환됩니다.
매월 1일 0시에 사용량이 초기화됩니다.
초기화 전에 계속 사용하려면 플랜을 업그레이드하세요.

결제 취소 & 환불

결제 취소는 결제일로부터 7일 이내 고객센터 문의 시 전액 환불됩니다.
구독 해지 시 다음 결제일부터 과금이 중단되며, 현재 주기는 끝까지 사용 가능합니다.
