음성 프리셋 목록

VoiceGen AI는 한국어 4종·영어 2종의 기본 음성 프리셋을 제공합니다.
API 호출 시 voice_id 파라미터로 원하는 음성을 선택할 수 있습니다.

한국어 음성

voice_id이름성별특징추천 용도
ko_female_1수아여성밝고 명랑한 톤. 친근하고 에너지 넘치는 느낌앱 안내, 알림, 고객 응대
ko_male_1민준남성신뢰감 있고 안정적인 목소리뉴스 읽기, 설명 영상, 오디오북
ko_female_2지은여성전문적이고 차분한 톤. 명확한 발음기업 ARS, 프레젠테이션
ko_male_2준서남성활기차고 역동적인 목소리광고, 마케팅, 스포츠 콘텐츠

영어 음성

voice_id이름성별특징추천 용도
en_female_1Emma여성따뜻하고 친근한 미국식 영어영어 학습, 글로벌 서비스
en_male_1James남성전문적이고 명확한 비즈니스 영어기업 프레젠테이션, 해외 마케팅

기본값

API 호출 시 voice_id를 생략하면 ko_female_1(수아)가 기본 적용됩니다.

// voice_id 생략 시 ko_female_1 자동 적용
{"text": "안녕하세요."}

// 명시적으로 지정
{"text": "안녕하세요.", "voice_id": "ko_male_1"}

음성 추가 요청
