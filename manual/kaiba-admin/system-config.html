AI 자동 해결

시스템 이슈 발생 시 AI가 자동으로 원인을 분석하고 해결을 시도하는 기능입니다.

  • 1
    자동 감지
    헬스체크에서 이상 감지 시 AI가 자동으로 문제 원인을 분석합니다.
  • 2
    해결 제안
    분석 결과를 바탕으로 해결 방법을 제안합니다. (큐 클리어, 연결 재설정, 캐시 삭제 등)
  • 3
    자동 실행
    "자동 해결" 모드 ON 시 관리자 승인 없이 안전한 작업(캐시 클리어, 큐 재처리 등)을 자동 수행합니다.
  • 4
    결과 보고
    수행된 작업 내역과 결과가 로그에 기록되며, 관리자에게 알림이 발송됩니다.
⚠️ 주의: AI 자동 해결은 안전한 범위의 작업만 수행합니다. DB 스키마 변경, 서비스 재시작 등 위험 작업은 반드시 관리자 승인이 필요합니다.
