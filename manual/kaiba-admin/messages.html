메시지 관리 (Messages)

발송 메시지 내역 조회, 예약 발송, 템플릿 관리, 발송 통계를 제공하는 메시지 운영 페이지입니다.

📌 접속 경로: 좌측 메뉴 → "메시지 관리" 클릭합니다.

화면 구성

탭설명
발송 내역전체 메시지 발송 이력 (성공/실패/대기)
예약 발송미래 특정 시점에 발송 예약된 메시지 관리
템플릿재사용 가능한 메시지 템플릿 라이브러리
통계발송 성과 분석 (개봉율, 클릭율 등)

발송 내역

컬럼설명
발송 시각메시지가 발송된 날짜/시간
수신자메시지 수신 대상 (개인 또는 그룹명)
채널발송 채널 (카카오/SMS/이메일/웹푸시)
제목메시지 제목 또는 첫 줄 미리보기
상태성공 ✅ / 실패 ❌ / 대기 ⏳
작업상세보기 / 재발송 / 삭제

예약 발송

  • 1
    예약 생성
    "새 예약" 버튼 → 수신 대상 선택 → 메시지 작성 → 발송 일시 설정 → 저장
  • 2
    대상 설정
    개별 선택, 그룹(태그) 선택, 조건 기반 선택(플랜별, 활동 기간별 등)이 가능합니다.
  • 3
    반복 설정
    1회 / 매일 / 매주 / 매월 반복 발송 스케줄을 설정할 수 있습니다.
  • 4
    예약 수정/취소
    발송 전까지 내용 수정, 일시 변경, 취소가 가능합니다.

템플릿 관리

자주 사용하는 메시지를 템플릿으로 저장하여 빠르게 재사용합니다.

기능설명
템플릿 생성제목, 본문, 변수({{이름}}, {{플랜}} 등) 포함 메시지 작성
카테고리 분류환영/안내/마케팅/알림/경고 등 유형별 분류
변수 치환발송 시 수신자 정보로 자동 치환되는 변수 삽입
미리보기변수 치환 후 최종 메시지 형태 확인
승인 관리카카오 알림톡 등 사전 승인 필요 채널의 승인 상태 관리

사용 가능한 변수

변수치환 값
{{이름}}수신자 이름
{{회사}}수신자 회사명
{{플랜}}현재 구독 플랜명
{{만료일}}구독 만료 예정일
{{사용량}}현재 월 사용량
{{링크}}커스텀 URL (추적 코드 자동 부여)

발송 통계

지표설명
발송 수총 발송 건수
도달율실제 수신자에게 도달한 비율
개봉율메시지를 열어본 비율 (이메일/카카오)
클릭율메시지 내 링크 클릭 비율
수신 거부수신 거부 처리된 수
💡 팁: 발송 실패가 반복되는 수신자는 연락처 정보(전화번호, 이메일)를 확인하세요. 카카오 알림톡은 템플릿 사전 승인이 필수이므로 신규 템플릿은 2~3일 여유를 두고 등록하세요.
