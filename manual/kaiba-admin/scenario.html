시나리오 관리 (Scenario Manager)

시나리오 기반 대화 캠페인을 생성·관리하고, 성과 지표를 분석하는 페이지입니다.

📌 접속 경로: 좌측 메뉴 → "시나리오 관리" 클릭 또는 /admin/onechat_scenario_manager.php에 직접 접속합니다.

시나리오 KPI 패널

페이지 상단에 4개의 핵심 성과 지표 카드가 표시됩니다.

시나리오 개념

시나리오는 챗봇이 사용자와의 대화에서 미리 설계된 흐름을 따라 특정 목표(구매 전환, 정보 수집, 상담 연결 등)로 유도하는 구조화된 대화 캠페인입니다.

시나리오 구성 요소

요소설명
트리거시나리오가 시작되는 조건 (키워드, 시간, 사용자 행동 등)
스텝순차적으로 진행되는 대화 단계 (질문 → 응답 → 분기)
분기 조건사용자 응답에 따라 다른 경로로 이동하는 조건
목표시나리오의 최종 전환 목표 (구매, 예약, 문의 등)
폴백예상 외 응답 시 대응 메시지 및 재시도 로직

시나리오 생성

  • 1
    새 시나리오 생성
    우측 상단 "+ 새 시나리오" 버튼 클릭 → 시나리오 편집기 진입
  • 2
    기본 정보 설정
    시나리오 이름, 설명, 대상 봇, 트리거 조건을 입력합니다.
  • 3
    스텝 설계
    대화 흐름의 각 스텝을 순서대로 추가합니다. 각 스텝에 봇 메시지, 사용자 응답 옵션, 분기 조건을 설정합니다.
  • 4
    목표 및 폴백 설정
    전환 목표(최종 도달점)와 예외 상황 대응(폴백 메시지)을 설정합니다.
  • 5
    테스트 및 활성화
    "시뮬레이션" 버튼으로 테스트 → 정상 확인 후 "활성화" 토글 ON → 실서비스 적용

통계 분석

각 시나리오의 "통계" 버튼 클릭 시 상세 성과 분석 모달이 표시됩니다.

분석 항목설명
퍼널 분석각 스텝별 진행률 (어디서 이탈하는지 시각화)
전환 추세일별/주별 전환율 추이 차트
평균 소요시간시나리오 시작~완료까지 평균 시간
이탈 지점사용자가 가장 많이 이탈하는 스텝 하이라이트
A/B 비교동일 시나리오의 변형 버전 간 성과 비교

관리 작업

작업설명
복제기존 시나리오를 복사하여 새 시나리오로 생성 (변형 테스트에 유용)
A/B 테스트두 시나리오를 동시 실행하여 성과 비교
일시 정지실행 중인 시나리오를 일시 정지 (진행 중 대화는 완료까지 유지)
아카이브더 이상 사용하지 않는 시나리오를 보관함으로 이동
💡 팁: 전환율이 낮은 시나리오는 퍼널 분석에서 이탈 지점을 확인한 후, 해당 스텝의 메시지를 수정하거나 분기 조건을 조정하세요. 복제 후 A/B 테스트가 효과적입니다.
