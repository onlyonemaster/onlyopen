AI 인사이트 (AI Insight)

AI가 자동으로 대화 데이터를 분석하여 핵심 발견사항, 개선 권고, 이상 징후를 리포트로 제공하는 지능형 분석 기능입니다.

📌 접속 경로: 좌측 메뉴 → "AI 인사이트" 클릭합니다.

인사이트 개요

AI 인사이트는 수동 분석이 어려운 대량 대화 데이터에서 의미 있는 패턴과 개선점을 AI가 자동으로 도출합니다. 일간/주간 단위로 리포트가 생성됩니다.

리포트 유형

유형설명주기
일간 요약전일 대화의 주요 트렌드, 이상 징후, 핵심 통계매일 09:00
주간 인사이트주간 패턴 분석, 성과 변화, 개선 권고사항매주 월요일
이상 감지 알림비정상 패턴 감지 시 즉시 알림 (이탈률 급증, 부정 감성 폭증 등)실시간
맞춤 분석관리자가 특정 주제/기간을 지정하여 요청하는 분석온디맨드

주요 발견사항 섹션

각 리포트는 아래 카테고리로 분류된 발견사항을 포함합니다.

카테고리예시
감성 트렌드"화요일 오후 부정 감성 비율이 평소 대비 40% 증가"
자주 실패하는 질문"'환불 절차' 관련 질문에서 AI 해결률 30% — 지식베이스 업데이트 필요"
신규 토픽 출현"'신규 API 연동' 관련 문의 급증 — 새 FAQ 항목 추가 권장"
성과 이상치"봇 A의 응답시간 급증 (8초) — RAG 인덱스 재구축 권장"
사용자 패턴"재방문 사용자 중 72%가 동일 질문 반복 — 자동 후속 메시지 도입 권장"

개선 권고

발견사항을 바탕으로 AI가 구체적인 개선 액션을 제안합니다.

  • 1
    권고사항 확인
    각 권고는 우선도(높음/중간/낮음), 예상 효과, 구체적 실행 방법을 포함합니다.
  • 2
    원클릭 적용
    일부 권고는 "적용" 버튼으로 즉시 반영 가능 (예: FAQ 추가, 프롬프트 수정 제안)
  • 3
    효과 추적
    적용된 권고의 효과를 자동 추적하여 다음 리포트에 Before/After 비교 제공

자동 알림 설정

알림 조건설명기본 상태
이탈률 급증이탈률이 평균 대비 50% 이상 증가ON
부정 감성 급증부정적 감성 비율이 30% 초과ON
응답시간 초과평균 응답시간이 5초 초과ON
해결률 하락1차 해결률이 50% 미만으로 하락ON
신규 토픽 감지이전에 없던 새로운 질문 유형 출현OFF

리포트 히스토리

과거 생성된 모든 인사이트 리포트는 히스토리 탭에서 조회할 수 있습니다.

기능설명
검색키워드, 날짜 범위, 유형별 리포트 검색
비교두 시점의 리포트를 나란히 비교
북마크중요 리포트 즐겨찾기 등록
공유리포트 링크 생성 또는 이메일 발송
💡 팁: 주간 인사이트의 권고사항을 꾸준히 적용하면 1~2개월 내 만족도와 해결률이 유의미하게 개선됩니다. "효과 추적" 기능으로 개선 효과를 정량적으로 확인하세요.
