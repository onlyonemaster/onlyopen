대시보드 (Dashboard v2)

K-AIBA 관리자 대시보드는 OneChat 시스템의 핵심 지표를 한눈에 확인하고 후보 봇을 관리하는 통합 관제 화면입니다.

📌 접속 경로: 로그인 후 좌측 메뉴 → "대시보드" 클릭 또는 /admin/onechat_dashboard_v2.php에 직접 접속합니다.

KPI 패널

대시보드 상단에는 6개의 핵심 성과 지표(KPI) 카드가 표시됩니다.

Context Bridge 상태

Context Bridge는 챗봇이 대화 맥락을 유지하기 위한 핵심 연결 모듈입니다.

  • 1
    Active (활성)
    봇이 대화 컨텍스트를 정상적으로 유지하며 이전 대화 내용을 기반으로 응답을 생성합니다.
  • 2
    Inactive (비활성)
    컨텍스트 연결이 끊어진 상태. 대화마다 독립적 응답을 생성합니다. Bridge 재연결이 필요합니다.
  • 3
    Pending (대기)
    초기 설정 중이거나 연결 시도 중인 상태. 자동으로 Active로 전환됩니다.

주요 조작법

  • 1
    새 봇 후보 추가
    우측 상단 "+ 새 후보" 버튼 클릭 → 기본 정보 입력 → Layer 1 자동 완료
  • 2
    레이어 설정 진행
    후보 행의 ⬜ 아이콘 클릭 → 해당 레이어 설정 모달 열림 → 정보 입력 후 저장
  • 3
    봇 활성화
    4-Layer 모두 ✅ 완료 시 "활성화" 버튼 활성 → 클릭하면 봇이 실서비스에 배포됩니다.
  • 4
    KPI 새로고침
    KPI 패널 우측의 🔄 아이콘 클릭 시 실시간 데이터로 갱신됩니다.
💡 팁: Bridge Active 수가 총 봇 수보다 현저히 낮다면, 연결 끊김 봇을 점검하세요. 봇 관리 페이지에서 일괄 재연결이 가능합니다.
