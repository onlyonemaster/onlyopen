연락처 관리 (Contacts)

고객 연락처 데이터베이스를 관리하고, 그룹/태그 분류, 가져오기/내보내기 기능을 제공합니다.

📌 접속 경로: 좌측 메뉴 → "연락처 관리" 클릭합니다.

연락처 목록

컬럼설명
체크박스일괄 작업 대상 선택
이름연락처 이름 (클릭 시 상세 정보)
이메일이메일 주소
전화번호휴대폰/유선 번호
회사소속 회사명
태그분류 태그 뱃지 (복수 가능)
마지막 대화가장 최근 대화 일시
작업편집 / 메시지 발송 / 삭제

검색 및 필터

필터설명
키워드 검색이름, 이메일, 전화번호, 회사명으로 검색
태그 필터특정 태그가 부여된 연락처만 표시
그룹 필터지정 그룹에 속한 연락처만 표시
활동 기간최근 대화가 있었던 기간으로 필터링
채널 필터유입 채널별 필터 (웹/카카오/네이버 등)

그룹 관리

  • 1
    그룹 생성
    "그룹 관리" 탭 → "새 그룹" 버튼 → 그룹명 입력, 설명 작성 → 저장
  • 2
    연락처 배정
    연락처 선택(체크박스) → "그룹 배정" 버튼 → 대상 그룹 선택 → 적용
  • 3
    동적 그룹
    조건 기반 자동 그룹 (예: "최근 30일 대화 있음 + Pro 플랜" → 자동 분류)

태그 시스템

기능설명
태그 추가연락처 상세에서 새 태그 입력 또는 기존 태그 선택
일괄 태그다수 연락처 선택 후 일괄 태그 부여/제거
태그 색상시각 구분을 위한 태그별 색상 지정
자동 태그특정 행동(구매, 문의, 이탈 등) 시 자동 태그 부여 규칙 설정

가져오기 / 내보내기

가져오기 (Import)

  • 1
    파일 업로드
    "가져오기" 버튼 → CSV 또는 Excel 파일 선택 → 업로드
  • 2
    컬럼 매핑
    파일의 각 열을 시스템 필드(이름, 이메일, 전화번호 등)에 매핑
  • 3
    중복 처리
    이미 존재하는 연락처 발견 시: 덮어쓰기 / 건너뛰기 / 병합 선택
  • 4
    가져오기 실행
    미리보기 확인 → "가져오기 실행" → 완료 후 결과 리포트 표시

내보내기 (Export)

옵션설명
전체 내보내기모든 연락처를 CSV/Excel로 다운로드
필터 내보내기현재 적용된 필터 조건의 연락처만 내보내기
선택 내보내기체크박스로 선택한 연락처만 내보내기
필드 선택내보낼 컬럼(필드)을 사용자 지정

연락처 상세 정보

연락처 이름 클릭 시 표시되는 상세 화면에서 아래 정보를 확인/편집합니다.

섹션내용
기본 정보이름, 이메일, 전화번호, 회사, 직책
태그 · 그룹부여된 태그 목록, 소속 그룹
대화 이력해당 연락처와의 전체 대화 타임라인
구독 정보연결된 구독 플랜, 사용량, 결제 이력
메모관리자가 작성한 내부 메모
💡 팁: "동적 그룹" 기능을 활용하면 마케팅 대상을 자동으로 세분화할 수 있습니다. 예를 들어 "30일 이상 미접속 + Pro 플랜"인 고객에게 리텐션 메시지를 자동 발송하는 워크플로우를 구성할 수 있습니다.
