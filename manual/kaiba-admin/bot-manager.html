봇 관리 (Bot Manager)

등록된 모든 챗봇의 활성/비활성 전환, 프롬프트 모드 변경, 세부 설정(톤·관계·목적)을 관리하는 페이지입니다.

📌 접속 경로: 좌측 메뉴 → "봇 관리" 클릭 또는 /admin/onechat_bot_manager.php에 직접 접속합니다.

검색 및 필터

봇 목록 상단에 다양한 필터 옵션이 제공됩니다.

필터설명
키워드 검색봇 이름 또는 설명에 포함된 키워드로 검색
상태 필터활성(ON) / 비활성(OFF) / 전체
프롬프트 모드기본(Default) / 전문(Professional) / 친근(Friendly) / 영업(Sales)
카테고리봇 유형별 분류 필터

ON/OFF 토글

  • 1
    개별 토글
    각 봇 행의 ON/OFF 스위치를 클릭하면 즉시 상태가 변경됩니다. ON → 실시간 서비스 가동, OFF → 서비스 중단.
  • 2
    일괄 ON/OFF
    체크박스로 여러 봇 선택 → 상단 "일괄 ON" 또는 "일괄 OFF" 버튼 클릭 → 확인 모달에서 승인 후 적용.
⚠️ 주의: 봇을 OFF로 전환하면 해당 채널의 사용자에게 "서비스 일시 중단" 메시지가 자동 발송됩니다. 서비스 시간 외에 작업하시길 권장합니다.

프롬프트 모드 변경

봇의 응답 스타일을 4가지 프롬프트 모드로 전환할 수 있습니다.

모드특징적합 용도
Default기본적인 AI 응답. 중립적 톤, 표준 응답 길이범용
Professional격식체, 전문 용어 사용, 구조화된 응답B2B, 기술지원
Friendly친근한 구어체, 이모지 사용, 짧은 응답일반 고객
Sales설득적 톤, CTA 포함, 제품/서비스 강조마케팅, 영업

모드 변경 방법

  • 1
    개별 변경
    봇 행의 프롬프트 모드 뱃지 클릭 → 드롭다운에서 새 모드 선택 → AJAX로 즉시 적용
  • 2
    일괄 변경
    다수 봇 체크 → 상단 "모드 변경" 버튼 → 드롭다운에서 모드 선택 → 확인 후 적용

상세 설정 모달

봇 이름 클릭 시 열리는 상세 설정 모달에서 정밀한 봇 행동을 제어합니다.

톤 설정 (Tone)

옵션설명
격식체~합니다, ~입니다 체의 공손한 표현
반말체~해, ~야 등의 친근한 표현
혼합상황에 따라 자동 전환

관계 설정 (Relationship)

옵션설명
상담원전문적 고객 상담사 역할
비서개인 비서처럼 친절하고 세심한 응답
전문가해당 분야 전문가로서 깊이 있는 답변
친구편안한 대화 상대

목적 설정 (Purpose)

옵션설명
정보 제공질문에 대한 정확한 정보 전달
문제 해결고객 문제의 원인 분석과 해결책 제시
영업 전환상담을 자연스럽게 구매/계약으로 연결
교육/안내서비스 사용법이나 절차를 단계별 안내

일괄 작업 요약

일괄 작업설명확인 필요
일괄 ON선택된 봇을 모두 활성화예
일괄 OFF선택된 봇을 모두 비활성화예
모드 변경선택된 봇의 프롬프트 모드 일괄 변경예
일괄 삭제선택된 봇을 영구 삭제 (복구 불가)이중 확인
💡 팁: 프롬프트 모드 변경은 즉시 반영됩니다. 변경 전 "미리보기" 버튼으로 새 모드의 샘플 응답을 확인하세요.
