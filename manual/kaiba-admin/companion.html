AI 컴패니언 (AI Companion)

AI 어시스턴트의 성격, 대화 시나리오, 학습 데이터를 설정하고 실시간 성능을 모니터링하는 페이지입니다.

📌 접속 경로: 좌측 메뉴 → "AI 컴패니언" 클릭합니다.

컴패니언 개념

AI 컴패니언은 단순 질의응답을 넘어 사용자와 지속적 관계를 형성하는 고급 AI 어시스턴트입니다. 사용자의 대화 이력, 선호도, 행동 패턴을 학습하여 개인화된 응답을 제공합니다.

페르소나 설정

컴패니언의 성격과 커뮤니케이션 스타일을 정의합니다.

설정 항목설명예시

대화 시나리오 관리

  • 1
    인사 시나리오
    첫 방문 / 재방문 / 시간대별 인사말을 각각 설정합니다. 개인화 변수(이름, 마지막 대화 주제 등)를 삽입할 수 있습니다.
  • 2
    주제별 대화 흐름
    FAQ, 상품 안내, 일정 예약 등 주제별로 최적화된 대화 흐름을 사전 정의합니다.
  • 3
    감성 대응
    사용자의 감성(화남, 급함, 기쁨 등)을 감지하고 적절한 톤으로 전환하는 규칙을 설정합니다.
  • 4
    에스컬레이션 조건
    상담원 전환이 필요한 조건(반복 실패, 불만 감지, 특정 키워드)을 정의합니다.

학습 데이터 관리

데이터 유형설명관리 방법
지식베이스 문서FAQ, 매뉴얼, 정책 문서 등 RAG에 활용되는 문서업로드/삭제
대화 이력 학습과거 성공적인 대화 사례를 기반으로 패턴 학습자동/수동 선별
피드백 데이터사용자 평가(좋아요/싫어요)를 반영한 응답 개선자동 반영
커스텀 예시관리자가 직접 작성한 이상적 질답 쌍추가/편집

학습 데이터 업로드

  • 1
    파일 업로드
    "학습 데이터" 탭 → "업로드" 버튼 → PDF, DOCX, TXT, CSV 파일 선택 → 자동 청킹 및 인덱싱
  • 2
    URL 크롤링
    웹페이지 URL 입력 → 자동으로 콘텐츠 추출 → 지식베이스에 추가
  • 3
    수동 입력
    "새 항목 추가" → 질문/답변 쌍 직접 입력 → 즉시 학습 반영

성능 모니터링

모니터링 항목설명

테스트 모드

  • 1
    샌드박스 채팅
    "테스트" 버튼 클릭 → 실제 사용자에게 영향 없이 컴패니언과 대화 테스트. 설정 변경 즉시 반영 확인.
  • 2
    시나리오 시뮬레이션
    사전 정의된 테스트 시나리오를 자동 실행하여 각 경로의 응답 품질을 검증합니다.
💡 팁: 할루시네이션율이 높다면 지식베이스 문서의 커버리지를 확인하세요. 사용자가 자주 묻는 질문 중 지식베이스에 없는 항목을 우선 추가하면 정확도가 빠르게 개선됩니다.
