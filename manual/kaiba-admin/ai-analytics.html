AI 분석 (AI Analytics)

대화 데이터를 기반으로 사용자 행동 패턴, AI 응답 품질, 트렌드를 분석하는 대시보드입니다.

📌 접속 경로: 좌측 메뉴 → "AI 분석" 클릭합니다.

분석 대시보드 개요

AI 분석 페이지는 크게 4개 영역으로 구성되어 전체 시스템 성과를 한눈에 파악할 수 있습니다.

영역설명
요약 KPI주요 수치 카드 (총 대화, 응답 시간, 만족도, 해결률)
트렌드 차트일별/주별/월별 대화량 및 품질 추이 그래프
봇별 성과각 봇의 개별 성과 비교 테이블
사용자 행동사용 패턴, 피크 시간대, 재방문율 분석

핵심 KPI 카드

지표설명목표값
총 대화 수선택 기간 내 전체 대화 건수-
평균 응답 시간AI 봇의 첫 응답까지 평균 소요 시간< 3초
사용자 만족도대화 후 평가 점수 평균 (5점 만점)> 4.0
1차 해결률상담원 전환 없이 AI가 해결한 비율> 70%
이탈률대화 도중 사용자가 떠난 비율< 15%
재방문율24시간 내 다시 대화를 시작한 비율> 30%

트렌드 차트

  • 1
    기간 선택
    우측 상단 날짜 피커에서 분석 기간을 설정합니다. 프리셋: 오늘, 7일, 30일, 90일, 커스텀
  • 2
    차트 유형 전환
    라인 차트 / 바 차트 / 영역 차트 간 전환 가능. 비교 모드에서 기간 대비 증감 확인
  • 3
    지표 필터
    차트 하단 범례에서 표시할 지표를 선택/해제하여 원하는 데이터만 시각화
  • 4
    데이터 내보내기
    "내보내기" 버튼으로 CSV 또는 이미지(PNG)로 차트 데이터를 다운로드

리포트 생성

  • 1
    리포트 생성
    "리포트 생성" 버튼 클릭 → 기간 및 포함 항목 선택 → PDF/Excel 형식 선택 → 생성
  • 2
    자동 리포트 스케줄
    "스케줄 설정"에서 일간/주간/월간 자동 리포트 생성 및 이메일 발송 설정
