구독자 관리 (Subscriber List)

구독 플랜별 회원을 조회·관리하고, 사용량 추적 및 만료일을 관리하는 페이지입니다.

📌 접속 경로: 좌측 메뉴 → "구독자 관리" 클릭 또는 /admin/onechat_subscriber_list.php에 직접 접속합니다.

구독 플랜 체계

K-AIBA OneChat 서비스는 6단계 구독 플랜을 제공합니다.

플랜월 대화 한도봇 수 제한주요 기능
Free100회1개기본 AI 응답
Basic1,000회3개기본 + 프롬프트 모드
Standard5,000회10개RAG 연동, 분석 기본
Pro20,000회30개전체 분석, AI 인사이트
Business100,000회100개전용 서버, SLA 보장
B2B무제한무제한커스텀 개발, 전담 매니저

사용량 추적

각 구독자의 월간 사용량이 실시간으로 추적됩니다.

  • 1
    사용량 바 색상 체계
    초록색 (0~60%): 정상 사용
    주황색 (61~85%): 사용량 주의
    빨간색 (86~100%): 한도 임박/초과
  • 2
    한도 초과 시
    월 한도 100% 도달 시 자동으로 서비스 제한. 관리자가 수동 해제하거나 사용자가 플랜 업그레이드 시 복구됩니다.
  • 3
    사용량 리셋
    매월 1일 00:00에 자동 리셋. 관리자 수동 리셋도 가능합니다.

만료 관리

  • 1
    만료 임박 알림
    만료 7일 전 자동 이메일/SMS 알림이 발송됩니다. 대시보드에도 경고 표시.
  • 2
    자동 갱신
    결제 수단이 등록된 구독자는 만료일에 자동 결제 후 갱신됩니다.
  • 3
    수동 연장
    작업 열의 "연장" 버튼 → 연장 기간 선택(1개월/3개월/6개월/1년) → 확인 후 적용.
  • 4
    플랜 변경
    작업 열의 "플랜 변경" → 새 플랜 선택 → 차액 정산 방법 선택(즉시/다음 결제일) → 적용.
