상담원 관리 (Operator Queue)

실시간 상담 대기열 모니터링, 상담원 배정, 상담 이력 관리, 우선순위 설정을 제공하는 페이지입니다.

📌 접속 경로: 좌측 메뉴 → "상담원 관리" 클릭합니다.

실시간 대기열

AI가 해결하지 못한 대화가 상담원 대기열에 진입합니다. 실시간으로 대기 중인 상담 요청을 모니터링합니다.

상담원 배정

  • 1
    자동 라우팅
    문의 유형, 상담원 전문분야, 현재 처리량을 기반으로 AI가 최적 상담원을 자동 배정합니다.
  • 2
    수동 배정
    대기열 항목의 "배정" 버튼 → 가용 상담원 목록에서 선택 → 즉시 배정 완료
  • 3
    재배정
    진행 중 상담을 다른 상담원에게 이관. 사유 입력 필수. 이전 대화 컨텍스트 자동 전달.

상담 이력

  • 1
    이력 조회
    "상담 이력" 탭에서 기간, 상담원, 유형, 만족도별 필터링하여 과거 상담 내역을 조회합니다.
  • 2
    대화 내용 확인
    각 이력 항목 클릭 → AI 대화 → 상담원 전환 → 해결까지의 전체 대화 스레드 확인
  • 3
    품질 평가
    관리자가 상담 품질을 내부 평가하여 상담원 역량 관리에 활용합니다.
