환불 처리

  • 1
    환불 요청 확인
    "환불 처리" 탭에서 접수된 환불 요청 목록을 확인합니다. 요청 사유, 결제 금액, 사용 기간을 검토합니다.
  • 2
    환불 금액 산정
    전액 환불 / 일할 계산(사용 일수 제외) / 부분 환불 중 선택합니다. 시스템이 자동으로 일할 금액을 계산해 제안합니다.
  • 3
    환불 승인
    "환불 승인" 버튼 클릭 → 결제 수단으로 환불 진행. PG사 처리 완료 시 상태 자동 업데이트.
  • 4
    구독 처리
    환불 완료 시 구독이 자동으로 Free 플랜으로 다운그레이드되거나 해지 처리됩니다.
⚠️ 주의: 결제일로부터 7일 이내는 전액 환불, 7~30일은 일할 계산, 30일 초과는 환불 불가가 기본 정책입니다. 예외 처리 시 "슈퍼관리자" 권한이 필요합니다.
