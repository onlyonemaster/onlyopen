공유 방법 총정리

kiam.kr에서는 콜백 메시지(및 IAM 카드)를 다양한 채널로 공유할 수 있습니다. SNS 공유 팝업(sns-modalwindow)을 통해 다음 방법들을 이용할 수 있습니다:

📱
데일리 문자발송
daily_send_pop() — 매일 자동으로 지인들에게 IAM 카드 발송
💬
문자 보내기
sns_sendSMS() — SMS 앱을 통해 직접 문자 전송
📋
주소 복사
sns_copyContacts() — 내 IAM 링크를 클립보드에 복사
💚
카톡 공유
sns_shareKakaoTalk() — 카카오톡으로 공유
📘
페이스북 공유
sns_shareFaceBook() — 페이스북에 공유
🔗
콜백 공유
share_callback() — 콜백 메시지를 다른 회원과 공유

SNS 공유 팝업 (sns-modalwindow)

SNS 공유 팝업은 showSNSModal() 함수 호출 시 나타나며, 카드 편집 모달의 [카드별 공유하기] 메뉴에서 접근할 수 있습니다:

// 카드 편집 모달 → 카드별 공유하기 클릭 시
onclick="$('#card_con_modal').modal('hide');showSNSModal('','Y');"

// SNS 공유 팝업 구성:
// 1. 데일리 문자발송 (daily_send_pop)
// 2. 문자 보내기 (sns_sendSMS)
// 3. 주소 복사 (sns_copyContacts)
// 4. 카톡 공유 (sns_shareKakaoTalk) — 주석 처리됨
// 5. 페이스북 공유 (sns_shareFaceBook) — 주석 처리됨
// 6. 콜백 공유 (share_callback) — 주석 처리됨
📌 참고: 카톡 공유, 페이스북 공유, 콜백 공유는 현재 HTML에서 주석 처리(<!-- -->)되어 있어 기본적으로는 보이지 않습니다. 향후 활성화될 수 있는 기능입니다.

카톡 공유 (sns_shareKakaoTalk)

카카오톡으로 IAM 카드나 콜백 메시지를 공유하는 기능입니다. 현재는 주석 처리되어 있으나, 다음과 같은 방식으로 동작할 것으로 예상됩니다:

항목내용
호출 함수sns_shareKakaoTalk()
공유 대상카카오톡 친구 또는 채팅방
공유 내용내 IAM 카드 링크 또는 콜백 메시지
필요 조건카카오톡 앱 설치, JavaScript SDK 연동

페이스북 공유 (sns_shareFaceBook)

페이스북으로 IAM 카드나 콜백 메시지를 공유하는 기능입니다:

항목내용
호출 함수sns_shareFaceBook()
공유 대상페이스북 타임라인 또는 메신저
공유 내용내 IAM 카드 링크 (og:image 등 메타태그 활용)
필요 조건페이스북 앱 또는 웹 로그인

문자로 공유하기 (sns_sendSMS)

SMS 문자 메시지를 통해 IAM 카드를 공유하는 방법입니다. sns_sendSMS(val) 함수가 처리합니다:

// sns_sendSMS 함수 흐름:
// 1. val이 "app_home"이면 → 메인 카드 정보를 AJAX로 가져옴
//    → 카드 이름, 회사, 직책, 전화번호, 단축 URL을 SMS 본문에 포함
// 2. 일반 공유면 → 현재 페이지 카드 정보를 SMS 본문에 포함
// 3. location.href = "sms:" + 전화번호 + "?body=" + 메시지내용

// 예시 SMS 내용:
// "홍길동님의 명함
//  ABC회사 과장 010-1234-5678
//  https://kiam.kr/?shorturl%26preview=N"

SMS 공유는 Android 기기의 기본 문자 앱을 호출하여 동작합니다. iPhone에서는 alert("휴대폰에서 이용해주세요.") 메시지가 표시됩니다.

데일리 문자발송 (daily_send_pop)

데일리 문자발송은 내 폰 주소록의 모든 지인에게 매일 자동으로 IAM 카드를 발송하는 기능입니다:

절차내용
1단계회원가입 먼저 하기
2단계온리원문자 앱 설치하기 (Google Play)
3단계데일리발송 시작하기
💡 안내: IAM 카드 발송은 무료이지만, 일반 메시지 발송은 유료입니다. 데일리발송 기능은 앱이 설치된 Android 기기에서만 사용할 수 있습니다.

주소 복사 (sns_copyContacts)

sns_copyContacts() 함수는 내 IAM 링크를 클립보드에 복사합니다. 복사된 링크는 원하는 곳(메신저, 이메일, 메모장 등)에 붙여넣기 하여 공유할 수 있습니다.

이 기능은 copy_msg_link()와 유사한 방식으로 동작하며, 임시 input 요소를 생성하여 텍스트를 선택 후 document.execCommand("copy")로 복사합니다.
