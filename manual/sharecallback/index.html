공유콜백이란?

공유콜백은 내가 만든 콜백 메시지를 다른 회원과 공유하여 함께 사용할 수 있게 해주는 기능입니다.

예를 들어 팀장이 만든 "고객 응대용 콜백 메시지"를 팀원 모두가 공유받아 똑같은 메시지로 부재중 전화에 응대할 수 있습니다. 또는 영업팀 전체가 통일된 콜백 메시지를 사용할 때도 유용합니다.

📌 핵심 포인트: 공유콜백은 콜백등록관리 메뉴에서 시작됩니다. 이 메뉴는 kiam.kr/m 페이지의 내정보(우측 하단 사람 아이콘) 드롭다운 → [콜백등록관리]에서 접근할 수 있습니다.

공유콜백 전체 흐름

  1. 1
    콜백 메시지 등록 — 먼저 공유할 콜백 메시지를 만듭니다. → IAM 콜백 메시지 만들기 →
  2. 2
    콜백등록관리 진입 — 내정보 드롭다운 → [콜백등록관리] 클릭 → 앱(AppScript) 연동 화면으로 이동
  3. 3
    공유 대상 설정 — 콜백등록관리에서 공유할 콜백 메시지를 선택하고, 공유할 회원을 지정합니다.
  4. 4
    공유 완료 — 공유받은 회원의 콜백 메시지함에 해당 메시지가 추가되어 사용 가능해집니다.

어디서 시작하나요?

공유콜백 기능은 내정보 드롭다운 메뉴에서 시작합니다:

메뉴 위치접근 방법연결 기능
내정보 드롭다운 (우측 하단)kiam.kr/m → 하단 우측 [내정보 아이콘] 클릭마이페이지 팝업 (mypage-modalwindow)
통합계정관리내정보 → [통합계정관리]goOnlyOneApp() → 앱(AppScript) 연동
마이페이지내정보 → [마이페이지]/iam/mypage.php → 회원 정보 관리
결제정보내정보 → [결제정보]/?cur_win=payment → 결제 내역
콜백등록관리내정보 → [콜백등록관리] ★goCallbackList() → 앱 내 콜백 관리 화면
공지/푸쉬 알림내정보 → [공지/푸쉬 알림]/?cur_win=unread_push → 알림 내역
AI로 자동 카드 만들기내정보 → [AI로 자동 카드 만들기]create_auto_card() → AI IAM 생성
AI명함프로필관리내정보 → [AI명함프로필관리]/m/ai_card_profile_list.php → AI 프로필 관리
굿마켓내정보 → [굿마켓]gwc_tab() → 굿마켓 상품
콜이야내정보 → [콜이야]callya_tab() → 콜이야 콘텐츠
위드유내정보 → [위드유]openShop() → 위드유 샵

빠른 시작

  1. 1
    내정보 열기: kiam.kr/m → 하단 우측 [내정보 아이콘] 클릭 → 마이페이지 팝업 열림
  2. 2
    콜백등록관리 진입: 팝업에서 [콜백등록관리] 클릭 → goCallbackList() 실행
  3. 3
    앱 연동 확인: Android 앱(온리원문자)에서 콜백등록관리 화면이 열립니다. PC에서는 앱 설치 안내가 표시됩니다.
  4. 4
    공유 설정: 앱 내 콜백등록관리 화면에서 공유할 메시지와 대상을 선택하여 공유합니다.
💡 팁: 콜백등록관리는 Android 앱 전용 기능입니다. PC에서는 [내정보] 드롭다운의 다른 메뉴(마이페이지, 결제정보 등)는 웹에서 바로 이용 가능하며, 콜백등록관리만 앱이 필요합니다.
