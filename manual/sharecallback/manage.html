공유콜백 관리 화면에서는 다음과 같은 정보를 한눈에 확인할 수 있습니다:

📤
내가 공유한 메시지
다른 회원에게 공유한 콜백 메시지 목록과 공유 상태를 확인합니다.
📥
공유받은 메시지
다른 회원이 나에게 공유한 콜백 메시지 목록을 확인합니다.
👥

공유 대상 회원을 추가하거나 제거할 수 있습니다.
🔔
공유 알림
새로운 공유 요청이나 공유 해제 알림을 확인합니다.

공유된 메시지 확인하기

콜백등록관리(앱)에서 내가 공유한 콜백 메시지를 확인하는 방법:

  1. 1
    콜백등록관리 접속: 내정보 드롭다운 → [콜백등록관리] 클릭
  2. 2
    공유 목록 탭 선택: 앱 내에서 "공유한 메시지" 또는 "공유 내역" 탭 선택
  3. 3
    상세 확인: 각 공유 항목별로 공유 대상, 공유 일시, 상태를 확인

공유 내역 테이블 구조 (추정)

컬럼설명
메시지 타이틀공유한 콜백 메시지의 제목
공유 대상공유받은 회원의 아이디/이름
공유 일시공유가 이루어진 날짜와 시간
상태활성(사용 중) / 비활성(해제됨) / 대기 중
관리공유 해제, 재공유 등의 액션 버튼

공유 상태 관리

공유콜백의 상태는 다음과 같이 구분됩니다:

상태의미공유자 액션수신자 액션
활성 (Active)공유된 메시지가 수신자의 콜백 메시지함에 정상 등록되어 사용 가능한 상태해제 가능기본 메시지로 설정 가능
비활성 (Inactive)공유자가 공유를 해제했거나 수신자가 거부한 상태재공유 가능더 이상 사용 불가
대기 중 (Pending)공유 요청은 보냈으나 수신자가 아직 승인하지 않은 상태요청 취소 가능승인/거부 선택 가능

공유 상태 변경은 앱(AppScript) 내 콜백등록관리에서만 가능하며, 웹에서는 조회만 가능할 수 있습니다.

공유 해제하기

더 이상 공유가 필요하지 않은 경우, 다음과 같이 공유를 해제할 수 있습니다:

  1. 1
    공유 목록에서 해당 메시지 선택
  2. 2
    [공유 해제] 또는 [해지] 버튼 클릭
  3. 3
    해제 확인: "정말 공유를 해제하시겠습니까?" 확인 메시지에 응답
  4. 4
    완료: 공유받은 회원의 콜백 메시지함에서 해당 메시지가 제거됨
📌 참고: 공유 해제 시 이미 해당 메시지를 기본값으로 사용 중이던 수신자는 다른 메시지로 전환해야 합니다. 해제된 메시지는 더 이상 부재중 전화에 자동 발송되지 않습니다.

공유받은 메시지 관리

다른 회원이 나에게 공유한 콜백 메시지는 내 콜백 메시지 리스트에 자동 추가됩니다:

  • 메시지 출처 표시: 공유받은 메시지는 "공유자: [아이디]" 형태로 출처가 표시될 수 있습니다.
  • 기본값 설정: 공유받은 메시지를 내 기본(default) 콜백 메시지로 설정할 수 있습니다.
  • 수정 제한: 공유받은 메시지는 원본 작성자만 수정 가능하며, 수신자는 내용을 변경할 수 없습니다.
  • 복사하여 사용: 공유받은 메시지를 복사하여 나만의 버전으로 새로 등록할 수 있습니다.

공유 라이프사이클

공유콜백 메시지의 전체 생명주기는 다음과 같습니다:

  1. 1
    생성: 콜백 메시지를 새로 등록 → 메시지 만들기 →
  2. 2
    공유 요청: 콜백등록관리에서 대상 회원에게 공유 요청 전송
  3. 3
    승인/거부: 수신자가 공유 요청을 승인 또는 거부
  4. 4
    사용: 승인된 메시지가 수신자의 콜백 메시지함에 등록되어 사용됨
  5. 5
    해제/만료: 공유자가 해제하거나 수신자가 사용 중단 → 메시지함에서 제거
