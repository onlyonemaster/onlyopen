기존 고객 관리란?

기존 고객 관리는 이벤트신청페이지가 아닌 기존에 보유하던 DB(주소록) 고객을 대상으로 예약 발송을 설정하고 관리하는 기능입니다.

엑셀이나 폰 주소록에서 가져온 기존 고객 DB에 AI 퍼널 메시지 시퀀스를 연결하여 자동 발송할 수 있습니다.

📌 접속 경로: https://kiam.kr/mypage_oldrequest_list.php

신청 고객 vs 기존 고객 차이

구분신청 고객 관리기존 고객 관리
고객 유입이벤트신청페이지 통해 직접 신청기존 보유 DB(엑셀, 폰주소록)
자동화신청 즉시 자동 퍼널 발동수동으로 발송 일정 설정
관리 위치mypage_request_list.phpmypage_oldrequest_list.php
활용 목적신규 리드 자동 너처링기존 고객 재활성화

활용 방법

1
기존 DB 주소록 등록

폰문자 발송 화면에서 주소록을 업로드하여 그룹을 먼저 생성합니다.
→ 주소록 관리 매뉴얼 참고

2
기존 고객 관리에서 새 예약 등록

[새 예약 등록] 버튼 클릭 → 주소록 선택 → 발송 폰번호 선택 → 메시지 입력

3
발송 기간 설정

시작일~마감일 지정, 일별 발송량 설정 후 저장

4
발송 결과 확인

→ 발송 결과 내역에서 확인
