데일리문자란?

데일리문자는 주소록(DB)을 일정 분량으로 나누어 매일 자동 발송하는 IAM의 문자 자동화 솔루션입니다.

한 번의 큰 홍보보다 매일의 작은 연결이 더 오래 갑니다. 기존 고객을 꾸준히 관리하면서 비용은 최소화할 수 있습니다.

📱 무료문자 활용 가능: 휴대폰 주소록과 엑셀 주소록 모두 활용할 수 있으며, 온리원문자 앱의 무료 발송 건수를 최대한 활용하여 문자 비용을 절감합니다.

활용 이유

💰
비용 절감
하루 무료 발송 건수 한도 내에서 매일 발송해 전체 문자 비용을 최소화합니다.
📅
꾸준한 접촉
한 번에 대량 발송보다 매일 소량 발송이 고객과의 관계 유지에 더 효과적입니다.
👥
기존 고객 관리
신규 유입이 없어도 기존 DB를 활용해 지속적인 마케팅을 자동으로 진행합니다.
📱
주소록 활용
휴대폰 연락처와 엑셀 주소록을 모두 활용할 수 있습니다.

활용 구조

항목내용
주소록 등록휴대폰 주소록 또는 엑셀(.xls) 업로드
일 발송량 설정하루에 몇 건씩 발송할지 수량 지정
발송 기간시작일~마감일 설정, 자동으로 나눠 발송
메시지 세트날짜별로 다른 메시지 등록 가능
퍼널 연결문자 내 챗봇 링크로 원챗 퍼널 자동 연결
발송 결과daily_list.php에서 전체 발송 현황 확인

주요 기능

  • 데일리 세트리스트 — 등록된 데일리 발송 그룹 전체 목록 조회
  • 메시지 세트 등록 — 각 날짜별 발송 메시지 내용 저장·관리
  • 발신내역 확인 — 날짜별 실제 발송 결과 추적
  • 자동 분할 발송 — 전체 주소록을 발송 일수로 자동 균등 분배
  • 발송 중단/재개 — 필요 시 특정 세트 일시 중단 가능
📌 데일리발송 접속 경로
kiam.kr 로그인 → 상단 메뉴 → 데일리발송 (https://kiam.kr/daily_list.php)

사용 방법

1
데일리발송 메뉴 접속

https://kiam.kr/daily_list.php 접속

2
새 세트 등록

[메시지세트 등록하기] 버튼 클릭 → 제목, 발송폰번호, 주소록 선택

3
발송 설정

일발송량, 발송시작일, 발송마감일 입력 → 저장

4
발송 시작

설정 완료 후 매일 자정 이후 자동으로 지정 수량 발송 시작

5
결과 확인

세트리스트에서 발신내역 클릭 → 날짜별 발송 결과 확인

표시 항목설명
메시지제목등록 시 입력한 세트 이름
발송폰번호발송에 사용하는 등록된 폰번호
주소록이름연결된 주소록 그룹명
주소건수전체 수신 대상 수
발송일수총 발송 예정 일수
일발송량하루 발송 건수
발송시작일자동 발송 시작 날짜
발송마감일자동 발송 종료 날짜
