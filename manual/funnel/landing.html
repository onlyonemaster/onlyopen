인포랜딩페이지란?

인포랜딩페이지는 자신의 이벤트·상품·서비스를 소개하거나 상세페이지로 보여주는 전용 랜딩페이지입니다. 문자에 링크를 넣어 고객을 유도하고, 하단에 신청창을 연결해 DB를 수집합니다.

💡 활용 예시: "무료 컨설팅 신청 랜딩", "이벤트 할인 소개 페이지", "제품 상세 소개 + 구매 신청"

접속 방법

1
kiam.kr 로그인

https://kiam.kr 접속 후 로그인

2
인포랜딩페이지 메뉴 이동

하단 메뉴 → 인포랜딩 또는 직접 접속: https://kiam.kr/mypage_landing_list.php

랜딩페이지 만들기

1
[랜딩페이지 등록하기] 버튼 클릭

목록 상단 오른쪽의 등록 버튼을 클릭합니다.

2
기본 정보 입력

제목(내부 식별용)과 랜딩페이지 설명을 입력합니다.

3
콘텐츠 편집

이미지, 텍스트, 버튼 등을 편집기에서 구성합니다. HTML 직접 편집도 가능합니다.

4
신청창 연결

하단에 이벤트신청페이지 코드를 삽입하여 고객 정보 수집 폼을 연결합니다.

5
저장 및 노출 설정

저장 후 [노출] 상태로 변경하면 URL이 활성화됩니다.

목록 관리

항목설명
제목등록 시 입력한 랜딩페이지 이름
인포랜딩설명관리용 설명 텍스트
미리보기실제 화면을 미리 확인하는 버튼
수정/삭제내용 편집 또는 삭제
노출/중지URL 활성화/비활성화 토글
📌 링크 복사: 목록에서 해당 랜딩페이지의 URL을 복사하여 문자 내용에 삽입하면 고객이 클릭 시 랜딩페이지로 이동합니다.

신청페이지와 연결

인포랜딩페이지 하단에 이벤트신청페이지 코드를 삽입하면 고객이 랜딩페이지에서 바로 신청할 수 있습니다.

1
이벤트신청페이지에서 코드 복사

→ 이벤트신청페이지 메뉴얼 참고

2
랜딩페이지 편집 화면에 코드 붙여넣기

HTML 편집 모드에서 신청창 코드를 원하는 위치에 삽입합니다.

3
저장 후 미리보기로 확인

신청창이 정상적으로 표시되는지 미리보기로 확인합니다.
