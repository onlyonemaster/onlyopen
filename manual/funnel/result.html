발송 결과 내역이란?

발송 결과 내역은 AI 퍼널 메시지 또는 예약 발송이 실제로 완료된 후의 결과를 조회하는 화면입니다.

발송 성공 여부, 수신 번호, 발송 시각, 메시지 내용을 한눈에 확인하고 마케팅 효과를 분석합니다.

접속 방법

1
kiam.kr 로그인 후 발송 결과 내역 접속

https://kiam.kr/mypage_send_list.php

항목설명

수신번호메시지를 받은 고객의 전화번호
수신키워드고객 식별 키워드 (이름 또는 ID)

결과발송 성공 / 실패 / 수신거부 상태

결과 상태 코드

상태의미조치 방법
✅ 성공정상적으로 발송 완료—
❌ 실패발송 중 오류 발생폰 상태 확인, 재발송 시도
🚫 수신거부수신거부 목록에 등록된 번호해당 고객 발송 목록에서 제외
⏳ 대기아직 발송 처리 중잠시 후 새로고침
📴 없는번호존재하지 않는 전화번호주소록에서 해당 번호 수정/삭제

활용 방법

  • 발송 성공률 분석 — 성공/실패 비율로 발송 품질 점검
  • 실패 번호 정리 — 반복 실패 번호를 주소록에서 제거해 발송 효율 향상
  • 수신거부 관리 — 수신거부 고객은 향후 발송에서 자동 제외
  • 날짜별 조회 — 특정 캠페인 기간의 결과만 필터링
  • 전체 리스트 / 신청 리스트 구분 — 전체 발송 또는 특정 신청창 발송만 조회
📌 20개씩 / 50개씩 / 100개씩 표시 옵션으로 한 번에 보이는 결과 수를 조절할 수 있습니다.
