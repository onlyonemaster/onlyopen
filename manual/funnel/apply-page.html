이벤트신청페이지란?

이벤트신청페이지는 고객의 이름·연락처 등 정보를 수집하기 위한 신청 폼(Form) 페이지입니다. 코딩 없이 클릭만으로 만들 수 있으며, 생성된 코드를 인포랜딩페이지나 외부 사이트에 삽입합니다.

고객이 신청 폼을 제출하면 자동으로 신청 고객 리스트에 등록되고, AI 퍼널 메시지가 자동 발송됩니다.

접속 방법

1
kiam.kr 로그인

https://kiam.kr 접속 후 로그인

2
이벤트신청페이지 메뉴 이동

하단 메뉴 → 고객신청창 또는 직접 접속:
https://kiam.kr/mypage_link_list.php

신청페이지 만들기

1
[신청창 등록] 버튼 클릭

목록 상단에서 새 신청창 등록 버튼을 클릭합니다.

2
신청창 기본 정보 입력
항목필수설명
신청창제목필수관리용 이름 (예: 무료상담 신청창)
신청대상선택대상 구분 메모 (예: 사업자, 개인)
발송폰번호필수신청 시 자동 발송에 사용할 폰번호
연결 퍼널선택연결할 AI 퍼널 메시지 세트 선택
3
수집 항목 설정

이름, 연락처는 기본 수집. 추가 항목(지역, 직업, 관심사 등) 자유 설정 가능

4
저장

저장하면 목록에 신청창이 생성되고 삽입 코드가 자동 발급됩니다.

코드 삽입 방법

생성된 신청창 코드를 복사하여 인포랜딩페이지 또는 외부 웹사이트에 삽입합니다.

1
목록에서 [코드 복사] 클릭

신청창 목록의 해당 항목 오른쪽 [소스코드 복사] 버튼 클릭

2
랜딩페이지에 붙여넣기

인포랜딩페이지 HTML 편집기에서 원하는 위치에 코드 붙여넣기

3
미리보기 확인

신청 폼이 정상 표시되는지 확인 후 저장

📌 외부 사이트 삽입: 생성된 iframe 코드를 자신의 블로그, 웹사이트, 카카오채널 등 어디든 삽입 가능합니다.

목록 관리

항목설명
신청창제목등록 시 입력한 신청창 이름
신청대상등록 시 설정한 대상 구분
발송폰번호신청 시 자동 발송에 사용되는 폰
소스코드 복사삽입용 iframe 코드 클립보드 복사
수정/삭제신청창 내용 편집 또는 삭제
구글폼 가져오기기존 구글폼 데이터를 연동·가져오는 기능

활용 팁

  • 신청창 + 인포랜딩 조합 — 랜딩페이지 하단에 신청창을 연결하면 고객이 소개를 보고 바로 신청 가능
  • 문자에 직접 링크 삽입 — 신청창 URL을 단축URL로 변환 후 문자에 삽입
  • AI 퍼널 연결 — 신청 즉시 AI 퍼널 설계에 따라 자동 메시지 발송 시작
  • 구글폼 연동 — 기존 구글폼 사용자도 데이터를 kiam으로 가져올 수 있음
