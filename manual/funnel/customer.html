신청 고객 관리란?

이벤트신청페이지를 통해 신규로 신청한 고객의 DB를 확인하고 관리하는 기능입니다. 고객이 신청 폼을 제출하면 이 리스트에 자동으로 추가됩니다.

각 고객의 신청 정보, 발송 현황, 챗봇 연결 여부를 한눈에 파악할 수 있습니다.

접속 방법

1
kiam.kr 로그인 후 신청 고객 관리 접속

https://kiam.kr/mypage_request_list.php

고객 리스트 확인

항목설명
신청창제목고객이 신청한 이벤트신청페이지 이름
고객명고객이 입력한 이름
연락처고객이 입력한 전화번호
신청일시신청 제출 날짜 및 시간
발송 현황연결된 AI 퍼널 발송 진행 상태
챗봇 연결챗봇 링크 클릭 여부
메모관리자가 직접 입력하는 메모 필드
📌 고객관리 리스트: 신청창별로 필터링하거나 전체 리스트를 조회할 수 있습니다.

고객 관리 기능

  • 개별 고객 상세 보기 — 특정 고객 클릭 시 입력한 모든 정보 확인
  • 메모 추가 — 상담 내용, 진행 상태 등 관리자 메모 입력
  • 삭제 — 불필요한 고객 정보 삭제 (단, 발송 중인 경우 주의)
  • 신청창 필터 — 특정 이벤트신청창에 등록된 고객만 조회
  • 기간 검색 — 특정 날짜 범위로 신청 고객 필터링

데이터 내보내기

수집된 고객 DB를 엑셀 파일로 내보내 SMS 발송 주소록으로 활용하거나 외부 CRM에 업로드할 수 있습니다.

1
전체 선택 또는 필터 적용 후 [다운로드] 클릭

목록 상단의 엑셀 내보내기 버튼을 클릭합니다.

2
CSV/Excel 파일로 저장

다운로드된 파일을 SMS 주소록 업로드나 외부 활용에 사용합니다.

💡 활용 예시: 수집된 DB → SMS 주소록 등록 → 데일리발송 연결 → 지속적 마케팅 자동화
