화면 구성

AI 실행 로그 페이지에서는 Claude AI가 인물 정보를 처리한 모든 이력을 확인할 수 있습니다. 언제, 누구에 대해, 어떤 결과로 처리했는지 추적합니다.

접속 경로: 관리자 → 인적자원관리 → AI 실행 로그

로그 컬럼 설명

컬럼설명
실행 일시AI가 해당 인물을 처리한 날짜·시각
인물 ID처리된 인물의 Gn_mandata ID
이름처리된 인물 이름
업데이트 필드 수AI가 실제로 채운 필드 개수 (fields_updated)
AI 비용해당 처리에 사용된 Claude API 비용 (USD)
결과처리 성공/실패 여부

일별 통계

로그 목록 위에 날짜별 처리 건수 통계가 표시됩니다. 하루에 몇 명을 처리했는지, 그 중 실제로 정보가 업데이트된 인물이 몇 명인지 한눈에 확인할 수 있습니다.

통계 항목설명
총 처리 인원해당 날짜에 AI가 처리한 전체 인물 수
업데이트 인원fields_updated > 0인 인물 수 (실제로 정보 변경됨)
당일 API 비용해당 날짜 claude_cost_usd 합계

API 비용 추적

각 AI 처리마다 Claude API 사용 비용이 기록됩니다. claude_cost_usd 컬럼에 달러(USD) 단위로 저장됩니다.

💡 비용 절감 팁
• 이름이 있는 인물만 AI 처리 대상으로 설정하면 불필요한 API 소비를 줄일 수 있습니다.
• 이미 이메일·회사가 채워진 인물(done 상태)은 재처리하지 않도록 설정을 확인하세요.
• 일별 통계에서 비용 추이를 모니터링하고 예산을 관리하세요.

기간 필터

로그는 기간 설정으로 필터링할 수 있습니다. 시작일·종료일을 선택하면 해당 기간의 로그만 표시됩니다.

데이터가 많은 경우 최근 7일, 30일 등 단기 필터를 사용하는 것을 권장합니다.
