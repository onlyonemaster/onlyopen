화면 구성

인물 목록 페이지는 약 370만 명의 인물 데이터를 검색하고 탐색하는 화면입니다. 한 페이지에 50명씩 표시되며, 검색 조건을 입력하면 즉시 필터링됩니다.

접속 경로: 관리자 → 인적자원관리 → 인물 목록

검색 방법

화면 상단의 검색 폼에서 4가지 조건으로 검색할 수 있습니다.

검색 필드설명예시
이름 이름(name) 필드 부분 일치 검색 홍길동, 홍
모바일 휴대폰 번호 부분 일치 검색 010-1234, 01012
이메일 이메일 주소 부분 일치 검색 hong@, gmail.com
회사 회사명(company) 부분 일치 검색 삼성, 현대
💡 검색 팁
• 여러 조건을 동시에 입력하면 AND 조건으로 검색됩니다.
• 검색 조건 없이 조회하면 전체 목록이 최신 등록 순으로 표시됩니다.
• 모바일 번호는 하이픈(-) 유무에 관계없이 검색됩니다.

목록 컬럼 설명

컬럼내용
번호데이터베이스 고유 ID
이름인물 이름 (없으면 공란)
모바일휴대폰 번호
이메일이메일 주소 (없으면 공란)
회사소속 회사명 (없으면 공란)
점수0~100점 완성도 점수
AI 상태pending(대기) / done(완료) / none(미처리)
등록일데이터 최초 등록 날짜
상세인물 상세 정보 링크

페이지 이동

한 페이지에 50명씩 표시됩니다. 하단의 페이지 번호를 클릭하거나 이전/다음 버튼으로 이동할 수 있습니다.

전체 데이터가 약 370만 명이므로, 검색 조건 없이 전체 탐색하는 것보다 검색 조건을 활용하는 것을 권장합니다.

상세 보기

목록에서 인물의 이름 또는 상세 버튼을 클릭하면 해당 인물의 상세 정보 페이지로 이동합니다.
