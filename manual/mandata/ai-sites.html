화면 구성

AI 검색 사이트 관리 페이지에서는 Claude AI가 인물 정보를 검색할 웹사이트 목록을 등록·관리합니다. 여기에 등록된 사이트에서 AI가 이름, 이메일, 회사 정보를 수집합니다.

접속 경로: 관리자 → 인적자원관리 → AI 검색 사이트 관리

사이트 목록

등록된 웹사이트 목록이 표시됩니다. 각 사이트별로 수집 가능한 정보 유형이 체크박스로 표시됩니다.

컬럼설명
사이트명사이트 이름 (관리용 구분자)
URL검색 대상 웹사이트 주소
이름 수집이 사이트에서 이름 정보를 수집할지 여부
이메일 수집이 사이트에서 이메일을 수집할지 여부
회사 수집이 사이트에서 회사명을 수집할지 여부
삭제사이트 목록에서 제거

사이트 추가

하단의 추가 폼에서 새로운 검색 사이트를 등록합니다.

  1. 사이트명 입력
    관리하기 쉬운 이름을 입력합니다. (예: "링크드인", "기업정보포털")
  2. URL 입력
    검색 대상 웹사이트 주소를 입력합니다. (예: https://www.linkedin.com)
  3. 수집 항목 체크
    이 사이트에서 수집할 정보 유형(이름/이메일/회사)에 체크합니다.
  4. 추가 버튼 클릭
    저장 완료 후 목록에 즉시 반영됩니다.
💡 효과적인 사이트 선택
인물 프로필이 공개된 사이트(링크드인, 기업 홈페이지, 인물 정보 DB 등)를 등록하면 AI의 정보 수집 성공률이 높아집니다.

사이트 삭제

목록에서 삭제 버튼을 클릭하면 해당 사이트가 AI 검색 대상에서 제외됩니다. 이미 수집된 데이터에는 영향을 주지 않습니다.

수집 옵션 (can_get_xxx)

각 사이트별로 수집 가능한 항목을 개별 제어할 수 있습니다.

옵션설명
can_get_name이 사이트에서 이름 수집 허용
can_get_email이 사이트에서 이메일 수집 허용
can_get_company이 사이트에서 회사명 수집 허용

예를 들어, 특정 사이트에서는 이메일만 수집하고 싶다면 can_get_email만 체크하면 됩니다.
