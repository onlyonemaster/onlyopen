화면 구성

AI 웹검색 설정 페이지에서는 Claude AI의 인물 정보 자동 수집 작업을 관리합니다. AI 큐에 등록된 인물 수를 확인하고, 처리 상태를 모니터링합니다.

접속 경로: 관리자 → 인적자원관리 → AI 웹검색 설정

AI 큐 현황

화면 상단에서 현재 AI 처리 대기 현황을 확인할 수 있습니다.

항목설명
AI 처리 완료 (done) ai_queue_status='done'인 인물 수. AI가 웹검색을 마친 인원.
AI 대기 중 (pending) 활성(active) 상태이고 이름이 있으며 pending 큐에 등록된 인원 수.
💡 pending 인원이 많다면?
AI 작업이 아직 처리되지 않은 인원이 많은 상태입니다. AI 웹검색 작업을 실행하거나 자동 실행 스케줄을 확인하세요.

Pending 인물 처리

AI 큐 대기 인물을 처리하는 방법입니다.

  1. AI 처리 시작 버튼 클릭
    화면에서 "AI 처리 시작" 또는 "실행" 버튼을 클릭합니다. AI가 pending 인물 중 이름이 있는 인물부터 순서대로 웹 검색을 시작합니다.
  2. 처리 진행 확인
    AI 실행 로그 페이지에서 실시간 처리 진행 상황을 확인할 수 있습니다.
  3. 결과 확인
    처리 완료 후 AI 업데이트 정보 페이지에서 실제로 정보가 업데이트된 인물 목록을 확인합니다.

AI 검색 설정

AI가 웹검색 시 사용하는 옵션을 설정합니다.

설정 항목설명
검색 사이트 AI가 정보를 수집할 웹사이트 목록. AI 검색 사이트 관리에서 별도 관리.
1회 처리 건수 AI가 한 번 실행될 때 처리할 최대 인물 수.
검색 필드 AI가 수집을 시도할 필드 (이메일, 회사명 등).

주의사항

⚠️ Claude API 비용 발생
AI 웹검색은 Claude API를 사용하므로 인물 1명당 API 비용이 발생합니다. 대량 처리 시 비용을 미리 확인하세요. AI 실행 로그에서 누적 비용(claude_cost_usd)을 확인할 수 있습니다.
💡 처리 우선순위
AI는 이름(name)이 있는 인물을 우선적으로 처리합니다. 이름이 없는 인물은 pending 상태여도 처리가 지연될 수 있습니다.
