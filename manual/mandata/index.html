인적자원관리란?

인적자원관리(mandata)는 kiam.kr 플랫폼의 관리자 전용 인물 데이터베이스 시스템입니다. 3,684,333명(약 370만 명)의 인물 정보를 관리하며, AI 웹검색을 통해 이메일·회사·AI 분석 메모를 자동으로 수집·업데이트합니다.

📍 접속 경로: kiam.kr 관리자 → 인적자원관리
관리자 계정으로만 접근 가능합니다.

주요 기능

📊
대시보드 통계
전체 인원, 완성도(이름/이메일/회사), AI 처리 현황을 한눈에 확인합니다.
🔍
인물 검색·목록
이름, 모바일, 이메일, 회사명으로 빠르게 검색하고 목록을 확인합니다.
👤
인물 상세 정보
개인 프로필, AI 분석 메모, 점수, AI 큐 상태를 상세히 확인합니다.
🤖
AI 웹검색 자동화
Claude AI가 웹을 검색하여 이메일·회사 정보를 자동으로 채워줍니다.
🌐
검색 사이트 관리
AI가 정보를 수집할 웹사이트 목록을 등록·관리합니다.
📋
AI 실행 로그
AI 작업 이력, 처리 인원, Claude API 비용을 날짜별로 추적합니다.

AI 웹검색 자동화

인적자원관리의 핵심 기능은 Claude AI를 활용한 인물 정보 자동 수집입니다. 이름과 모바일 번호만 있는 인물도 AI가 웹에서 이메일, 회사명, 직책 등을 자동으로 찾아서 채워줍니다.

AI 처리 상태의미
pendingAI 처리 대기 중 (큐에 등록됨)
doneAI 처리 완료
none아직 AI 큐에 등록되지 않음

업무 흐름

  1. 인물 데이터 확인
    대시보드에서 전체 인원, 이메일·회사 완성률, AI 처리 현황을 확인합니다.
  2. 인물 검색
    목록 페이지에서 이름, 모바일, 이메일, 회사명으로 검색하여 원하는 인물을 찾습니다.
  3. 상세 정보 확인
    인물 상세 페이지에서 개인 정보, AI 분석 메모, 점수를 확인합니다.
  4. AI 자동 수집 설정
    AI 웹검색 설정에서 pending 인물을 처리하거나, 검색 사이트를 추가·관리합니다.
  5. 결과 확인
    AI 실행 로그에서 처리 완료 현황과 업데이트된 인물 정보를 확인합니다.

빠른 시작

  1. 관리자 → 인적자원관리 → 대시보드 접속
  2. 전체 인원 및 완성도 통계 확인
  3. 인물 목록·검색에서 원하는 인물 검색
  4. AI 웹검색 설정에서 pending 처리 현황 확인
  5. AI 처리가 완료되면 AI 업데이트 정보에서 결과 확인
