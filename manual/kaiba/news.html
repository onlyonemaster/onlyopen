AI 뉴스 (메인 페이지)

kaiba.kiam.kr 메인 화면은 최신 AI 뉴스를 MSN 스타일 타일 레이아웃으로 보여줍니다.

화면 구성

메인 페이지(https://kaiba.kiam.kr/)에 접속하면 AI 관련 최신 뉴스가 카드(타일) 형태로 표시됩니다.

  • 상단 네비게이션 — 로고, 메뉴(협회소개·정책사업·비즈니스·CEO클럽·커뮤니티·AI vs CEO·회원지원), 로그인/회원가입 버튼
  • 검색창 — 뉴스 키워드 검색 (실시간 필터링)
  • 카테고리 필터 버튼 — 카테고리별 뉴스 분류
  • 뉴스 그리드 — 3열(데스크톱) / 2열(태블릿) / 1열(모바일) 반응형 카드 레이아웃
  • 푸터 — 협회 정보, 서비스 링크, 문의처

뉴스 카테고리

색상카테고리설명
●인공지능AI 기술, 서비스, 제품 관련 뉴스
●기술소프트웨어, 하드웨어, 인프라 기술 뉴스
●비즈니스투자, M&A, 파트너십, 매출 등 사업 뉴스
●연구·학술논문, 연구성과, 학회 관련 뉴스
●헬스케어의료 AI, 디지털 헬스 뉴스
●금융·핀테크금융 AI, 핀테크 서비스 뉴스
●모빌리티자율주행, 스마트 이동수단 뉴스
●정책·규제정부 정책, 규제, 법률 관련 뉴스
●기타기타 산업 관련 뉴스

검색 기능

  • 1
    검색창에 키워드 입력
    페이지 상단 검색창에 찾고 싶은 키워드를 입력합니다.
  • 2
    Enter 또는 검색 버튼 클릭
    검색 결과가 뉴스 그리드에 즉시 반영됩니다. 일치하는 키워드는 하이라이트 표시됩니다.

카테고리 필터 사용법

  • 1
    필터 버튼 클릭
    검색창 아래의 카테고리 버튼(전체, 인공지능, 기술, 비즈니스 등)을 클릭합니다.
  • 2
    선택한 카테고리의 뉴스만 표시
    활성화된 필터 버튼은 파란색으로 표시되며, 해당 카테고리 뉴스만 그리드에 나타납니다. "전체" 클릭 시 모든 뉴스가 표시됩니다.

뉴스 카드 구조

각 뉴스 카드에는 다음 정보가 포함됩니다:

  • 대표 이미지 — 뉴스 썸네일 (없으면 그라데이션 배경)
  • 카테고리 배지 — 색상별 분류 표시
  • 제목 — 뉴스 헤드라인 (최대 3줄)
  • 요약 — 기사 내용 요약 (최대 3줄)
  • 출처 — 언론사 이름 (예: AI타임스, 디일렉)
  • 날짜 — 게시 날짜
💡 팁: 뉴스 카드를 클릭하면 원본 기사 페이지로 이동합니다.
