📱 폰 데이터 연동

아이엠 앱(iamapp)을 통해 통화·문자·건강·캘린더 데이터를 마이챗에 자동 동기화합니다.

⚠️ 폰 데이터 연동은 스탠다드 이상 플랜에서만 사용 가능합니다.

수집 데이터

종류내용처리 방식
📞 통화 기록발수신 기록, 통화 시간번호 마스킹(010-****-5678) 후 저장
💬 문자/SMS주요 내용 요약원문 미저장, 계좌·카드번호 자동 마스킹
📅 캘린더일정·약속 (향후 30일)제목·시간·장소
🏃 건강/헬스걸음수·심박·수면·체중·칼로리당일 기준 집계

연동 방법

  1. 1
    아이엠 앱(iamapp) 실행
  2. 2
    설정 → 마이챗 연동 → 데이터 동기화 켜기
  3. 3
    필요한 권한(통화·문자·캘린더·건강) 허용
  4. 4
    데이터 자동 수집 시작 → 마이챗 learn.html에서 확인

개인정보 보호

  • 전화번호는 마스킹 처리 후 저장 (010-****-5678)
  • 문자 원문은 절대 저장하지 않음 — AI 요약만 저장
  • 계좌번호·카드번호는 자동 마스킹
  • 데이터 공개 범위 기본값: 🔒 나만 보기
  • 긴급 차단 시 모든 폰 데이터도 즉시 비공개 전환
💡 learn.html의 폰 데이터 연동 현황 섹션에서 채널별 수집 건수를 확인할 수 있습니다.
