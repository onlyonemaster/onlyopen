아바타 정보

항목설명
아바타 이름대화창에 표시되는 AI 이름 (최대 30자)
말투·성격 메모AI가 학습할 말투와 성격. 구체적일수록 개인화됨.

2차 보안 PIN

4자리 숫자 PIN을 설정하면 마이챗 진입 시 추가 인증이 필요합니다.

  1. 1
    숫자 패드에서 4자리 입력
  2. 2
    4자리 완성 즉시 자동 저장
⚠️ PIN을 잊어버린 경우 고객센터에 문의해야 합니다. 안전한 곳에 별도 기록하세요.

데이터 저장 방식

🔐
서버 암호화 보관 (추천)
E2E 암호화. 회사도 열람 불가. 폰 분실 시 복구 가능. 스탠다드 3년, 프로 영구 보관.
📱
내 기기에만 보관
최강 프라이버시. 단, 폰 분실 시 데이터 영구 소실 위험.
💾
혼합 + 다운로드
기기+서버 이중 저장. ZIP으로 언제든 직접 다운로드 가능.

자체 API키 (BYOK)

  1. 1
    API 제공사 선택 (DeepSeek / OpenAI / Claude / Gemini)
  2. 2
    API키 입력 → 저장
  3. 3
    저장 즉시 무제한 모드로 전환
💡 눈 아이콘(👁)으로 키 표시/숨기기를 전환할 수 있습니다. 키는 AES-256 암호화로 저장되어 회사도 열람 불가합니다.

🚨 긴급 차단 (Panic Lock)

마이챗 메뉴(≡) → 긴급 차단 버튼을 누르면:

  • 모든 외부 공개(scope=public/both) 데이터가 즉시 비공개로 전환
  • 원챗 외부 아바타에서도 해당 데이터에 접근 불가
⚠️ 긴급 차단 후 해제는 설정 페이지에서 개별 데이터의 공개 범위를 다시 설정해야 합니다.

데이터 내보내기

설정 → 내 데이터 전체 다운로드 버튼으로 모든 학습 데이터를 ZIP 파일로 다운로드할 수 있습니다. (JSON + CSV 형식)
