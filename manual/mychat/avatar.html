😊 얼굴 탭 — 아바타 만들기

두 가지 방법 중 선택할 수 있습니다.

🎨
AI 생성 (추천)
성별·나이대·스타일을 선택하면 DALL-E가 4가지 아바타 이미지를 생성. 마음에 드는 걸 선택.
📸
사진 업로드
내 사진(JPG·PNG·WEBP, 최대 10MB)을 업로드. 정면 얼굴 사진 권장.

AI 생성 옵션

옵션선택지
성별👩 여성 / 👨 남성 / 🧑 중성
나이대20대 / 30대 / 40대 / 50대+
스타일📸 사실적 / 🎨 일러스트 / 🕹️ 3D 캐릭터
추가 설명예: 안경 쓴, 미소 짓는, 단발머리 (선택)
💡 AI 생성 기능은 BYOK 플랜에서 본인 OpenAI API키를 등록한 경우 또는 플랫폼 키가 설정된 경우 사용 가능합니다.

🎬 화상 탭 (HeyGen 선택 연동)

HeyGen API키를 등록하면 내 얼굴 아바타가 실시간으로 립싱크하며 말하는 화상 통화가 가능합니다.

1️⃣
HeyGen API키 등록
app.heygen.com → Settings → API에서 키 발급 후 입력. AES-256 암호화 저장.
2️⃣
아바타 생성
얼굴 탭에서 업로드한 사진으로 HeyGen Photo Avatar 자동 생성 (약 2분)
3️⃣
테스트 영상
문장 입력 → 10~30초 후 립싱크 영상 생성. 대화창에서 자동 재생.
⚠️ HeyGen 화상 아바타는 PRO 플랜 사용자에게만 제공됩니다. 비용은 HeyGen API 사용료($1/분)가 별도로 부과됩니다.
