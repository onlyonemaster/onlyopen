데이터 입력 방법

  1. 1
    learn.html 진입 → 채널 아이콘 클릭
  2. 2
    제목(선택) + 내용 입력
  3. 3
    공개 범위 설정 (기본값: 🔒 나만 보기)
  4. 4
    저장하기 → 즉시 AI 학습에 반영

효과적인 데이터 입력 팁

  • 📔 일기는 매일 짧게라도 — AI가 감정 패턴을 가장 잘 학습하는 채널
  • 👤 기본 정보는 처음에 한 번 꼼꼼히 — 이름·직업·가치관
  • 🔮 상징 채널은 한 번만 입력해도 영구 반영됨
  • 📱 폰 연동(스탠다드 이상)을 활성화하면 데이터가 자동 축적됨
