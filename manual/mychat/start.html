🚀 구독 & 첫 진입

마이챗 구독을 시작하고 처음 진입하는 방법을 안내합니다.

1단계: 구독하기

  1. 1
    kiam.kr/m/ 앱 홈 → 🧠 마이챗 아이콘 클릭
  2. 2
    구독 페이지에서 플랜 선택 → 결제하기 버튼
  3. 3
    토스페이먼츠 결제 완료 → 자동으로 마이챗 대화창으로 이동
🌱
스타터 — 9,900원/월
AI 대화 300회, 음성 50회, 학습데이터 200건
🔥
스탠다드 — 24,900원/월
AI 대화 1,000회, 음성 300회, 폰 연동 가능
🔑

본인 API키 사용, 모든 기능 무제한

2단계: PIN 설정

첫 진입 시 설정 → 2차 보안 PIN에서 4자리를 설정하세요.

PIN을 설정하지 않으면 이후 진입 시 PIN 없이 접근할 수 있습니다. 개인 데이터 보호를 위해 반드시 설정을 권장합니다.

3단계: 아바타 이름 설정

설정 → 아바타 정보에서 이름과 말투·성격 메모를 입력하면 AI 아바타가 나만의 캐릭터로 동작합니다.

4단계: 첫 대화 시작

마이챗 대화창(index.html)에서 메시지를 입력하면 AI 아바타와 대화가 시작됩니다. 처음에는 학습 데이터가 없어 일반적인 답변을 하지만, 데이터를 쌓을수록 나를 더 잘 이해하는 답변을 합니다.

📚 학습 데이터 입력하기를 먼저 완료하면 훨씬 풍부한 대화가 가능합니다.
