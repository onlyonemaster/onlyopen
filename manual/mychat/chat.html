💬 AI와 대화하기

내 학습 데이터를 기반으로 AI 아바타와 1:1 대화하는 방법을 안내합니다.

대화 방법

  1. 1
    마이챗 대화창 하단 입력창에 메시지 입력
  2. 2
    AI가 내 학습 데이터를 참조해 답변 생성 (출처 표시: 📔 일기 기반)
  3. 3
    답변 하단 빠른 액션 버튼으로 추가 질문 가능

빠른 액션 버튼

버튼설명
🧭 의사결정 등록현재 고민을 의사결정 추적에 바로 등록
📊 데이터 흐름 분석최근 내 데이터 패턴 요약 요청
⏰ 7일 후 리마인드지금 주제를 7일 뒤 AI가 먼저 꺼내도록 예약
🔍 심층 분석방금 주제를 더 깊이 분석 요청
📝 감정 기록오늘 감정을 일기 채널에 저장
🔄 패턴 찾기내 반복 패턴 탐색 요청

메뉴 버튼(≡) 기능

대화창 우상단 ≡ 버튼을 누르면 메뉴가 열립니다.

메뉴이동

내 데이터 인용 방식

AI 아바타가 답변할 때 활용한 데이터 출처를 표시합니다.

📔 일기 기반 | 📱 통화 기록 참조 | 🏃 건강 데이터 | 📅 캘린더

이 표시가 많을수록 AI가 내 실제 데이터를 잘 활용하고 있다는 의미입니다.

💡 학습 데이터가 많을수록 AI 답변의 정확도와 개인화 수준이 높아집니다. 데이터 입력 방법을 참고하세요.
