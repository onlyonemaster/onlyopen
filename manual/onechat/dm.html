💬 DM 채팅 사용법

kiam.kr 회원끼리 1:1 또는 그룹으로 실시간 채팅할 수 있습니다. 답장, 이모지 반응, 파일 전송, 투표 등 다양한 기능을 사용해보세요.

DM 채팅이란?

채팅 탭(💬)은 kiam.kr에 가입한 회원끼리 직접 메시지를 주고받는 공간입니다. 고객 챗봇과는 별개로, 내부 구성원·파트너·지인과 빠르게 소통할 때 사용합니다.

👤
1:1 개별 채팅
특정 회원에게 바로 메시지를 보낼 수 있습니다
👥
그룹 채팅
여러 명을 한 채팅방에 초대해 함께 대화합니다
📌
메시지 고정
중요한 메시지를 채팅방 상단에 고정할 수 있습니다
📊
투표
채팅방 안에서 바로 의견을 모을 수 있습니다

채팅 목록 화면

하단 내비게이션에서 채팅(💬) 탭을 누르면 채팅 목록이 표시됩니다.

개별 / 그룹 서브탭

목록 상단에 두 개의 탭이 있습니다.

탭표시 내용
개별 채팅1:1 대화 목록. 상대방 온라인 여부(초록 점)와 안읽은 메시지 수를 보여줍니다
그룹 채팅내가 참여 중인 그룹 채팅방 목록입니다

채팅방 카드 읽는 법

표시 요소설명
● 초록 점상대방이 현재 온라인 상태입니다 (5분 이내 접속)
🔴 빨간 숫자아직 읽지 않은 새 메시지 수입니다
📌 아이콘내가 고정해둔 채팅방입니다 (목록 상단에 표시)
메시지 미리보기가장 최근 메시지를 짧게 표시합니다
시간마지막 메시지를 보낸 시각입니다

새 채팅 시작하기 (1:1)

  • 1
    상단 오른쪽 새 채팅(✏️) 버튼을 누릅니다
    채팅 탭 헤더에 있는 편집 아이콘 버튼입니다.
  • 2
    검색창에 상대방 이름 또는 아이디를 2자 이상 입력합니다
    회원 목록이 실시간으로 나타납니다. 온라인 중인 회원에는 초록 점이 표시됩니다.
  • 3
    대화할 회원을 누릅니다
    기존에 대화한 적이 있으면 기존 채팅방이 열리고, 처음이라면 새 채팅방이 자동으로 생성됩니다.
💡 이미 대화했던 상대라면
채팅 목록에서 바로 이름을 눌러 입장할 수 있습니다. 새 채팅 버튼을 누르지 않아도 됩니다.

그룹 채팅 만들기

  • 1
    상단 오른쪽 그룹(👥) 버튼을 누릅니다
    새 채팅 버튼 옆에 있는 그룹 아이콘입니다.
  • 2
    그룹 이름을 입력합니다
    나중에 관리 메뉴에서 이름을 변경할 수 있습니다.
  • 3
    초대할 회원을 검색해서 선택합니다
    여러 명을 선택할 수 있습니다. 선택된 회원은 상단에 칩 형태로 표시됩니다.
  • 4
    그룹 채팅 만들기 버튼을 누릅니다
    그룹 채팅방이 생성되고 초대된 멤버에게 "님이 초대되었습니다" 시스템 메시지가 표시됩니다.

그룹 관리 기능

그룹 채팅방 헤더에서 👥 멤버 버튼을 눌러 멤버를 관리할 수 있습니다.

기능설명사용 가능
멤버 초대새 회원을 그룹에 추가합니다모든 멤버
멤버 내보내기특정 멤버를 그룹에서 제거합니다그룹 관리자만
그룹명 변경그룹 채팅방 이름을 바꿉니다그룹 관리자만
그룹 나가기내가 그룹 채팅방에서 퇴장합니다모든 멤버
📌 그룹 관리자 권한
그룹을 만든 사람이 자동으로 관리자가 됩니다. 관리자는 멤버 내보내기와 그룹 이름 변경 권한을 가집니다.

채팅방에서 대화하기

메시지 보내기

  • 1
    하단 입력창에 메시지를 입력합니다
    입력창은 내용에 따라 자동으로 높이가 늘어납니다 (최대 3줄).
  • 2
    Enter 또는 ➤ 전송 버튼을 누릅니다
    Shift+Enter는 줄바꿈입니다. Enter만 누르면 바로 전송됩니다.

읽음 확인

내가 보낸 메시지 아래에 ✓✓ 파란색이 표시되면 상대방이 메시지를 읽은 것입니다.

고정 메시지 배너

채팅방에 고정된 메시지가 있으면 채팅창 상단에 파란색 배너로 표시됩니다. 배너를 누르면 해당 메시지 위치로 이동합니다.

파일 & 이미지 전송

  • 1
    입력창 왼쪽 📎 첨부 버튼을 누릅니다
    파일 선택 창이 열립니다.
  • 2
    전송할 파일을 선택합니다
    이미지(JPG, PNG, GIF, WEBP), PDF, ZIP, Word, Excel, 동영상(MP4) 등을 지원합니다. 최대 파일 크기는 20MB입니다.
파일 종류채팅방 표시 방식
이미지 (JPG, PNG 등)썸네일 미리보기로 표시됩니다. 누르면 전체화면으로 볼 수 있습니다.
일반 파일 (PDF, ZIP 등)파일 아이콘과 파일명, 용량이 표시됩니다. 누르면 다운로드됩니다.

메시지 기능 모음

메시지를 길게 누르거나 마우스 오른쪽 버튼으로 클릭하면 컨텍스트 메뉴가 열립니다.

💡 메뉴 최상단에는 빠른 이모지 반응 (👍 ❤️ 😂 😮 😢 🙏) 6개가 표시됩니다. 이모지를 누르면 바로 반응을 남길 수 있습니다.

답장하기

  • 1
    메시지를 길게 눌러 메뉴를 엽니다
  • 2
    ↩ 답장을 선택합니다
    입력창 위에 인용 미리보기가 표시됩니다. 어떤 메시지에 답하는지 한눈에 확인할 수 있습니다.
  • 3
    메시지를 입력하고 전송합니다
    전송된 메시지에 인용된 원본 메시지가 함께 표시됩니다. 인용 부분을 누르면 원본 위치로 이동합니다.

이모지 반응

  • 1
    메시지를 길게 눌러 메뉴를 엽니다
  • 2
    원하는 이모지를 누릅니다
    메시지 아래에 이모지 반응 칩이 표시됩니다. 같은 이모지를 한 번 더 누르면 반응이 취소됩니다.

메시지 수정

  • 1
    내가 보낸 메시지를 길게 눌러 메뉴를 엽니다
    수정은 내가 보낸 메시지에만 가능합니다.
  • 2
    ✏️ 수정을 선택합니다
    입력창에 기존 메시지 내용이 자동으로 채워집니다.
  • 3
    내용을 수정하고 전송합니다
    수정된 메시지에는 (수정됨) 표시가 붙습니다.

메시지 삭제

  • 1
    내가 보낸 메시지를 길게 눌러 메뉴를 엽니다
  • 2
    🗑️ 삭제를 선택합니다
    삭제된 메시지는 "삭제된 메시지입니다"로 표시됩니다. 완전히 사라지지 않고 삭제 여부만 표시됩니다.

메시지 고정

  • 1
    고정할 메시지를 길게 눌러 메뉴를 엽니다
  • 2
    📌 메시지 고정을 선택합니다
    채팅방 상단에 파란색 고정 배너가 나타납니다. 채팅방에 입장할 때마다 항상 표시됩니다.
📌 채팅방당 고정 메시지는 1개입니다. 새로 고정하면 이전 고정이 해제됩니다.

투표 만들기

  • 1
    채팅방 헤더에서 📊 투표 버튼을 누릅니다
    투표 만들기 창이 아래에서 올라옵니다.
  • 2
    질문과 선택지를 입력합니다
    기본으로 선택지 2개가 제공됩니다. + 선택지 추가를 눌러 최대 10개까지 늘릴 수 있습니다.
  • 3
    필요하면 복수 선택 허용에 체크합니다
    체크하면 참여자가 여러 선택지를 동시에 고를 수 있습니다.
  • 4
    투표 시작 버튼을 누릅니다
    채팅방에 투표 메시지가 전송됩니다. 멤버들이 선택지를 누르면 실시간으로 결과가 갱신됩니다.

투표에 참여하기

  • 1
    채팅방에 표시된 투표 메시지에서 원하는 선택지를 누릅니다
    선택한 항목이 파란색으로 강조되고 득표율 막대가 즉시 업데이트됩니다.
  • 2
    선택을 취소하고 싶으면 다시 같은 항목을 누릅니다
    복수 선택이 허용된 경우 여러 항목을 선택할 수 있습니다. 단일 선택 투표는 다른 항목을 누르면 기존 선택이 자동으로 바뀝니다.

채팅방 설정

채팅방 헤더에서 ⋮ 더보기 버튼을 누르면 채팅방 설정 메뉴가 열립니다.

메뉴설명
📌 채팅방 고정이 채팅방을 목록 최상단에 고정합니다. 다시 누르면 해제됩니다.
🔕 알림 끄기이 채팅방의 알림을 8시간 동안 무음으로 설정합니다.
🚪 나가기채팅방에서 퇴장합니다. 그룹 채팅은 나간 후 재입장이 불가합니다(초대 필요).
💡 자주 대화하는 채팅방은 고정해두세요
고정된 채팅방은 목록 최상단에 보라색 배경으로 표시되어 빠르게 찾을 수 있습니다.
