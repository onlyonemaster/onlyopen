아바타 학습시키기

나의 말투, 전문 지식, 경험을 AI 아바타에게 학습시킬수록 더 자연스럽고 똑똑한 응답을 할 수 있습니다.

학습 화면 진입

  • 1
    상단 오른쪽 👤 아바타 버튼을 클릭합니다
    드롭다운 메뉴가 열립니다.
  • 2
    "아바타 학습시키기"를 선택합니다
    전체 화면 학습 패널이 아래에서 슬라이드업되어 열립니다. 상단에 총 학습 수와 마지막 학습 시간이 표시됩니다.

4가지 학습 방법

📔 일기 · 대화 탭

하루의 경험, 미팅 내용, 감정 등을 일기 형식으로 입력합니다. AI가 나의 일상과 관심사를 학습합니다.

설정 항목설명
날짜 선택어느 날의 일기인지 날짜를 선택합니다
템플릿 선택식사 / 미팅 / 감정 / 일상 / 성과 중 선택하면 형식이 자동 완성됩니다
카테고리가족 / 일 / 취미 / 여행 / 건강 / 관계 중 선택합니다
내용 입력자유롭게 그날의 경험을 기록합니다

📝 텍스트 탭

전문 지식, 업무 노하우, 자주 하는 말 등 자유 형식의 텍스트를 입력합니다.

예시: "저는 부동산 투자 전문가로, 항상 리스크 관리를 우선시합니다. 고객에게는..."

🎙️ 음성 탭

직접 말로 녹음하여 학습 데이터를 만듭니다. 말투와 어조까지 AI가 학습합니다.

  • 1
    🎙️ 녹음 시작 버튼을 누릅니다
    마이크 사용 권한을 허용하면 녹음이 시작됩니다. 타이머와 파형 애니메이션이 표시됩니다.
  • 2
    말하고 싶은 내용을 말합니다
    업무 소개, 전문 지식, 고객 응대 방식 등을 자연스럽게 말하세요.
  • 3
    정지 버튼을 누르고 저장합니다
    녹음 완료 후 업로드/저장 버튼을 누르면 학습 데이터로 등록됩니다.

📁 파일 탭

문서 파일을 업로드하여 AI가 그 내용을 학습하게 합니다.

지원 형식예시
PDF회사 소개서, 제안서, 보고서
DOC / DOCX업무 매뉴얼, 상품 설명서
TXT자주 하는 말, Q&A 목록
PPT / PPTX프레젠테이션 자료
XLS / XLSX데이터 표, 가격표
💡 많이 학습할수록 더 똑똑해집니다
학습 데이터가 쌓일수록 AI가 나의 전문 분야를 더 정확하게 파악합니다. 주 1~2회 꾸준히 학습시키는 것을 추천합니다.
