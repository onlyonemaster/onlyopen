🤖 챗봇 자동 설정 위저드

업종과 기본 정보를 입력하면 AI가 챗봇 시스템 프롬프트, LLM 활용 모드, Q&A 초안을 자동으로 생성해줍니다. 처음 원챗을 시작하는 분들에게 특히 유용합니다.

💡 위저드를 사용하면 평균 10분 이내에 챗봇을 완성할 수 있습니다. 생성된 내용은 언제든지 수정 가능합니다.

위저드 진입

  • 1
    사이드바(☰) → 챗봇 설정을 클릭합니다
    챗봇 설정 패널이 열립니다.
  • 2
    "AI 자동 설정 위저드" 버튼을 클릭합니다
    4단계 설정 화면이 순차적으로 안내됩니다.

위저드 4단계

STEP 1 — 업종 & 기본 정보 입력

AI가 맞춤형 챗봇을 만들기 위해 필요한 기본 정보를 입력합니다.

항목입력 예시
업종/서비스한의원, 미용실, 카페, 컨설팅, 강의, 부동산...
업체명청담한의원, 홍길동 스튜디오...
주요 서비스침술, 명상치료, 한약 처방...
타겟 고객건강에 관심 많은 40~60대, 직장인...
대표자 소개 (선택)자유 입력 또는 기존 명함 정보 자동 불러오기

STEP 2 — AI가 프롬프트 초안 생성

입력한 정보를 바탕으로 AI가 자동 생성합니다.

  • ✓
    시스템 프롬프트 (기본 + 맞춤 + LLM 지침 3섹션)
    챗봇의 페르소나, 금지 발언, 응대 규칙, LLM 모드별 지침이 포함된 완성형 프롬프트를 생성합니다.
  • ✓
    자주 묻는 질문(FAQ) 초안 5~10개
    해당 업종에서 고객이 자주 묻는 질문과 모범 답변을 생성합니다.
  • ✓
    추천 LLM 활용 모드
    업종 특성에 맞는 LLM 기본지식 활용 모드를 자동으로 제안합니다. (예: 의료 업종 → 보완 모드 권장)

STEP 3 — 검토 & 수정

AI가 생성한 내용을 확인하고 필요한 부분을 직접 수정합니다.

💡 수정 팁
• 업체명, 전화번호, 주소 등 구체적인 정보를 반드시 확인하세요.
• 금지 발언 목록은 업종 규정에 맞게 조정하세요.
• FAQ 답변이 실제 서비스와 다를 경우 수정하세요.

STEP 4 — 챗봇에 적용

  • ✓
    "챗봇에 적용" 버튼을 누릅니다
    생성된 프롬프트가 챗봇에 즉시 반영됩니다. 고객이 다음 대화부터 새로운 설정으로 응답받게 됩니다.

위저드 재실행

챗봇 설정 패널에서 언제든지 위저드를 다시 실행할 수 있습니다. 이전 설정을 덮어쓰거나 특정 섹션만 업데이트할 수 있습니다.
