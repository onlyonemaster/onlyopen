📤 발신(퍼널)탭 사용법

SMS 문자로 챗봇 링크를 보낸 수신자의 응답 현황을 확인하고, 공유 링크 방문자를 함께 관리하는 탭입니다.

발신탭이란?

발신탭은 내가 먼저 챗봇 링크를 보낸 상대방의 목록입니다. kiam.kr에서 AI 메시지 캠페인을 발송하면, 수신자 명단과 각자의 응답 상태가 이 탭에 자동으로 표시됩니다.

📩
퍼널 목록
SMS 문자를 보낸 수신자 전체 명단과 응답 여부를 확인합니다
🔗
공유 방문자
공유 링크(카카오·SNS 등)로 방문한 사람도 같은 탭에서 볼 수 있습니다
📊
응답 통계
전체·대화중·미사용 수를 상단 통계 바에서 한눈에 파악합니다
🔁
링크 재발송
각 카드의 챗봇 링크 버튼으로 개별 수신자 링크를 복사해 재전송합니다

화면 구성

발신탭 화면은 위에서부터 검색바 → 통계바 → 전환 버튼 → (필터탭) → 목록 순서로 구성됩니다.

통계 바

표시 항목설명
전체 N명퍼널 모드: 발송된 전체 수신자 수 / 공유 모드: 전체 방문자 수
대화중 N명챗봇과 한 번 이상 대화한 수신자 수
미사용 / 미대화 N명아직 대화하지 않은 수신자 수

퍼널 / 공유 전환 버튼

통계 바 오른쪽에 두 개의 전환 버튼이 있습니다.

버튼표시 목록필터
🔽 퍼널 (기본 활성) SMS 캠페인으로 발송된 수신자 명단 전체 · 대화중 · 미사용
🔗 공유 공유 링크(카카오·SNS·QR)로 방문한 구독자 전체 · 대화중 · 미대화
💡 퍼널 버튼이 기본으로 활성화되어 있습니다. 공유 버튼을 누르면 공유 링크 방문자 전용 필터 탭이 나타납니다.

SMS 퍼널 링크

kiam.kr에서 AI 메시지 캠페인을 발송하면, 각 수신자마다 개별 단축 링크가 생성되어 문자에 포함됩니다.

SMS 링크 흐름

  • 1
    캠페인 발송 시 수신자별 단축 링크 생성
    문자에 포함되는 단축 링크: chatbot.kiam.kr/s/k3apCa
    이 링크를 클릭하면 아래 주소로 이동합니다.
  • 2
    단축 링크가 퍼널 링크로 연결됨
    단축 링크 → chatbot.kiam.kr/s/onechat1?r=47922
    여기서 onechat1은 챗봇 코드, 47922는 수신자 고유 번호입니다.
  • 3
    수신자가 링크 클릭 → 챗봇 대화 시작
    수신자의 스마트폰에서 챗봇 화면이 열리고, AI가 첫 인사를 보냅니다. 대화 내용은 발신탭(퍼널)에 자동 기록됩니다.
  • 4
    발신탭에서 응답 현황 확인
    대화중(초록), 미사용(빨강) 상태로 구분되어 카드가 표시됩니다. 카드를 클릭하면 대화 내용을 볼 수 있습니다.
📌 링크 형식 비교
형식예시설명
단축 링크 (문자에 포함)chatbot.kiam.kr/s/k3apCa6자리 코드, 클릭 시 퍼널 링크로 이동
퍼널 링크 (실제 연결 주소)chatbot.kiam.kr/s/onechat1?r=47922수신자 번호(r=)가 포함된 개별 주소

퍼널 카드 구성

각 수신자는 카드 형태로 표시됩니다. 카드에서 바로 확인할 수 있는 정보는 다음과 같습니다.

카드 요소설명
아바타 (이니셜/프로필)수신자의 이름 이니셜 또는 등록된 프로필 사진
N회 배지대화 횟수 — 초록 배지로 표시 (대화한 적 있는 경우)
미사용 배지아직 챗봇과 대화하지 않은 수신자
📱 PWA 배지챗봇을 홈 화면에 설치(PWA)한 수신자
챗봇 링크 버튼해당 수신자의 퍼널 링크 복사 (?r=수신자번호 포함)
이름 / 직함 / 연락처수신자의 등록된 기본 정보
등록일캠페인 발송 날짜
💡 카드를 클릭하면 해당 수신자와의 전체 대화 내용이 담긴 채팅창이 열립니다.

공유 모드 — 방문자 목록

발신탭 상단의 공유 버튼을 누르면 카카오·SNS·QR 등 공유 링크를 통해 방문한 구독자 목록으로 전환됩니다.

공유 모드 필터

필터표시 내용
전체공유 링크로 방문한 모든 구독자
대화중챗봇과 한 번 이상 대화한 방문자
미대화방문만 하고 아직 대화하지 않은 방문자

방문자 카드 구성

카드 요소설명
아바타 (색상+이니셜)방문자 ID 기반 자동 생성 닉네임의 이니셜 (예: 노란 P = 파란고양이)
닉네임운영자가 이름을 지정하지 않은 경우 자동 생성된 닉네임 표시
챗봇 링크 버튼해당 방문자 전용 링크 복사 (?v=방문자ID)
방문자 ID8자리 고유 식별 코드 (예: WGGTOBPX)
전화번호PWA 설치 시 입력한 전화번호 (등록한 경우만 표시)
마지막 메시지 미리보기가장 최근 대화 내용 26자 미리보기
✏️ 이름 수정 버튼방문자의 닉네임을 운영자가 직접 지정할 수 있습니다

방문자 이름 직접 지정

  • ✏️
    카드 오른쪽의 ✏️ 버튼을 클릭합니다
    이름 입력 팝업이 열립니다. 새로운 이름을 입력하고 확인을 누르면 저장됩니다.
  • 💡
    이름을 비워두면 자동 닉네임으로 초기화됩니다
    이름 입력창을 비우고 확인하면 자동 생성 닉네임(예: 파란고양이)으로 돌아갑니다.

챗봇 칩 필터

챗봇이 여러 개인 경우, 목록 위에 챗봇 칩이 표시되어 챗봇별로 수신자를 필터링할 수 있습니다.

💡 특정 캠페인(sms_idx)의 수신자만 보고 싶을 때 챗봇 이름 칩을 클릭하세요. 다시 클릭하면 해제됩니다.

검색 기능

상단 🔍 검색 버튼을 누르면 검색바가 나타납니다.

검색 가능 항목설명
이름수신자 이름 또는 자동 닉네임으로 검색
직함 / 소속등록된 직함·소속명으로 검색
연락처전화번호 일부로 검색
방문자 ID8자리 ID 코드로 검색 (공유 모드)
