프롬프팅 설정

AI 아바타가 어떤 방식으로 대화할지 지침을 설정합니다. 상대방별로 말투, 관계, 목적을 다르게 설정할 수 있습니다.

프롬프팅 설정 진입

  • 1
    채팅방에서 오른쪽 상단 ℹ️ 버튼을 클릭합니다
    각 채팅방마다 개별 프롬프팅을 설정할 수 있습니다.
  • 2
    프롬프팅 설정 패널이 열립니다
    3가지 모드 중 하나를 선택하고 세부 설정을 입력합니다.

3가지 프롬프팅 모드

① 기본 프롬프팅 모드

프로필 설정에서 입력한 기본 프롬프트만 적용합니다. 모든 고객에게 동일한 방식으로 응답합니다.

📌 기본 프롬프트는 프로필 설정 화면에서 변경합니다. 이 패널에서 "기본 프롬프트 편집" 버튼을 눌러도 수정 가능합니다.

② 맞춤 프롬프팅 모드

이 상대방에게만 적용할 개별 설정을 입력합니다. 기본 프롬프트는 무시됩니다.

설정 항목선택지
말투/톤격식체 / 친근체 / 전문가 / 캐주얼 / 공감형 / 간결형
상대와의 관계고객 / 파트너 / VIP / 동료 / 언론 / 정계 / 투자자
대화 목적서비스소개 / 상담응대 / 팔로업 / 미팅조율 / 고객지원 / 네트워킹
직접 작성자유 형식으로 AI에게 지시사항을 직접 입력

③ 기본 + 맞춤 모드

기본 프롬프트를 유지하면서 추가 지시사항을 덧붙입니다. 가장 세밀한 설정이 가능합니다.

💡 미리보기로 확인하세요
👁️ 미리보기 버튼을 누르면 최종적으로 AI에게 전달되는 프롬프트 전문을 확인할 수 있습니다. 적용 전 반드시 확인해 보세요.

적용하기

  • ✓
    "적용하기" 버튼을 클릭합니다
    설정이 저장되고 채팅창에 "⚙️ 프롬프팅 적용: [모드]" 시스템 메시지가 삽입됩니다. 이후 AI 아바타는 새 설정대로 응답합니다.
