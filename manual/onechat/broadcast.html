📢 HI 공지발송

챗봇을 통해 퍼널·공유 수신자 전체에게 운영자 공지 메시지를 일괄 발송합니다. SMS 비용 없이 무제한으로 발송할 수 있는 강력한 마케팅 도구입니다.

HI 공지발송이란?

챗봇 링크를 한 번이라도 클릭한 수신자는 이후 챗봇을 통해 계속 메시지를 받을 수 있습니다. HI 공지발송은 이 원리를 이용해 운영자가 원하는 시점에 등록된 수신자 전체 또는 일부에게 공지 메시지를 일괄로 보내는 기능입니다.

📨
문자 1회 → 무제한 발송
최초 챗봇 링크 문자 1회로 이후 모든 공지는 챗봇으로 무료 발송
🎯
3가지 발송 대상
전체 / 퍼널(명함 수신자) / 공유(링크 방문자) 중 선택 발송
👁️
읽음·응답 통계
발송 후 읽은 사람, 응답한 사람을 실시간으로 확인
🔍
필터 발송
이름·연락처로 특정 대상만 골라서 발송 가능

발송 대상 구분

수신자는 챗봇 링크를 받은 경로에 따라 두 가지로 구분됩니다.

구분대상특징
퍼널(Funnel) 명함 문자(SMS)로 챗봇 링크를 받은 수신자 이름·연락처 정보가 등록되어 있음
공유(Shared) 카카오톡·SNS·QR 등으로 공유 링크를 클릭한 방문자 익명으로 시작하며 전화번호 인증 후 식별 가능
전체 퍼널 + 공유 전체 모든 챗봇 수신자에게 동시 발송
💡 마케팅의 끝판왕
명함 문자를 한 번만 보내면 그 이후 신제품 출시, 이벤트 안내, 프로모션 공지를 모두 챗봇으로 무료 발송할 수 있습니다. 오픈 카카오톡 채널과 유사하지만 내 AI 아바타가 답변까지 해준다는 점이 다릅니다.

사용 방법

공지발송 패널 열기

  • 1
    우측 상단 아바타 아이콘을 클릭합니다
    원챗 화면 오른쪽 위에 있는 내 아바타 사진을 클릭하면 드롭다운 메뉴가 나타납니다.
  • 2
    메뉴에서 HI 공지발송을 선택합니다
    📢 HI 공지발송 항목을 클릭하면 발송 타입 선택 화면이 올라옵니다.
  • 3
    발송 타입을 선택합니다
    📢 전체 발송퍼널 + 공유 수신자 모두에게 발송
    🔵 퍼널 발송명함 SMS 수신자에게만 발송
    🟣 공유 발송챗봇 공유 링크 방문자에게만 발송
    📊 발송 이력과거 발송 내역 및 통계 조회

메시지 작성 및 발송

  • 1
    발송 대상 수를 확인합니다
    패널 상단에 현재 퍼널 N명 / 공유 N명 / 합계 N명이 자동으로 표시됩니다.
  • 2
    (선택) 이름·연락처로 특정 대상만 필터링합니다
    검색창에 이름이나 연락처를 입력하면 대상이 자동으로 필터링되고, 발송 인원 수도 갱신됩니다.
  • 3
    공지 제목을 입력합니다 (선택사항)
    제목을 입력하지 않아도 발송 가능하지만, 이력 목록에서 구분하기 쉬우므로 입력을 권장합니다.
  • 4
    메시지 내용을 입력합니다
    입력하는 즉시 아래 미리보기 영역에 실제 수신자에게 표시되는 모습이 보라색 공지 카드로 미리 보여집니다.
  • 5
    📢 발송 N명 버튼을 눌러 발송합니다
    확인창에서 "확인"을 누르면 즉시 발송됩니다. 발송 완료 후 몇 명에게 전달됐는지 토스트 알림이 표시됩니다.
📌 수신자 화면에서는 어떻게 보일까요?
수신자가 챗봇을 열면 채팅 내역 사이에 보라색 "운영자 공지" 카드가 표시됩니다. 카드에는 공지 아이콘(📢), "운영자 공지" 표시, NOTICE 배지, 그리고 메시지 내용이 담겨 있습니다. 수신자는 챗봇으로 바로 답장을 남길 수 있습니다.

발송 이력 확인

HI 공지발송 → 발송 이력을 선택하면 그동안 보낸 모든 공지 목록이 표시됩니다.

항목설명
전체/퍼널/공유 배지해당 공지의 발송 대상 타입
발송 일시공지를 보낸 날짜와 시간
제목 / 메시지 미리보기공지 내용 요약
📨 발송 N명총 발송 수신자 수
👁 읽음 N명(%)공지를 읽은 수신자 수와 읽음률
↩ 응답 N명(%)챗봇으로 답장한 수신자 수와 응답률

공지 상세 통계

이력 목록에서 특정 공지를 클릭하면 상세 통계 화면이 열립니다.

  • 📊
    발송 / 읽음 / 응답 통계 바
    각 항목의 비율이 막대 그래프로 시각화됩니다. 읽음률과 응답률을 한눈에 파악할 수 있습니다.
  • 👥
    수신자별 목록 (탭 필터)
    전체 / 응답 / 읽음 / 미읽음 탭으로 필터링하여 수신자별 상태를 개별 확인할 수 있습니다.
    각 수신자 카드에는 이름, 연락처, 답장 미리보기, 읽음/응답 여부가 표시됩니다.
💡 활용 팁
응답률이 높은 메시지 유형을 파악해 다음 공지에 활용하세요. 특히 퍼널과 공유의 응답률 차이를 비교하면 어떤 채널이 더 효과적인지 알 수 있습니다.

전체 발송 흐름

📌 마케팅 채널로서의 원챗 공지발송 흐름
  1. 명함 SMS 1회 발송 → 수신자가 챗봇 링크 클릭 → 챗봇에 등록
  2. 이후 이벤트·신제품·프로모션 공지 → 챗봇으로 무제한 무료 발송
  3. 수신자가 공지에 답장 → 운영자에게 알림 수신 → 1:1 대화 가능
  4. AI 아바타가 답변 자동화 → 운영자 없이도 24시간 응대
