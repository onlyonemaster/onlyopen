📊 대시보드 & 분석

원챗 대시보드는 챗봇 운영 현황을 실시간으로 파악하고, AI가 분석한 대화 데이터를 기반으로 운영 의사결정을 지원하는 종합 관제 화면입니다.

대시보드 접속 방법

  • 1
    원챗 상단 아바타 이미지 클릭 → [📊 대시보드] 선택
    또는 사이드바(☰) → [대시보드] 메뉴를 클릭합니다.
  • 2
    대시보드 전용 화면이 열립니다
    아래 주소로 직접 접속도 가능합니다.
    https://kiam.kr/aimessage/onechat/dashboard.html

KPI 요약

🤖
AI 승인 대기
AI가 제안한 응답 중 운영자 승인이 필요한 항목 목록 및 처리
💬
대화 분석

① KPI 요약 패널

오늘 챗봇 운영 상태를 숫자로 빠르게 파악합니다.

지표설명판단 기준
총 방문자 오늘 챗봇 링크에 접속한 고유 방문자 수 전일 대비 증감 표시
대화 참여율 방문자 중 실제로 AI와 대화를 시작한 비율(%) 80% 이상 → 우수 / 50% 이하 → 개선 필요
미읽음 건수 운영자가 아직 확인하지 않은 새 메시지 수 즉시 처리 필요 항목 강조 표시
직접 연결 요청 방문자가 AI 대신 운영자 직접 대화를 요청한 건수 우선 처리 항목
AI 자동 처리율 전체 대화 중 AI가 단독으로 처리 완료한 비율 높을수록 운영 효율 우수
AI 승인 대기 운영자 승인이 필요한 AI 제안 응답 건수 0이면 모두 처리 완료

② AI 승인 대기 패널

원챗은 AI 처리 방식을 5단계 자율도로 운영합니다. 단계에 따라 운영자 개입 범위가 달라집니다.

단계모드명동작 방식
1단계 AI 즉시 실행 AI가 판단·응답·발송까지 완전 자동 처리. 승인 불필요
2단계 AI 제안 → 승인 AI가 응답 초안 작성 후 운영자 승인 대기. 승인 시 발송
3단계 의사결정 AI가 분석만 제공, 운영자가 발송 여부 최종 결정
4단계 직접 처리 운영자가 직접 응답 작성 및 발송
5단계 보류 즉각 처리 불필요. 나중에 처리 예정으로 보류

승인 대기 항목 처리 방법

  • 1
    대기 목록에서 항목을 클릭합니다
    방문자 이름, AI 제안 응답 내용, 대화 맥락이 표시됩니다.
  • 2
    처리 방식을 선택합니다
    버튼동작
    ✅ 승인AI 제안 응답을 그대로 발송
    ✏️ 수정 후 승인내용을 수정한 뒤 발송
    ⏸ 보류나중에 처리 (보류 목록으로 이동)
    🙋 직접 대응내가 직접 채팅창에서 응답
💡 긴급 항목: 불만 표현·VIP 고객·전화/계약 요청이 감지된 대화는 빨간색으로 강조 표시됩니다. 즉시 처리를 권장합니다.

③ 대화 분석 패널

AI가 챗봇 대화 전체를 분석하여 의도·감정·키워드·이슈를 자동으로 추출합니다. [대화 분석 실행] 버튼을 클릭하면 분석이 시작됩니다.

의도(Intent) 분류

의도 유형설명대응 방법
FAQ / 단순 안내자주 묻는 일반 질문AI 아바타 학습 데이터 보강
전화 / 계약직접 통화·계약 의향 표현즉시 운영자 직접 대응
불만 / VIP불만족 표현 또는 중요 고객우선 처리, 감정 케어
재발송 / 이벤트이전 메시지 재문의·이벤트 참여AI 동행 또는 시나리오 캠페인 연결
의도 불명확AI가 의도 판단 불가프롬프트 개선 또는 직접 대응

감정(Sentiment) 분포

전체 대화의 감정 분포를 긍정 / 중립 / 부정으로 시각화합니다.

지표의미
긍정 비율 높음챗봇 만족도 우수. 현재 프롬프트·학습 데이터 유지
부정 비율 증가프롬프트 또는 학습 데이터 개선 필요. 자주 묻는 FAQ 추가 검토
중립 대부분단순 정보 조회 위주. 전환율 향상 위해 CTA 강화 필요
📌 분석 주기
대화 분석은 실시간이 아닌 [대화 분석 실행] 버튼 클릭 시 수동으로 실행됩니다. 데이터 축적 후 주 1회 이상 실행을 권장합니다.

⑤ 경영 요약 (AI 리포트)

AI가 오늘의 챗봇 운영 상태를 자연어로 요약한 리포트입니다. 대시보드 상단에서 확인할 수 있습니다.

💡 경영 요약 예시
"오늘 방문자 24명 중 18명(75%)이 대화에 참여했습니다. AI가 15건을 자동 처리하고 있습니다. 미읽음 3건, 직접 연결 요청 1건이 있습니다. 승인 대기 2건이 있어 확인이 필요합니다. 대화 참여율 75% — 참여율이 양호한 수준입니다."
📌 경영 요약은 5분마다 자동 갱신됩니다. 수동 갱신이 필요하면 페이지를 새로고침하세요.

실시간 갱신

대시보드 데이터는 5분마다 자동으로 갱신됩니다.

갱신 방식설명
자동 갱신5분 간격으로 전체 데이터 자동 로드
수동 갱신페이지 새로고침 (F5 또는 브라우저 새로고침)
대화 분석[대화 분석 실행] 버튼 클릭 시 즉시 분석 실행

대시보드 활용 팁

💡 매일 아침 체크리스트
1. 미읽음 / 직접 연결 요청 건수 확인 → 즉시 처리
2. AI 승인 대기 목록 처리
3. 경영 요약으로 어제 대비 방문자·참여율 변화 파악
4. 주 1회 대화 분석 실행 → 부정 감정·불명확 의도 개선
⚠️ 로그인 세션 만료 시
"로그인이 필요합니다" 메시지가 표시되면 kiam.kr에 다시 로그인 후 대시보드를 새로고침하세요.
