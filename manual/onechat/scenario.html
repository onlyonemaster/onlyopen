🎯 시나리오 캠페인 설정

운영자가 하나의 목적을 입력하면, AI가 유입 메시지부터 챗봇 대화 · 후속 관리 · AI 동행 · 상품 소개까지 전 과정을 자동으로 설계해주는 기능입니다.

시나리오 시스템이란?

기존 원챗은 챗봇 링크를 공유하면 AI가 일반 프롬프트로 자동 응답하는 구조입니다. 시나리오 캠페인 시스템(OSCS)은 여기서 한 단계 더 나아가, 유입 채널부터 상품 전환까지 하나의 흐름으로 연결합니다.

🔗
맥락 승계
카카오·SMS 등 유입 채널 메시지와 챗봇 대화 내용이 자동으로 연결됩니다
🤖
AI 설계
운영자가 목적만 입력하면 AI가 전체 캠페인 흐름 초안을 자동 생성합니다
🔄
후속 자동화
대화 종료 후 상태별 후속 메시지와 AI 동행이 자동으로 연결됩니다
🛍
상품 전환
대화 흐름 안에서 자연스럽게 상품을 소개하고 외부 쇼핑몰로 연결합니다

진입 방법

  • 1
    원챗 화면에서 ☰ 햄버거 메뉴를 엽니다
    화면 상단 왼쪽의 ☰ 버튼을 탭하면 사이드바 메뉴가 열립니다.
  • 2
    「대시보드」 바로 아래 「시나리오 설정」을 선택합니다
    시나리오 목록 화면이 열립니다. 기존에 만든 시나리오가 있으면 카드로 표시됩니다.
  • 3
    「＋ 새 시나리오」 버튼을 눌러 시작합니다
    STEP 1부터 5단계 설계 화면이 순서대로 진행됩니다.

시나리오 상태

상태설명
초안 작성 중인 시나리오. 아직 챗봇에 적용되지 않은 상태
활성 현재 챗봇에 적용 중인 시나리오. 챗봇 1개당 1개만 활성화 가능
일시정지 다른 시나리오가 활성화되어 자동으로 일시정지된 상태
📌 챗봇 1개당 활성 시나리오는 1개만 유지됩니다. 새 시나리오를 활성화하면 기존 활성 시나리오는 자동으로 일시정지됩니다.

5단계 설계 흐름

시나리오는 아래 5단계를 순서대로 진행하며 완성합니다. 각 단계는 이전 단계의 결과가 자동으로 전달됩니다.

1
📣 유입 메시지 설계
카카오·SMS·SNS 등 외부 채널에서 사용자를 챗봇으로 유입시킬 메시지를 AI로 생성합니다.
캠페인 목적 입력 채널별 메시지 자동 생성
2
💬 챗봇 캠페인 설계
도입→전개→선택 유도→마무리 4단계 대화 흐름을 AI와 함께 설계하고 시스템 프롬프트로 변환합니다.
STEP 1 목적 자동 전달 대화 흐름 + 프롬프트 생성
3
🔄 후속 관리 설계
대화 종료 후 사용자 상태(관심 있음 / 미응답 / 전환 완료)에 따라 다른 후속 메시지를 AI로 설계합니다.
사용자 상태 조건 설정 상태별 후속 대화 시나리오
4
❤️ AI 동행 설계
기존 AI 동행 기능과 연결해 시나리오 목적에 맞는 장기 관계 유지 전략을 설계합니다.
동행 목적·주기 설정 동행 정책 프롬프트 + 샘플 메시지 Gn_companion_config 자동 연동
5
🛍 AI 상품 소개 설계
대화 흐름 안에서 자연스럽게 상품을 소개하고 외부 쇼핑몰(스마트스토어·쿠팡·자사몰 등)로 전환합니다.
상품명·가격·혜택·링크 입력 소개 문장 3가지 + 링크 유도 문구

STEP 1 — 유입 메시지 설계

STEP 1외부 채널(카카오, SMS, SNS 등)을 통해 사용자를 챗봇으로 유입시키는 메시지를 AI로 자동 생성하는 단계입니다.

입력 항목

항목설명필수
캠페인 목적이 캠페인으로 무엇을 이루고 싶은지 한 문장으로 입력✅ 필수
타깃 고객메시지를 받을 대상 설명 (예: 30~40대 건강에 관심 있는 여성)권장
채널 선택카카오 채널 / 친구톡 / SMS / 인스타 / 페이스북 / 블로그 / 이메일 / QR 등 복수 선택✅ 필수
톤 선택친근 / 전문 / 긴급 / 감동 중 1가지✅ 필수
행동 유도 문구(CTA)예: "지금 확인하기", "무료 상담 받기"선택

AI 생성 결과

결과물설명
짧은 메시지40자 이내 — 카카오 친구톡, 배너 등에 적합
보통 메시지80~120자 — SMS·LMS에 적합
긴 메시지200자 이상 — 블로그·이메일·SNS 본문에 적합
채널별 최적화선택한 채널마다 글자 수·형식에 맞춘 버전
해시태그 추천SNS 채널 선택 시 자동 추천 (인스타·밴드 등)
이모지 포함 버전이모지를 활용한 감성 메시지 버전
💡 마음에 드는 메시지를 채택(✔)한 후 STEP 2로 이동하세요. 최소 1개를 채택해야 다음 단계로 진행할 수 있습니다. 채택된 메시지는 HI 공지발송 도구와도 연동됩니다.

STEP 2 — 챗봇 캠페인 설계

STEP 2방문자가 챗봇에 진입했을 때의 대화 흐름 전체를 도입 → 전개 → 선택 유도 → 마무리 4단계로 AI가 설계합니다.

대화 4단계 구조

단계역할예시
① 도입방문자 맞이 인사, 방문 맥락 확인"안녕하세요! 건강 정보 문자 보내드렸는데 혹시 받아보셨나요?"
② 전개핵심 메시지 전달, 관심 유발"요즘 면역력 관리에 관심 있으신 분들이 많더라고요. 혹시 어떤 부분이 가장 신경 쓰이세요?"
③ 선택 유도사용자 선택 유도 (버튼·질문)"1. 면역력 높이기 2. 피로 회복 3. 수면 개선 — 어떤 걸 더 알아보고 싶으세요?"
④ 마무리결론 + 다음 행동 안내"딱 맞는 제품을 찾아드릴게요! 아래 링크에서 확인해보세요 👇"
📌 STEP 2에서 완성된 대화 흐름은 시스템 프롬프트로 변환되어, 시나리오 활성화 시 챗봇의 AI 응답 엔진에 자동 주입됩니다. 기존 프롬프팅 설정 위에 시나리오 레이어가 덧씌워지는 방식이므로 기존 설정은 유지됩니다.

STEP 3 — 후속 관리 설계

STEP 3첫 챗봇 대화가 끝난 후, 방문자의 반응 상태에 따라 자동으로 다른 후속 메시지를 보내는 흐름을 설계합니다.

후속 대상 유형 (3가지)

유형조건후속 전략 예시
🟢 관심 있음대화를 완료하고 선택지를 클릭한 방문자더 깊은 정보 제공, 상품 소개 유도
🟡 미응답링크를 클릭했지만 대화를 시작하지 않은 방문자가벼운 재접근 메시지, 다른 채널 안내
🔵 전환 완료상품 링크를 클릭하거나 구매 완료한 방문자감사 메시지, 리뷰 요청, 재구매 유도
💡 후속 메시지는 AI가 초안을 생성하고, 운영자가 수정·확정합니다. 확정된 후속 메시지는 발신탭(퍼널)의 방문자 상태 변화에 따라 자동으로 발송됩니다.

STEP 4 — AI 동행 설계

STEP 4기존 AI 동행 기능과 연동하여, 시나리오 목적에 맞는 장기 관계 유지 전략을 설계합니다.

설정 항목

항목설명
동행 목적AI 동행 메시지의 방향성 (예: 건강 정보 지속 제공, 제품 재구매 유도)
발동 조건동행 메시지를 보낼 트리거 (예: 대화 후 3일 경과, 미응답 상태 지속)
대화 주제AI 동행이 다룰 주요 주제 목록
메시지 스타일친근·전문·감성·정보형 중 선택
전송 간격최소 2일 ~ 최대 30일 (1일 미만 설정 불가)
허용 시간대동행 메시지 발송 가능 시간 범위
종료 조건동행을 멈출 조건 (예: 전환 완료, 최대 5회 발송 후)
📌 시나리오를 비활성화하면 AI 동행 설정도 원래 기본 설정으로 자동 복구됩니다. 이미 진행 중인 동행 스케줄은 다음 사이클부터 새 정책이 적용됩니다.

STEP 5 — AI 상품 소개 설계

STEP 5대화 흐름 안에서 상품을 자연스럽게 소개하고 외부 쇼핑몰로 연결하는 문장을 AI로 생성합니다. 이 단계를 완료하면 「시나리오 활성화」 버튼이 활성화됩니다.

입력 항목

항목설명
상품명소개할 상품 또는 서비스명 (필수)
상품 설명상품의 특징과 혜택 요약
핵심 혜택고객에게 강조할 혜택 목록 (최대 5가지)
가격 / 할인율현재 판매 가격 및 할인 정보
외부 링크스마트스토어 / 쿠팡 / 자사몰 URL
삽입 시점대화 중반 / 선택 후 / 마무리 시 / AI 자동 판단
소개 강도1(최저)~5(최고) — 강도 5는 과도한 판매 유도 경고 표시

AI 생성 결과

결과물설명
소개 문장 3가지소개 강도·삽입 시점에 맞는 버전 3가지 생성
대화 삽입 완성 문장챗봇 대화에 그대로 사용할 수 있는 완성 문장
링크 유도 문구"지금 확인하기 👉 [링크]" 형태의 CTA 문구
💡 상품은 최대 5개까지 등록할 수 있으며, 드래그로 우선순위를 조정합니다. 등록된 상품 정보는 저장되어 다음 시나리오에서도 재사용할 수 있습니다.

시나리오 활성화

STEP 5까지 완료되면 「시나리오 활성화」 버튼이 활성화됩니다. 버튼을 누르면 아래 작업이 자동으로 실행됩니다.

자동 실행 작업설명
챗봇 프롬프트 주입STEP 2에서 설계한 캠페인 프롬프트가 AI 응답 엔진에 적용됨
AI 동행 정책 업데이트STEP 4에서 설계한 동행 정책이 Gn_companion_config에 반영됨
챗봇 링크 생성시나리오 태그가 포함된 전용 링크 (?sc=시나리오ID) 자동 생성
기존 시나리오 일시정지동일 챗봇의 다른 활성 시나리오는 자동으로 일시정지
📌 시나리오 비활성화 시 챗봇은 기존 프롬프팅 설정(프롬프팅 설정 매뉴얼)으로 자동 복구됩니다.

핵심 설계 원칙

#원칙설명
1 기존 시스템 비침습 기존 원챗 소스를 최소한으로 수정합니다. 신규 테이블·모듈·API만 추가하고, 수정 시에는 기존 로직 위에 레이어를 덧입히는 방식
2 단계 독립 & 데이터 자동 연결 각 단계(STEP 1~5)는 독립적으로 작동하지만, 이전 단계의 결과가 다음 단계로 자동 전달됩니다. 같은 내용을 두 번 입력할 필요 없음
3 AI가 이끄는 설계 운영자는 방향과 목적만 입력하면 됩니다. AI가 초안을 생성하고 운영자는 수정 요청을 반복하며 확정
