접속 & 화면 구성

원챗에 처음 접속하는 방법과 각 화면의 구성 요소를 설명합니다.

1단계: kiam.kr 로그인

  • 1
    kiam.kr에 접속합니다
    웹 브라우저 주소창에 아래 주소를 입력하세요.
    https://kiam.kr
  • 2
    아이디와 비밀번호로 로그인합니다
    아이엠 회원 계정으로 로그인하세요. 아직 회원이 아니라면 회원가입 매뉴얼을 먼저 확인하세요.
📌 로그인 없이 접속하면?
"로그인이 필요합니다" 메시지가 표시됩니다. 반드시 kiam.kr에서 먼저 로그인 후 접속하세요.

2단계: 원챗 접속

  • 1
    원챗 주소로 이동합니다
    로그인 후 아래 주소를 주소창에 직접 입력하거나, kiam.kr 메뉴에서 원챗을 선택하세요.
    https://kiam.kr/aimessage/onechat/
  • 2
    스마트폰 앱 형태의 화면이 열립니다
    PC에서 접속하면 화면 중앙에 앱 형태로 표시됩니다. 스마트폰에서는 전체 화면으로 보입니다.

상단 헤더 구성

화면 맨 위에 항상 표시되는 헤더에는 4가지 버튼이 있습니다.

버튼위치역할
☰ 메뉴왼쪽사이드바 서랍을 열어 6개 주요 메뉴에 접근합니다 → 사이드바 매뉴얼
🔍 검색오른쪽채팅 목록 또는 연락처를 이름으로 검색합니다 (현재 탭에 따라 검색 대상이 바뀜)
🔔 알림오른쪽새 메시지·연결 요청 알림을 확인합니다. 새 알림이 있으면 빨간 점이 표시됩니다
👤 아바타오른쪽클릭 시 드롭다운 메뉴 오픈 → 아바타 학습·챗봇 설정·프로필·공지발송·PWA등록자·로그아웃 접근

👤 아바타 드롭다운 메뉴

오른쪽 위 아바타(이니셜 원)를 클릭하면 아래 메뉴가 나타납니다.

항목설명
🔄 동기화 아이콘AI 아바타 학습 데이터의 동기화 상태를 실시간 표시 (동기화됨 / 동기화 중 / 오류)
🧠 아바타 학습시키기PDF·텍스트·음성·일기로 AI를 학습시키는 화면으로 이동
⚙️ 챗봇 설정응답 스타일·톤·언어 등 챗봇 동작 방식 설정
👤 내 프로필 설정사진·이름·챗봇 링크·QR코드 관리
📢 HI 공지발송수신자 전체에게 공지 메시지 일괄 발송
📱 PWA 등록자앱 설치 후 전화번호를 등록한 방문자 목록 확인
🚪 로그아웃계정에서 안전하게 로그아웃
🔄 동기화 아이콘이란?
AI 아바타에게 새로운 내용을 학습시킨 후 그 데이터가 챗봇에 적용되는 상태를 아이콘으로 보여줍니다.
• 🔄 회전 중 = 지금 동기화가 진행 중입니다 (잠시 기다리세요)
• ✅ 체크 = 동기화 완료, AI가 최신 내용으로 응답 중
• ⚠️ 느낌표 = 동기화 오류 — 학습 화면에서 다시 시도 필요

하단 탭 구성

화면 아래에 4개 탭이 있습니다. 탭을 눌러 화면을 전환합니다.

🏠
홈
kiam.kr 메인 페이지로 이동합니다
📤
발신
내가 SMS로 챗봇 링크를 보낸 상대(퍼널) + 공유 링크 방문자를 함께 관리합니다
💬
채팅 (기본)
kiam.kr 회원 간 1:1·그룹 DM 대화 목록입니다. 앱을 열면 이 탭이 먼저 보입니다
📥
수신
카카오·SNS·QR코드 등 공유 링크를 통해 먼저 접속한 방문자 목록입니다. 구독 중인 챗봇을 관리합니다
탭아이콘주요 사용 상황
홈🏠kiam.kr 메인으로 이동할 때
발신📤 (깔때기)SMS로 보낸 퍼널 수신자 응답 현황 확인 + 공유 링크 방문자 보기
채팅💬회원 간 DM 대화 목록 — 1:1 / 그룹 채팅
수신📥 (받은편지함)내 챗봇 공유 링크로 접속한 신규 방문자 — DM 전환·PWA 설치 유도

📤 발신 탭 — 퍼널 / 공유 전환

발신 탭 상단에는 퍼널과 공유 두 개의 전환 버튼이 있습니다.

버튼표시 대상데이터 출처
🔽 퍼널 (기본) 내가 SMS·문자로 챗봇 링크를 발송한 수신자 목록 문자 발송 캠페인 DB (Gn_aievent_request)
🔗 공유 카카오·SNS·QR 등 공유 링크를 클릭하여 방문한 방문자 목록 링크 방문 구독 DB (Gn_visitor_subscriptions)
💡 퍼널 모드에서는 전체·대화중·미사용 필터를 사용합니다.
공유 모드로 전환하면 전체·대화중·미대화 필터가 나타나고, 방문자 ID와 마지막 메시지가 표시됩니다.
→ 발신탭 상세 매뉴얼 보기

📥 수신 탭 — 필터 & 기능

수신 탭에는 4개의 필터 칩이 있어 방문자를 분류해 볼 수 있습니다.

필터표시 내용
전체구독 중인 모든 방문자
대화중AI 챗봇과 한 번 이상 대화한 방문자
미대화구독만 하고 아직 대화하지 않은 방문자
DM전환됨운영자가 직접 DM 대화로 전환한 방문자
💡 각 방문자 카드에는 챗봇 링크 복사 버튼이 있어 해당 방문자 전용 링크(?v=방문자ID)를 클릭 한 번에 복사할 수 있습니다.
→ 수신탭 상세 매뉴얼 보기
💡 처음 사용할 때는
채팅 탭(회원 DM 대화)과 수신 탭(신규 방문자)을 가장 많이 사용하게 됩니다.
