📥 수신(공유)탭 사용법

카카오톡·SNS·QR코드 등 공유 링크를 통해 직접 접속한 방문자를 관리하는 탭입니다. DM 전환, PWA 설치 유도 등 다양한 기능을 제공합니다.

수신탭이란?

수신탭은 내 챗봇 공유 링크를 클릭해 먼저 찾아온 방문자들의 목록입니다. 운영자가 직접 발송한 SMS 퍼널과 달리, 카카오·SNS·명함·홈페이지 등 다양한 채널에서 유입된 방문자를 한 곳에서 관리합니다.

👥
방문자 구독 관리
공유 링크로 접속한 방문자가 챗봇을 구독하면 이 탭에 자동 등록됩니다
💬
DM 전환
방문자와 더 깊은 관계를 원할 때 1:1 DM 채팅으로 전환할 수 있습니다
📱
PWA 설치 유도
방문자에게 챗봇을 홈 화면에 추가하도록 유도해 재방문율을 높입니다
🔗
방문자 전용 링크
각 방문자에게 고유한 링크(?v=ID)를 복사해 개별 안내할 수 있습니다

화면 구성

수신탭 화면은 위에서부터 검색바 → 통계바 → 필터 칩 → 목록 순서로 구성됩니다.

통계 바

표시 항목설명
전체 N명현재 구독 중인 방문자 전체 수
대화중 N명한 번 이상 대화한 방문자 수
미대화 N명구독만 하고 아직 대화하지 않은 방문자 수

필터 칩 (4가지)

필터 칩표시 내용
전체구독 중인 모든 방문자 (DM 전환된 사람 제외)
대화중AI 챗봇과 한 번 이상 대화한 방문자
미대화구독했으나 아직 대화하지 않은 방문자
DM전환됨운영자가 DM 채팅으로 전환한 방문자 (수신탭에서 제외 후 DM탭으로 이동)

방문자 카드 구성

각 방문자는 카드 형태로 표시됩니다.

카드 요소설명
아바타 (색상+이니셜)방문자 ID 기반 자동 생성 색상 · 닉네임 첫 글자
💬 대화 인디케이터대화한 적 있는 방문자는 아바타에 파란 대화 아이콘이 표시됨
닉네임자동 생성 닉네임 (예: 파란고양이) 또는 운영자가 직접 지정한 이름
챗봇 링크 버튼해당 방문자 전용 링크 복사 (?v=방문자ID)
N회 배지대화 횟수
방문자 ID8자리 고유 식별 코드 (예: WGGTOBPX)
챗봇 이름방문자가 사용한 챗봇 이름
전화번호PWA 설치 시 등록한 전화번호 (파란색으로 표시)
마지막 메시지가장 최근 대화 내용 미리보기 (🤖 AI 응답 / 사용자 메시지 구분)
✏️ 이름 수정 버튼방문자 닉네임을 운영자가 직접 지정

대화중 / 미대화 그룹 구분

목록은 자동으로 두 그룹으로 나뉩니다.

그룹조건
💬 대화중 · N명chat_count > 0 — 챗봇과 대화한 적 있는 방문자
🕐 미대화 · N명chat_count = 0 — 구독만 하고 아직 대화 없음

PWA 앱 설치 유도

방문자가 챗봇과 일정 횟수 이상 대화하면, 챗봇 화면 안에서 홈 화면에 추가 안내 카드가 자동으로 표시됩니다.

PWA 설치 흐름

  • 1
    방문자가 챗봇과 대화를 이어갑니다
    일정 메시지 수(시스템 기준)를 넘으면 챗봇 화면 하단에 PWA 설치 안내 카드가 나타납니다.
  • 2
    방문자가 "홈 화면에 추가" 버튼을 탭합니다
    스마트폰 홈 화면에 챗봇 아이콘이 추가됩니다. 이후 앱처럼 바로 실행할 수 있습니다.
  • 3
    (선택) 전화번호를 등록합니다
    PWA 설치 카드에서 전화번호를 입력하면 운영자의 원챗에서 해당 방문자 카드에 전화번호가 표시됩니다.
  • 4
    운영자 원챗 → 아바타 메뉴 → "PWA 등록자"에서 목록 확인
    아바타 드롭다운 메뉴의 📱 PWA 등록자를 클릭하면 앱을 설치하고 전화번호를 등록한 방문자 전체 목록을 볼 수 있습니다.
📌 PWA란?
Progressive Web App — 웹페이지를 스마트폰 홈 화면에 앱처럼 추가하는 기술입니다. 별도 앱스토어 설치 없이 아이콘 한 번으로 챗봇을 바로 실행할 수 있습니다. iOS Safari와 Android Chrome 모두 지원합니다.

PWA 등록자 관리 패널

아바타 드롭다운 → 📱 PWA 등록자를 클릭하면 별도 패널이 열립니다.

패널 기능설명
이름·전화번호·방문자ID 검색등록된 정보로 빠르게 방문자를 찾을 수 있습니다
방문자 목록PWA 설치 + 전화번호 등록한 방문자 전체 목록
전화번호 표시등록한 전화번호가 파란색으로 표시됩니다
마지막 방문 시간가장 최근에 챗봇을 방문한 시각

DM 채팅으로 전환

방문자와 더 깊은 관계를 원하거나, 공개 챗봇 대화가 아닌 1:1 개인 채팅으로 전환하고 싶을 때 사용하는 기능입니다.

📌 DM 전환이란?
수신탭의 방문자를 kiam.kr 회원 DM 채팅방으로 연결하는 기능입니다. 전환 후 해당 방문자는 수신탭에서 제거되고 DM전환됨 필터에서만 확인할 수 있습니다.

DM 전환 방법

  • 1
    수신탭에서 방문자 카드를 클릭해 채팅창을 엽니다
    방문자와의 챗봇 대화 내용이 표시됩니다.
  • 2
    채팅창 상단 메뉴에서 "DM 전환" 옵션을 선택합니다
    DM 방 생성 여부를 확인하는 다이얼로그가 표시됩니다.
  • 3
    확인하면 DM 채팅방이 생성됩니다
    채팅탭에 새 DM 방이 생성되고, 방문자는 수신탭의 DM전환됨 필터로 이동합니다.
💡 DM 전환 후에도 방문자는 기존 챗봇 링크(?v=방문자ID)로 다시 챗봇에 접속할 수 있습니다. DM 전환은 운영자 측 관리 상태를 변경하는 것이며, 방문자 경험에는 영향을 주지 않습니다.

방문자 전용 링크 복사

각 방문자 카드에는 챗봇 링크 버튼이 있어, 해당 방문자에게만 적용되는 개인화된 링크를 복사할 수 있습니다.

항목설명
링크 형태chatbot.kiam.kr/s/onechat1?v=WGGTOBPX
복사 방법카드의 챗봇 링크 버튼 클릭 → 클립보드에 자동 복사
활용특정 방문자에게 링크를 재발송 시, 기존 대화 기록과 연결됨
💡 방문자 전용 링크(?v=)와 일반 공유 링크의 차이
• 일반 공유 링크 /s/onechat1: 새 방문자로 등록 (새 대화 시작)
• 방문자 전용 링크 /s/onechat1?v=WGGTOBPX: 해당 방문자의 기존 대화에 이어짐

방문자 이름 지정

방문자에게는 자동으로 닉네임이 배정되지만, 운영자가 직접 이름을 지정할 수 있습니다.

  • ✏️
    카드 오른쪽 ✏️ 버튼을 클릭합니다
    이름 입력 팝업이 열립니다. 원하는 이름을 입력하고 확인하면 저장됩니다.
