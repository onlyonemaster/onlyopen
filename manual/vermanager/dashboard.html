📊 대시보드

메인 대시보드는 선택된 사이트의 버전 정보, KPI, 빠른 릴리즈 액션, 최근 이력을 한 화면에 제공합니다.

🌐 사이트 선택기 (상단)

여러 사이트가 등록된 경우, 드롭다운으로 조회할 사이트를 전환할 수 있습니다. URL 파라미터 ?site=kiam-prod로 직접 지정도 가능합니다. 기본값은 첫 번째 활성 사이트입니다.

🚀 빠른 릴리즈 버튼 (3종)

대시보드에서 바로 릴리즈를 실행할 수 있습니다:

🟢 PATCH🟡 MINOR🔴 MAJOR

클릭 시 api/release.php로 POST 요청이 전송되고, 버전이 자동 범핑(bump)됩니다.

// 프론트엔드에서 호출
fetch('/vermanager/api/release', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    site: 'kiam-prod',
    type: 'patch',
    note: '자동 릴리즈'
  })
})

최근 릴리즈 이력 + 개선사항 목록

대시보드 하단에는 최신 릴리즈 이력과 등록된 개선사항이 표시됩니다. 「전체보기」링크로 각각 history, improvements 페이지로 이동할 수 있습니다.
