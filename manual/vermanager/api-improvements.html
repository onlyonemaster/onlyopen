🔧 소스 개선사항 API (api/improvements.php)

소스 개선 항목의 CRUD를 담당하는 다중 사이트 지원 API입니다. GET/POST/DELETE 메서드를 지원하며 사이트별 독립된 improvements.json 파일을 읽고 씁니다.

GET /vermanager/api/improvements?site=kiam-prod
GET /vermanager/api/improvements?site=all
POST /vermanager/api/improvements
DELETE /vermanager/api/improvements?id=imp_xxx&site=kiam-prod

GET 파라미터

파라미터타입필수설명
sitestring선택사이트 ID. all이면 모든 사이트의 개선사항 병합 반환. 생략 시 현재 선택된 사이트 기준.

서버 처리 로직 (완전 추적)

// ── GET 처리 ──
if ($method === 'GET') {
    $site_id = $_GET['site'] ?? get_current_site_id();

    if ($site_id === 'all') {
        // 모든 활성 사이트 순회 → improvements.json 병합
        $all_data = [];
        foreach (get_active_sites() as $sid => $s) {
            $imps = site_read_json($sid, 'improvements.json');
            foreach ($imps as $imp) {
                $imp['site_id'] = $sid;
                $imp['site_name'] = $s['name'] ?? $sid;
                $all_data[] = $imp;
            }
        }
        return json_encode(['ok'=>true,'mode'=>'all','data'=>$all_data,'total'=>count($all_data)]);
    }

    // 특정 사이트
    if (!get_site($site_id)) { return error_json('사이트를 찾을 수 없습니다.'); }
    $data = site_read_json($site_id, 'improvements.json');
    $unreleased = count(array_filter($data, fn($i) => empty($i['released_in'])));
    return json_encode(['ok'=>true,'site_id'=>$site_id,'data'=>$data,'total'=>count($data),'unreleased'=>$unreleased]);
}

// ── POST 처리 ──
if ($method === 'POST') {
    $input = json_decode(file_get_contents('php://input'), true);
    $site_id = $input['site'] ?? null;
    validate_site($site_id);

    $new_imp = [
        'id'         => uniqid('imp_'),            // 고유 ID 생성
        'title'      => $input['title'],
        'category'   => $input['category'],
        'content'    => $input['content'],
        'date'       => date('Y-m-d'),
        'created_at' => date('c'),
        'released_in'=> null,                      // 아직 릴리즈 안 됨
    ];

    $current = site_read_json($site_id, 'improvements.json');
    $current[] = $new_imp;
    site_write_json($site_id, 'improvements.json', $current);

    return json_encode(['ok'=>true,'site_id'=>$site_id,'id'=>$new_imp['id'],'message'=>'✅ 새로운 개선사항이 추가되었습니다.']);
}

// ── DELETE 처리 ──
if ($method === 'DELETE') {
    $site_id = $_GET['site'] ?? null;
    $imp_id = $_GET['id'] ?? null;
    validate_site($site_id);

    $current = site_read_json($site_id, 'improvements.json');
    $current = array_values(array_filter($current, fn($i) => $i['id'] !== $imp_id));
    site_write_json($site_id, 'improvements.json', $current);

    return json_encode(['ok'=>true,'message'=>'✅ 개선사항이 삭제되었습니다.']);
}
💡 핵심 포인트: POST로 등록된 개선사항의 released_in 필드는 null입니다. 이후 릴리즈 API가 실행될 때 해당 버전으로 채워집니다. site=all 모드는 모든 활성 사이트의 improvements.json을 읽어 하나의 배열로 병합하며, 각 항목에 site_id와 site_name을 추가합니다.
