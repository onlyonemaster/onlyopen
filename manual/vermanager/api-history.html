📜 버전 히스토리 API (api/history.php)

사이트별 또는 전체 사이트의 버전 변경 이력을 조회합니다. 릴리즈 유형(major/minor/patch)으로 필터링하고 개수 제한을 둘 수 있습니다.

GET /vermanager/api/history?site=kiam-prod
GET /vermanager/api/history?site=all
GET /vermanager/api/history?site=kiam-prod&type=patch&limit=5

GET 파라미터

파라미터타입필수설명
sitestring선택사이트 ID. all이면 모든 사이트의 히스토리 병합 반환. 기본값: 현재 선택 사이트.
typestring선택필터: major | minor | patch. 지정 시 해당 유형만 반환.
limitint선택결과 개수 제한. 지정하지 않으면 전체 반환.

서버 처리 로직 (완전 추적)

// 1) site=all — 전체 사이트 병합
if ($site_id === 'all') {
    $all_data = [];
    foreach (get_active_sites() as $sid => $s) {
        $history = site_read_json($sid, 'version_history.json');
        foreach ($history as $entry) {
            $entry['site_id'] = $sid;
            $entry['site_name'] = $s['name'] ?? $sid;
            $all_data[] = $entry;
        }
    }
    // 날짜 기준 정렬 (최신순)
    usort($all_data, fn($a, $b) => ($b['date'] ?? '') <=> ($a['date'] ?? ''));

    // type 필터 적용
    if ($filter_type) {
        $all_data = array_filter($all_data, fn($e) => ($e['type'] ?? '') === $filter_type);
    }

    // limit 적용
    if ($limit > 0) {
        $all_data = array_slice(array_values($all_data), 0, $limit);
    }

    return json_encode(['ok'=>true,'mode'=>'all','data'=>array_values($all_data),'total'=>count($all_data)]);
}

// 2) 단일 사이트
if (!get_site($site_id)) { return error_json('사이트를 찾을 수 없습니다.'); }

$history = site_read_json($site_id, 'version_history.json');
// 최신순 정렬
usort($history, fn($a, $b) => ($b['date'] ?? '') <=> ($a['date'] ?? ''));

// type 필터
if ($filter_type) {
    $history = array_filter($history, fn($e) => ($e['type'] ?? '') === $filter_type);
}

// limit
if ($limit > 0) {
    $history = array_slice(array_values($history), 0, $limit);
}

$site = get_site($site_id);
$current_version = site_get_current_version($site_id);

return json_encode([
    'ok' => true,
    'site_id' => $site_id,
    'site_name' => $site['name'] ?? $site_id,
    'environment' => $site['environment'] ?? 'unknown',
    'current_version' => $current_version,
    'data' => array_values($history),
    'total' => count($history),
]);

사용 예시

// 최근 3개의 패치 릴리즈만 조회
curl "https://kiam.kr/vermanager/api/history?site=kiam-prod&type=patch&limit=3"

// 전체 사이트의 히스토리 (타임라인 뷰)
curl "https://kiam.kr/vermanager/api/history?site=all"

// JavaScript fetch
fetch('/vermanager/api/history?site=kiam-prod&limit=5')
  .then(r => r.json())
  .then(data => {
    data.data.forEach(entry => {
      console.log(`${entry.from} → ${entry.to} (${entry.type})`);
    });
  });
💡 핵심 포인트: 각 히스토리 항목은 linked_improvements 배열로 해당 릴리즈에 포함된 소스 개선 ID들을 추적합니다. site=all 모드는 사이트 간 히스토리를 날짜 기준으로 병합하여 전체 타임라인을 제공합니다.
