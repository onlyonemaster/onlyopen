📦 Git/GitHub 자동화 API (api/git.php)

Phase 5에서 구현된 CI/CD 자동화 API입니다. Git 커밋, 시맨틱 태그 생성, GitHub Push, 전체 릴리즈 파이프라인을 API 호출만으로 자동화합니다.

GET /vermanager/api/git?action=status&site=kiam-prod
GET /vermanager/api/git?action=log&site=kiam-prod&limit=10
POST /vermanager/api/git — commit / tag / push / full-release

GET 액션

action파라미터반환 정보
statussiteGit 리포 확인, 현재 브랜치, 최신 커밋, 변경 파일 목록, 최근 태그 5개, 리모트 URL
logsite, limitgit log --oneline 결과 (기본 10건)
automation-logsite자동화 작업 이력 (git_automation_log.json, 최대 100건)

POST 액션

actionBody 필드수행 작업
commitsite, messagegit add -A → git commit -m "message"
tagsite, version, notegit tag -a "v{version}" -m "note" (이미 존재 시 경고)
pushsitegit push origin {branch} --tags
full-releasesite, version, note, commit_messageCommit → Tag → Push 3단계 순차 실행. 단계별 성공/실패 추적.

서버 처리 로직 (완전 추적)

// ── git_status() ──
function git_status(string $doc_root): array {
    // 1) .git 디렉터리 존재 확인
    // 2) 현재 디렉터리 저장 → chdir($doc_root)
    // 3) git rev-parse --abbrev-ref HEAD     → 현재 브랜치
    // 4) git log -1 --format="%h %s (%ci)"   → 최신 커밋
    // 5) git status --porcelain              → 변경 파일 목록
    // 6) git tag --sort=-creatordate | head -5 → 최근 태그
    // 7) git remote get-url origin           → 리모트 URL
    // 8) chdir($cwd) 복원
}

// ── git_commit() ──
function git_commit(string $doc_root, string $message): array {
    chdir($doc_root);
    shell_exec('git add -A 2>&1');                    // 전체 스테이징
    $commit_cmd = 'git commit -m ' . escapeshellarg($message) . ' 2>&1';
    $output = shell_exec($commit_cmd);
    // nothing to commit / error: / fatal: → 실패 판단
    $new_hash = shell_exec('git log -1 --format="%h" 2>&1');
    chdir($cwd);
    return ['success'=>bool, 'new_commit'=>...];
}

// ── git_tag() ──
function git_tag(string $doc_root, string $version, string $note): array {
    chdir($doc_root);
    // 이미 존재하는 태그 확인: git tag -l 'v{version}'
    // git tag -a 'v{version}' -m 'note'
    chdir($cwd);
}

// ── git_push() ──
function git_push(string $doc_root): array {
    chdir($doc_root);
    $branch = shell_exec('git rev-parse --abbrev-ref HEAD');
    shell_exec("git push origin {$branch} --tags 2>&1");
    chdir($cwd);
}

// ── full-release (3단계) ──
// 1) git_commit() 실행
// 2) git_tag() 실행
// 3) git_push() 실행
// 각 단계 결과를 steps[] 배열에 누적
// log_git_action()으로 모든 작업을 git_automation_log.json에 기록
