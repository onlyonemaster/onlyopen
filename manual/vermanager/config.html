bump_version 로직

function bump_version(array $current, string $type): array {
    switch ($type) {
        case 'major': $next['major']++; $next['minor'] = 0; $next['patch'] = 0; break;
        case 'minor': $next['minor']++; $next['patch'] = 0; break;
        case 'patch': $next['patch']++; break;
    }
    // 예: major → minor=0, patch=0  (하위 초기화)
    //     minor → patch=0
    return $next;
}

하위호환 래퍼 (7개)

기존에 get_package(), get_improvements() 등으로 호출하던 코드가 깨지지 않도록 get_current_site_id() 기준으로 자동 연결됩니다:

get_package()          → site_get_package( get_current_site_id() )
get_current_version()  → site_get_current_version( get_current_site_id() )
get_version_history()  → site_get_history( get_current_site_id() )
get_improvements()     → site_get_improvements( get_current_site_id() )
get_changelog()        → site_get_changelog( get_current_site_id() )
write_json($file, $d)  → site_write_json( get_current_site_id(), $file, $d )
read_json($file)       → site_read_json( get_current_site_id(), $file )
💡 핵심 포인트: 모든 새로운 코드는 site_* 함수를 직접 사용하고, 기존 코드는 하위호환 래퍼를 통해 자동으로 동작합니다. get_current_site_id()는 URL ?site=xxx 파라미터 또는 첫 번째 활성 사이트를 반환합니다.
