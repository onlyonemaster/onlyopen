🌐 사이트 관리 (pages/sites.php)

사이트 등록, 수정, 비활성화를 위한 관리자 UI입니다. Add / Edit 모달과 사이트 목록 테이블을 통해 모든 사이트를 중앙 관리합니다.

페이지 구조

vm-main
├── vm-topbar: "사이트 관리" + 활성사이트/전체사이트 카운트
│
├── 통계 카드 (4개)
│   ├── 전체 사이트: $stats['total_sites']
│   ├── 운영 환경: $stats['production_sites']
│   ├── 개발 환경: $stats['development_sites']
│   └── 서버 대수: $stats['total_servers']
│
├── [ + 새 사이트 추가 ] 버튼 → addSite() → 숨겨진 form 표시
│
├── 사이트 목록 테이블
│   ├── 사이트명 | 도메인 | 환경 | 현재버전 | 릴리즈 | 서버 | 상태 | 관리
│   └── 각 행: [수정] [비활성화] 버튼
│
├── 숨겨진 "새 사이트 추가" 폼 (id="addSiteForm")
│   ├── 사이트 ID*, 사이트명*, 도메인
│   ├── 추가 도메인 (aliases, 콤마구분)
│   ├── 환경 (production/development/staging)
│   ├── 문서 루트, 앱 이름
│   ├── 서버 호스트명, 서버 IP
│   ├── 부모 사이트 (선택)
│   ├── 설명
│   └── [저장] [취소] 버튼
│
└── 숨겨진 "사이트 수정" 폼 (id="editSiteModal")
    └── 기존 데이터 prefilled + [변경사항 저장] [취소]

// ── 사이트 추가 ──
async function addSite() {
    // 1) 폼 데이터 수집 (id, name, domain, environment, document_root, ...)
    const formData = { id, name, domain, aliases, environment, document_root,
                       app_name, server_hostname, server_ip, parent_site, description };

    // 2) POST /vermanager/api/sites
    const res = await fetch('/vermanager/api/sites', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(formData)
    });
    const data = await res.json();

    // 3) 성공 시 페이지 리로드
    if (data.ok) { alert(data.message); location.reload(); }
}

// ── 변경사항 저장 ──
async function saveSiteEdit() {
    const formData = { id, name, domain, ... };
    const res = await fetch('/vermanager/api/sites', {
        method: 'PUT',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(formData)
    });
    const data = await res.json();
    if (data.ok) { alert(data.message); location.reload(); }
}

// ── 사이트 비활성화 ──
async function deactivateSite(siteId) {
    if (!confirm(`정말 '${siteId}' 사이트를 비활성화하시겠습니까?\n데이터는 보존됩니다.`)) return;

    const res = await fetch(`/vermanager/api/sites?id=${siteId}`, {
        method: 'DELETE'   // → 소프트 삭제 (status='inactive')
    });
    const data = await res.json();
    if (data.ok) { alert(data.message); location.reload(); }
}

등록 폼 필드 상세

#필드타입필수site-registry.json 경로
1사이트 IDtext필수sites.{id}.key
2사이트명text필수name
3도메인text선택domain
4환경select필수environment
5문서 루트text선택document_root
6서버 호스트text선택server_hostname
7서버 IPtext선택server_ip
8부모 사이트select선택parent_site
💡 핵심 포인트: 사이트 ID는 site-registry.json의 키(key)로 사용되며 등록 후 변경할 수 없습니다. 환경 선택에 따라 사이드바와 대시보드에서 다른 아이콘(🚀운영, 🧪개발, 📋스테이징)이 표시됩니다. 부모 사이트를 지정하면 대시보드의 site=all API에서 parent_site / child_sites 관계가 자동 탐색됩니다.
