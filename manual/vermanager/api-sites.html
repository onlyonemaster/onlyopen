🌐 사이트 등록부 CRUD API (api/sites.php)

사이트 등록부(site-registry.json)를 관리하는 완전한 RESTful CRUD API입니다. GET/POST/PUT/DELETE 메서드를 지원하며, 새 사이트 등록 시 자동으로 데이터 디렉터리와 기본 JSON 파일들을 생성합니다.

GET /vermanager/api/sites — 전체 목록
GET /vermanager/api/sites?id=kiam-prod — 특정 사이트
POST /vermanager/api/sites — 신규 등록
PUT /vermanager/api/sites — 정보 수정
DELETE /vermanager/api/sites?id=kiam-prod — 비활성화

POST 요청 Body (사이트 등록)

필드타입필수설명
idstring필수고유 사이트 ID (예: kiam-prod). 중복 불가.
namestring선택표시명 (기본값: id)
domainstring선택도메인 주소
environmentstring선택production | development | staging
document_rootstring선택서버 내 문서 루트 경로
server_hostnamestring선택서버 호스트명
server_ipstring선택서버 IP 주소
parent_sitestring선택부모 사이트 ID (운영↔개발 연결)

PUT 요청 Body (사이트 수정)

// 요청: id는 변경 불가, 나머지 필드는 부분 업데이트
{
  "id": "kiam-prod",
  "name": "kiam.kr (운영 v2)",
  "server_ip": "192.168.1.100"
}

// 응답
{
  "ok": true,
  "message": "✅ 사이트 'kiam-prod' 정보가 업데이트되었습니다.",
  "updated_fields": ["name", "server_ip"]
}

서버 처리 로직 (완전 추적)

// ── GET ──
// GET /api/sites        → get_all_sites() + 각 사이트 current_version, release_count, improvement_count 추가
// GET /api/sites?id=xxx → get_site($id) + 상세 정보 + child_sites 배열 탐색

// ── POST (사이트 생성) ──
// 1) id 유효성 검증 (필수, 중복 불가)
// 2) site-registry.json에 새 항목 추가 (status='active')
// 3) save_registry() → JSON 파일 쓰기
// 4) site_data_dir($id) 호출 → data/sites/{id}/ 디렉터리 생성
// 5) 기본 JSON 파일 생성:
//    - package.json:      {"name":"...","version":"1.0.0","lastRelease":null}
//    - version_history.json: []
//    - improvements.json: []
//    - changelog.json:    []

// ── PUT (사이트 수정) ──
// 1) id 필드 검증 (존재 확인, id 자체는 변경 불가)
// 2) 기존 데이터와 새 데이터를 array_merge
// 3) updated_at 갱신 → save_registry()

// ── DELETE (소프트 삭제) ──
// 1) id 검증
// 2) status를 'inactive'로 변경 (데이터는 보존)
// 3) save_registry()
// ※ 실제 파일 삭제는 하지 않음. 필요 시 수동 복구 가능.
💡 핵심 포인트: 사이트 등록 시 4개의 기본 JSON 파일이 자동 생성됩니다. DELETE는 완전 삭제가 아닌 소프트 삭제(status=inactive)로 처리되어 데이터 복구가 가능합니다. parent_site 필드로 운영↔개발 사이트의 부모-자식 관계를 설정할 수 있습니다.
