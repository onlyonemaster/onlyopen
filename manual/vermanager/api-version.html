📡 버전 조회 API (api/version.php)

사이트별 또는 전체 사이트의 현재 버전 정보를 JSON으로 반환하는 읽기 전용 API입니다. CORS 헤더가 포함되어 있어 외부 서비스에서도 호출 가능합니다.

GET /vermanager/api/version
GET /vermanager/api/version?site=kiam-prod
GET /vermanager/api/version?site=all

요청 파라미터

파라미터타입필수설명
sitestring선택사이트 ID. 생략 시 사용 가능한 사이트 목록과 기본 사이트 미리보기 반환. all이면 모든 활성 사이트 정보 반환.

서버 처리 로직 (정밀 추적)

// 1) config.php 로드 → 상수, 함수 사용 가능
require_once __DIR__ . '/../config.php';

// 2) JSON + CORS 헤더 설정
header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');

// 3) site 파라미터 획득
$site_id = $_GET['site'] ?? null;

// 4) site=all 분기
if ($site_id === 'all') {
    $all_sites = get_active_sites();          // site-registry.json → status=active 필터
    $result = [];
    foreach ($all_sites as $sid => $s) {
        $ver = site_get_current_version($sid);  // data/sites/{sid}/package.json 읽기
        $pkg = site_get_package($sid);
        $result[] = [
            'site_id'      => $sid,
            'site_name'    => $s['name'] ?? $sid,
            'domain'       => $s['domain'] ?? '',
            'environment'  => $s['environment'] ?? 'unknown',
            'version'      => $ver,
            'last_release' => $pkg['lastRelease'] ?? null,
            'display_string' => ($s['app_name'] ?? 'Onlyone OneChat') . ' v' . $ver['raw'],
        ];
    }
    echo json_encode([
        'ok' => true, 'mode' => 'all',
        'total' => count($result),
        'system_stats' => get_system_stats(),
        'data' => $result,
    ], JSON_UNESCAPED_UNICODE);
    exit;
}

// 5) 특정 사이트 분기
if ($site_id && get_site($site_id)) {
    $site = get_site($site_id);
    $ver = site_get_current_version($site_id);
    $pkg = site_get_package($site_id);

    // 부모-자식 사이트 연결 탐색
    $parent_id = $site['parent_site'] ?? null;
    $children = [];
    foreach (get_active_sites() as $csid => $cs) {
        if (($cs['parent_site'] ?? null) === $site_id) $children[] = $csid;
    }

    echo json_encode([
        'ok' => true, 'site_id' => $site_id,
        'site_name' => $site['name'] ?? $site_id,
        'domain'    => $site['domain'] ?? '',
        'environment' => $site['environment'] ?? 'unknown',
        'version'     => $ver,
        'package'     => $pkg,
        'parent_site' => $parent_id,
        'child_sites' => $children,
        'last_release' => $pkg['lastRelease'] ?? null,
        'display_string' => ($site['app_name'] ?? 'Onlyone OneChat') . ' v' . $ver['raw'],
    ], JSON_UNESCAPED_UNICODE);
    exit;
}

// 6) site 미지정 → 사용 가능한 목록 안내
echo json_encode([
    'ok' => true,
    'message' => 'site 파라미터를 지정해주세요.',
    'available_sites' => array_keys(get_active_sites()),
    'default_preview' => ...,
], JSON_UNESCAPED_UNICODE);

데이터 소스 추적

정보출처파일 경로
사이트 목록site-registry.json/home/vermanager/data/site-registry.json
현재 버전package.json/home/vermanager/data/sites/{id}/package.json
릴리즈 이력version_history.json/home/vermanager/data/sites/{id}/version_history.json
시스템 통계get_system_stats()site-registry.json 기준 집계
부모-자식parent_site 필드site-registry.json 내 각 사이트 항목

사용 예시

// curl로 버전 확인
curl https://kiam.kr/vermanager/api/version?site=kiam-prod

// 브라우저에서 직접 접속 가능 (JSON 뷰어 추천)
https://kiam.kr/vermanager/api/version?site=all

// JavaScript fetch
fetch('/vermanager/api/version?site=kiam-prod')
  .then(r => r.json())
  .then(data => console.log('버전:', data.display_string));
💡 핵심 포인트: 이 API는 읽기 전용이며 인증 없이 접근 가능합니다. CORS가 허용되어 있어 외부 모니터링 도구에서 현재 버전을 주기적으로 폴링할 수 있습니다. site=all 모드에서는 get_system_stats()를 통해 전체 시스템의 현황(운영/개발 사이트 수, 서버 대수)도 함께 반환합니다.
