📜 릴리즈 이력

모든 릴리즈의 버전 변경 내역을 타임라인 형태로 조회할 수 있습니다. MAJOR/MINOR/PATCH 타입별로 필터링하고, 각 릴리즈에 포함된 개선사항을 추적합니다.

이력 API (GET /api/history)

GET /vermanager/api/history?site=kiam-prod
GET /vermanager/api/history?site=kiam-prod&type=patch
GET /vermanager/api/history?site=kiam-prod&limit=5
파라미터기본값설명
site(선택된 사이트)대상 사이트 ID
typeallmajor / minor / patch
limitall최대 조회 건수

타입·개수 필터

UI에서는 필터 탭으로 전환: 전체 MAJOR MINOR PATCH

최신순 정렬, 각 항목에 MAJOR MINOR PATCH 배지가 표시됩니다.

타임라인 UI

릴리즈 이력은 좌측에 타임라인 마커가 있는 카드 형태로 표시됩니다:

 ●  2026-05-02 10:48    [PATCH]
 │  ─────────────────────────────────
 │  v1.0.0 → v1.0.1
 │  테스트 자동 릴리즈
 │  📎 linked: imp_4, imp_5 (2건)
 │
 ●  2026-05-02 09:00    [MINOR]
    ─────────────────────────────────
    v1.0.0 → v1.1.0
    신규 기능 추가

Linked Improvements 추적

각 릴리즈 항목은 linked_improvements 배열과 imp_count 필드로 연결된 개선사항을 추적합니다. 「📎」 링크로 개선사항 상세를 바로 확인할 수 있습니다.
