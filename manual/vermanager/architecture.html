🏗️ index.php 라우터 완전 분석

Apache mod_rewrite와 PHP 내장 서버를 모두 지원하는 메인 라우터의 동작 원리입니다.

라우트 결정 로직

// 1순위: Apache mod_rewrite → ?route=xxx
$route = $_GET['route'] ?? null;

// 2순위: PHP 내장 서버 → REQUEST_URI 파싱
if (!$route) {
    $uri = $_SERVER['REQUEST_URI'] ?? '/';
    $uri = parse_url($uri, PHP_URL_PATH);        // 쿼리스트링 제거
    $uri = rtrim($uri, '/');
    $uri = preg_replace('#^/vermanager#', '', $uri); // 접두사 제거
    $uri = ltrim($uri, '/');
    $route = $uri ?: 'dashboard';                // 기본값: dashboard
}

// index.php/xxx 패턴 정리
$route = preg_replace('#^index\.php/?#', '', $route);

.htaccess 설정

RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php?route=$1 [QSA,L]

실제 파일이나 디렉터리가 아니면 모두 index.php?route=xxx로 전달합니다. CSS/JS 같은 정적 자산은 그대로 서빙됩니다.

사이트 선택 메커니즘

$current_site_id = get_current_site_id();
$current_site = $current_site_id ? get_site($current_site_id) : null;

function get_current_site_id(): ?string {
    $id = $_GET['site'] ?? null;
    if ($id && get_site($id)) return $id;     // URL 지정 사이트
    
    $sites = get_active_sites();
    if (!empty($sites)) {
        return array_key_first($sites);       // 첫 번째 활성 사이트
    }
    return null;
}
💡 핵심 포인트: PHP 내장 서버(php -S localhost:8000)로도 완전히 동작합니다. .htaccess 없이 REQUEST_URI를 직접 파싱하여 라우팅합니다.
