🖥️ 원격 서버 관리 & 배포 운영 가이드

원격 서버의 상태 모니터링, 버전 배포, 사이트 간 데이터 동기화 방법을 단계별로 안내합니다.

개념: 서버 관리의 3가지 기능

기능설명API
서버 상태 진단SSH 연결성, 문서 루트 유효성, 디스크 용량 등 종합 체크GET /api/remote?action=status
버전 배포특정 버전을 서버의 문서 루트에 배포하고 version.txt 기록POST /api/remote (action=deploy)
데이터 동기화운영↔개발 환경 간 JSON 데이터 파일 복사POST /api/remote (action=sync)

1. 서버 상태 확인

UI에서 확인

  1. /vermanager/remote?site=kiam-prod 접속
  2. 서버 상태 카드가 자동 로드됨: 연결 상태, 핑 응답시간, 현재 버전, 문서 루트 체크, 디스크 용량
  3. 새로고침 버튼으로 실시간 갱신 가능

API로 확인

# 단일 서버 상태
curl https://kiam.kr/vermanager/api/remote?action=status&site=kiam-prod

# 모든 서버 일괄 확인
curl https://kiam.kr/vermanager/api/remote?action=all-servers

응답 해석

{
  "connection": "ok",        // SSH 소켓 연결 성공
  "ping": { "reachable": true, "latency_ms": 45 },
  "version_check": { "current": "1.0.1", "file_version": "1.0.1", "match": true },
  "docroot_check": {         // 문서 루트 진단
    "has_index": true,       // index.php 존재
    "has_config": true,      // config.php 존재
    "has_htaccess": true,    // .htaccess 존재
    "disk_free_mb": 4520,    // 여유 공간
    "disk_total_mb": 20480   // 전체 공간
  }
}

2. 버전 배포 실행

UI에서 배포

  1. /vermanager/remote?site=kiam-prod 접속
  2. "새 버전 배포" 섹션에서 배포할 버전 입력 (예: 1.0.2)
  3. "배포 실행" 버튼 클릭
  4. 3단계 진행 상황 실시간 확인: SSH 테스트 → 문서 루트 확인 → version.txt 기록

API로 배포

curl -X POST https://kiam.kr/vermanager/api/remote \
  -H "Content-Type: application/json" \
  -d '{"action":"deploy","site":"kiam-prod","version":"1.0.2"}'

3. 환경 간 데이터 동기화

사용 시나리오

// 운영 → 개발: 운영 데이터를 개발 환경에 복사
POST /api/remote {"action":"sync","from":"kiam-prod","to":"kiam-dev"}

// 개발 → 운영: 개발 테스트 완료 후 운영에 반영
POST /api/remote {"action":"sync","from":"kiam-dev","to":"kiam-prod"}

동기화 대상 파일: package.json, version_history.json, changelog.json, improvements.json

⚠️ 주의: 동기화는 대상 사이트의 데이터를 덮어씁니다. 운영→개발 동기화 시 개발 환경의 미발행 개선사항이 유실될 수 있으니 주의하세요.

4. 배포 로그 확인

# 배포 이력 조회
curl https://kiam.kr/vermanager/api/remote?action=deploy-log&site=kiam-prod

# 응답: 최근 100건의 배포 기록 (타임스탬프, 버전, 단계별 결과)

5. 원격 관리 페이지 (pages/remote.php)

UI 페이지 접속: https://kiam.kr/vermanager/remote?site=kiam-prod

vm-main
├── 서버 상태 카드 (자동 로드)
│   ├── 연결 상태: 🟢 접속 가능 / 🔴 접속 불가
│   ├── 응답 시간: 45ms
│   ├── 현재 버전: v1.0.1 (서버파일 일치여부 표시)
│   └── 문서 루트: /home/kiam (핵심파일 존재여부)
│
├── 디스크 정보
│   ├── 전체: 20GB
│   ├── 사용: 15.6GB
│   └── 여유: 4.4GB (22%)
│
├── [새 버전 배포] 섹션
│   ├── 배포 버전 입력: [______]
│   └── [배포 실행] 버튼 → POST /api/remote (action=deploy)
│
├── [환경 간 동기화] 섹션
│   ├── 원본 사이트: [kiam-prod ▼]
│   ├── 대상 사이트: [kiam-dev ▼]
│   └── [동기화 실행] 버튼 → POST /api/remote (action=sync)
│
└── 최근 배포 로그 (테이블)
    └── 날짜 | 사이트 | 버전 | 상태 | 상세
💡 핵심 포인트: 원격 서버 관리는 /home/vermanager/api/remote.php 파일 하나가 모든 기능(Ping, Status, Deploy, Sync, Deploy Log)을 처리합니다. action 파라미터로 기능을 구분하며, GET은 읽기 작업, POST는 쓰기 작업에 사용됩니다. 배포 로그는 100건까지 보관되고 초과 시 오래된 항목부터 자동 삭제됩니다.
