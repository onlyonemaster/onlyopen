폰문자란?

폰문자는 kiam.kr 플랫폼에서 제공하는 SMS/LMS/MMS 대량 문자 발송 서비스입니다. 웹 대시보드 또는 온리원문자 앱과 연동하여 수천 건의 문자를 한 번에 발송하고, 수신 여부와 발송 내역을 실시간으로 확인할 수 있습니다.

문자 내 링크를 클릭한 고객은 자동으로 원챗 퍼널에 등록되어 AI 챗봇 자동응답으로 이어집니다.

📌 온리원문자 앱: Android 전용 앱을 설치하면 스마트폰을 발신기로 사용하여 건당 최저 0.7원으로 문자를 발송할 수 있습니다.
→ Google Play 다운로드

주요 기능

📤
대량 문자 발송
CSV 수신자 명단 업로드 후 SMS/LMS/MMS를 한 번에 발송합니다.
🔄
일별 자동발송
DB를 날짜별로 나누어 매일 자동 스케줄 발송합니다.
📞
콜백문자
부재중 전화가 오면 자동으로 문자를 발송하는 자동화 기능입니다.
📊
발송 통계
성공/실패, 수신 여부, 클릭률을 실시간으로 확인합니다.
🔗
챗봇 자동 연동
링크 클릭 고객이 원챗 퍼널에 자동 등록됩니다.
📱
모바일 앱 지원
온리원문자 앱(Android)으로 언제 어디서나 발송 가능합니다.

발송 채널 종류

채널특징최대 길이이미지
SMS단문 문자, 즉시 발송90바이트❌
LMS장문 문자, 풍부한 본문2,000바이트❌
MMS멀티미디어 문자2,000바이트✅ 최대 3장
RCS웹 채팅형 문자 (기업 전용)제한 없음✅

요금 안내

포인트 차감 방식으로 운영됩니다. 마이페이지 → 포인트 충전에서 캐시포인트를 충전하세요.

채널건당 비용비고
SMS0.7원~90바이트 이하, 앱 연동 시
LMS2.5원~91바이트 이상
MMS15원~이미지 포함
RCS별도 문의기업 전용 신청 필요

빠른 시작

  1. 1
    발신번호 등록 — 문자 발송 전 발신번호를 먼저 등록합니다. → 발신번호 등록 →
  2. 2
    수신자 명단 준비 — CSV 파일로 이름·전화번호 목록을 준비합니다.
  3. 3
    문자 작성 & 발송 — 메시지를 작성하고 발송 채널을 선택합니다. → 발송 방법 →
  4. 4
    결과 확인 — 발송 통계와 수신 여부를 확인합니다. → 내역 확인 →
