웹문자란?

웹문자는 스마트폰 앱 없이 웹 서버를 통해 직접 발송하는 문자 서비스입니다. 별도의 발신 잔액을 충전하여 사용하며, 폰 상태에 관계없이 안정적으로 대량 발송이 가능합니다.

📌 웹문자 발송 화면: 발송 화면(sub_6.php) 상단 탭에서 💬 웹문자 탭을 선택합니다.

폰문자 vs 웹문자

구분폰문자(앱)웹문자
발송 방식스마트폰 앱 경유웹 서버 직접 발송
요금건당 0.7원~별도 충전 잔액 차감
폰 필요 여부발신 폰 필요불필요
발신번호등록된 휴대폰 번호인증된 발신번호
RCS 지원미지원지원 (단문/장문/포토)
대량 발송일별 제한 있음잔액 내 무제한

잔액 확인

웹문자 탭 상단에서 현재 웹문자 잔액을 확인할 수 있습니다.

💰
잔액 확인
발송 전 현재 잔액을 확인하여 발송 가능 여부를 점검합니다.
⚡
잔액 충전
잔액이 부족한 경우 [충전하기] 버튼으로 바로 충전 페이지로 이동합니다.

발신번호 조회

웹문자 발신에 사용할 번호를 먼저 등록해야 합니다. 발신번호는 실명 인증된 번호만 사용 가능합니다.

1
⚙️ 발신번호 관리 탭 선택

발송 화면 상단 탭에서 발신번호 관리를 클릭합니다.

2
발신번호 등록 신청

사용할 전화번호를 입력하고 인증 절차를 완료합니다.

3
승인 후 발송 가능

관리자 승인 후 해당 번호로 웹문자 발송이 가능합니다.

발송 방법

1
웹문자 탭 선택 후 발신번호 설정

발송 화면에서 💬 웹문자 탭을 선택하고, 등록된 발신번호를 선택합니다.

2
수신처 입력

개별번호 입력 또는 주소록 그룹을 선택합니다.

3
메시지 작성

단문(SMS), 장문(LMS), 이미지(MMS) 중 선택 후 내용을 작성합니다.

4
발송 실행

내용 확인 후 [발송] 버튼을 클릭합니다. 잔액이 차감됩니다.

RCS 발송

RCS(Rich Communication Services)는 이미지, 버튼, 카드형 레이아웃을 지원하는 차세대 문자 규격입니다.

종류특징
RCS 단문최대 100자 텍스트, 버튼 포함 가능
RCS 장문최대 1,300자 텍스트, 버튼 포함 가능
RCS 포토이미지 + 텍스트 + 버튼 카드형 레이아웃
📌 RCS 주의사항: 수신자 단말기가 RCS를 지원하지 않는 경우 일반 SMS로 대체 발송됩니다. RCS 발송은 별도 요금이 적용됩니다.
