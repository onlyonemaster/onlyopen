주소록 관리란?

폰문자 발송 화면(sub_4.php)의 주소록 관리 탭에서는 발신 휴대폰별로 수신처(고객 번호) 목록을 등록·관리합니다.

그룹 주소록을 만들어 한 번에 대량 발송하거나, 엑셀 파일로 번호를 업로드할 수 있습니다.

휴대폰 등록 정보

항목설명
휴대폰번호발신용으로 등록된 스마트폰 번호

그룹 주소록

1
그룹 생성

주소록 탭에서 그룹번호 항목의 [+추가] 버튼을 클릭하여 새 그룹을 만듭니다.

2
그룹명 입력

그룹 이름을 입력하고 저장합니다. (예: VIP고객, 신규문의, 2024년DB)

3
번호 등록

엑셀 업로드 또는 직접 입력으로 해당 그룹에 고객 번호를 추가합니다.

4
발송 시 그룹 선택

문자 발송 화면에서 그룹을 선택하면 해당 그룹 전체에 자동으로 발송됩니다.

엑셀 업로드

📁 지원 형식: Excel 97~2003 통합문서(.xls) 형식만 지원합니다.
샘플 파일: 화면 내 업로드샘플.xls 링크를 클릭하여 형식을 확인하세요.
1
샘플 파일 다운로드

발송 화면 내 업로드샘플.xls를 다운로드하여 형식을 확인합니다.

2
번호 입력 후 저장

샘플 형식에 맞게 수신자 번호를 입력하고 .xls 형식으로 저장합니다.

3
업로드 실행

[엑셀 업로드] 버튼을 클릭하고 파일을 선택합니다. 업로드 완료 후 번호 목록이 자동으로 등록됩니다.

개별 번호 관리

➕
개별 번호 추가
번호를 직접 입력하여 주소록에 개별 등록합니다.
🗑️
번호 삭제
불필요한 번호를 개별 또는 일괄 삭제합니다.
📝
메모 기능
각 번호에 메모 사항을 등록하여 고객 특이사항을 기록합니다.
🚫
발송 제외 설정
특정 번호를 발송 제외 처리하여 해당 발신 폰 발송에서 제외합니다.

활용 팁

💡 묶음발송 vs 개별발송
- 묶음발송: 동일 메시지를 여러 번호에 한 번에 발송 (빠름)
- 개별발송: 번호마다 별도 메시지로 처리 (개인화 가능)

💡 중복 제거: 업로드 시 중복 번호는 자동 제거됩니다. 처리 전 중복 건수와 제거 후 건수를 확인하세요.
