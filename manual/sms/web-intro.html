웹문자·RCS란?

웹문자는 스마트폰 앱(온리원문자 앱) 없이 웹 브라우저에서 직접 문자를 발송하는 서비스입니다. 포인트를 충전하여 건당 요금을 지불하는 방식으로 운영되며, RCS(Rich Communication Services) 발송도 지원합니다.

🖥️ 웹문자로 퍼널을 발송할 경우 사전에 포인트를 충전하셔야 합니다. → ⚡ 충전하기

발송 채널 종류

💬
웹 SMS
90자 이내 단문. 비용이 가장 저렴하며 즉시 도달률이 높습니다.
📝
웹 LMS
90자 초과 시 자동 전환. 상세한 안내문이나 긴 내용에 적합합니다.
🖼️
웹 MMS
이미지 + 텍스트. 제품 사진, 이벤트 배너 등 시각적 홍보에 활용합니다.
📱
RCS 단문
채팅 앱 스타일 단문 메시지. 버튼 링크 삽입 가능.
📋
RCS 장문
긴 내용 + 버튼 포함 리치 메시지. 고객 응대 자동화에 효과적.
🎨
RCS 포토
이미지 카드형 RCS. 시각적으로 임팩트 있는 메시지 전달.

충전 및 요금

웹문자는 포인트 선충전 방식으로 운영됩니다.

  • 마이페이지 → 포인트 충전에서 캐시포인트를 충전합니다.
  • 발송 시 채널별 단가에 따라 포인트가 자동 차감됩니다.
  • 현재 잔액은 발송 화면 상단 💰 잔액에서 확인할 수 있습니다.
📌 무료 제공: 가입 후 일정 기간 동안 무료 건수가 제공됩니다. 잔액 조회에서 남은 무료 건수를 확인하세요.

RCS 발송 안내

RCS는 기업 전용 채널로, 사전에 RCS 발신번호를 별도 신청해야 합니다.

  1. 1
    RCS 발신번호 신청 — 통신사에 기업 RCS 채널 개설을 신청합니다.
  2. 2
    발신번호 등록 — kiam.kr 발신번호 관리에서 승인된 RCS 번호를 등록합니다.
  3. 3
    RCS 채널 선택 후 발송 — 단문/장문/포토 중 형식을 선택하고 발송합니다. 버튼명(최대 15자)과 버튼 링크를 추가할 수 있습니다.
⚠️ 주의: RCS 1회 최대 20건 발송 제한이 있습니다. 대량 발송이 필요하면 별도 문의하세요.

발신번호 설정

웹문자 발신번호는 폰문자 발신번호와 별도로 관리됩니다.

  • 발송 화면의 ⚙️ 발신번호 관리에서 웹문자용 발신번호를 등록합니다.
  • RCS 발신번호는 승인 후 별도로 등록해야 합니다.
  • 발신번호가 없을 경우 발송이 불가능합니다 (-- RCS 발신번호 없음 -- 표시).

시작하기

웹문자 발송을 시작하려면 아래 단계를 따르세요.

  1. 1
    포인트 충전 → 충전하기
  2. 2
    발신번호 등록 → 발송 화면에서 ⚙️ 아이콘 클릭
  3. 3
