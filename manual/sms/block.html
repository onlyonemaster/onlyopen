수신거부란?

수신거부 관리는 광고 문자 수신을 원하지 않는 고객의 번호를 등록하여, 이후 해당 번호에는 광고 문자가 발송되지 않도록 차단하는 기능입니다.

수신거부 번호는 폰별 또는 계정 전체 단위로 관리할 수 있습니다.

법적 의무

⚠️ 정보통신망법 준수 필수
광고 문자에는 반드시 수신거부 방법을 명시해야 합니다.
예: "무료거부 0808-xxx-xxxx" 또는 "회신 시 수신거부 처리"

수신거부 요청을 받은 즉시 처리해야 하며, 이를 무시하고 계속 발송하면 과태료 대상이 될 수 있습니다.

수신거부 등록

✏️
개별 직접 등록
수신거부 탭에서 번호를 직접 입력하여 개별 등록합니다.
📤
엑셀 일괄 업로드
수신거부 번호 목록을 엑셀 파일로 업로드하여 대량 등록합니다.
🤖
수신 내역 자동 처리
고객이 "거부", "해지", "취소" 키워드를 회신하면 자동으로 수신거부 처리됩니다.

목록 관리

기능설명
번호 검색특정 번호가 수신거부 목록에 있는지 확인
수신거부 해제고객 요청 시 수신거부 목록에서 제거
목록 다운로드수신거부 번호 전체를 엑셀로 내보내기
폰별 분류발신 폰별로 수신거부 목록을 분리 관리

자동 처리

발송 시 시스템이 수신거부 목록과 자동 대조하여 해당 번호에는 발송을 건너뜁니다.
