발신 내역

발송한 문자의 결과를 확인하려면 발신내역 페이지로 이동하세요.

항목설명
발송일시문자가 발송된 날짜와 시각
발신번호발송에 사용된 번호
수신자 수총 발송 건수
성공 / 실패실제 전달된 건수와 실패 건수
메시지 내용클릭 시 전송된 내용 확인

발송 상태 이해

상태의미조치
✅ 성공수신자 단말기에 정상 전달됨—
🔄 처리중통신사 전송 대기 중잠시 후 새로고침
❌ 실패결번·수신 거부·오류번호 확인 후 재발송
⏸ 예약예약된 시간 대기 중취소 가능 (2분 전까지)
🚫 차단스팸 필터 또는 수신 거부 등록재발송 불가

통계 활용

  • 발송 성공률: 정상 전달 비율. 80% 미만이면 수신자 목록 품질을 점검하세요.
  • 링크 클릭률: 문자 내 챗봇 링크 클릭 비율. 마케팅 효과 측정에 활용하세요.
  • 수신 거부율: 높을수록 스팸으로 분류될 위험이 높아집니다.
  • 포인트 사용 내역: 마이페이지 → 포인트 내역에서 확인 가능합니다.
