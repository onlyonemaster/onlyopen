발송 화면 접속

https://kiam.kr/sub_6.php 로 접속하거나 상단 메뉴 → 문자발송을 클릭합니다.

준비사항: ① 발신번호 등록 완료 ② 캐시포인트 충전 ③ 수신자 명단(CSV/엑셀)

수신자 입력

방법 1 — 직접 입력

수신번호 입력창에 번호를 하나씩 입력합니다. 줄바꿈(Enter)으로 여러 번호를 구분합니다.

방법 2 — 파일 업로드 (대량 발송)

  1. 1
    CSV 파일 준비: 열 순서 = 이름, 전화번호 (헤더 포함)
  2. 2
    [수신자 파일 업로드] 버튼 클릭 → CSV 파일 선택
  3. 3
    미리보기에서 이름·번호 확인 → 오류 수정
지원 파일 형식최대 행 수인코딩
CSV (.csv)50,000건UTF-8 또는 EUC-KR
Excel (.xlsx)30,000건—

메시지 작성

  • 제목(선택): LMS/MMS에서 표시됩니다.
  • 본문: 직접 입력 또는 템플릿 불러오기
  • 변수 사용: #{이름} 입력 시 수신자 이름으로 자동 치환됩니다.
  • 이미지 첨부(MMS): JPG/PNG, 최대 300KB, 최대 3장
💡 팁: 90바이트 이하면 SMS(0.7원), 초과하면 자동으로 LMS(2.5원)로 전환됩니다. 글자 수 카운터를 확인하세요.

발송 채널 선택

채널언제 사용비용
SMS 자동90바이트 이하 단문0.7원
LMS 강제장문·링크 포함 시2.5원
MMS이미지 포함 시15원

예약 발송

[예약 발송] 체크박스를 활성화하면 날짜·시간을 지정해 나중에 자동 발송할 수 있습니다.

  • 최소 10분 이후로 예약 가능
  • 예약 취소는 발송 2분 전까지 가능
  • 예약 문자 목록: 예약 문자 관리

발송 실행

  1. 1
    발신번호 선택 (등록된 번호 중 선택)
  2. 2
    발송 미리보기 확인 (수신자 수, 총 예상 비용)
  3. 3
    [발송하기] 버튼 클릭 → 포인트 차감 후 즉시 발송
⚠️ 주의: 발송 후 취소/환불이 불가합니다. 수신자 명단과 메시지 내용을 반드시 확인하세요.

챗봇 링크 삽입 (퍼널 마케팅 연동)

문자 본문에 챗봇 링크를 삽입하면, 링크를 클릭한 고객이 원챗 수신탭에 자동 등록됩니다.

  1. 1
    원챗 → 프로필 설정에서 내 챗봇 링크 복사 (https://chatbot.kiam.kr/s/내아이디)
  2. 2
    메시지 본문에 링크 붙여넣기
  3. 3
    링크 클릭 고객 → 원챗 퍼널 자동 등록 → AI 챗봇 자동 응답 시작
