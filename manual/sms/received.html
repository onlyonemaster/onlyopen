수신 내역이란?

폰문자 수신 내역 화면(sub_4.php?status=5&status2=3)에서는 발신 폰이 실제로 수신한 문자 메시지를 확인할 수 있습니다.

고객이 발신 번호로 답문자(회신)를 보낸 경우, 이 화면에서 수신 내역을 확인하고 직접 회신할 수 있습니다.

📌 온리원문자 앱 필요: 수신 내역은 스마트폰에 설치된 온리원문자 앱이 실행 중일 때만 서버로 전달됩니다. 앱이 꺼진 상태에서는 수신 내역이 등록되지 않을 수 있습니다.

화면 접속

1
폰문자 메뉴 접속

kiam.kr 로그인 후 상단 메뉴 → 폰문자 발송(sub_4.php)에 접속합니다.

2
수신내역 탭 클릭

화면 상단 탭에서 수신내역 탭을 선택합니다.

3
발신번호 선택

조회할 발신 폰 번호를 선택하여 해당 폰으로 수신된 문자를 확인합니다.

화면 구성

항목설명
발신/회신문자수신된 문자의 종류 (발신 또는 회신)
문자인증인증 문자 수신 여부 표시
수신번호문자를 보낸 고객의 번호
수신 내용수신된 문자 메시지 내용
수신 일시메시지를 수신한 날짜/시간

회신 문자

수신된 고객 문자에 직접 답문자를 보낼 수 있습니다.

1
수신 내역에서 번호 확인

회신할 고객 번호를 확인합니다.

2
문자 발송 화면으로 이동

해당 번호를 발송 화면의 수신처에 입력하고 답문자를 작성·발송합니다.

⚠️ 기본서비스 안내: 수신 내역 확인은 기본 발신기능 앱(온리원문자)과 연동 시 제공되며, WiFi 상태보다 LTE/5G 연결 상태에서 더욱 안정적으로 수신됩니다.

활용 팁

🔔
즉시 확인
고객 회신 문자는 영업 응대 기회입니다. 수신 후 빠르게 확인하고 후속 대응하세요.
📲
앱 백그라운드 실행
온리원문자 앱을 항상 백그라운드로 실행하여 수신 내역이 누락되지 않도록 합니다.
🚫
수신거부 처리
수신 문자에 "거부", "해지" 등의 키워드가 있으면 수신거부 목록에 등록하세요.
