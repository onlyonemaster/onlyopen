🔎 검색 기술 가이드

온리원디버의 수집 품질은 검색어에 달려 있습니다. 네이버 검색지침을 이해하고 효과적인 검색어를 만드는 방법을 상세히 안내합니다.

검색 기술이 왜 중요한가?

온리원디버는 고객이 원하는 DB를 자동으로 수집해주는 솔루션이 아니라, 고객의 검색 기술에 의해 작동하는 솔루션입니다. 검색어의 정확도와 적절성이 수집 결과의 품질을 결정합니다.
  • DB 공개자가 자신의 정보를 올리는 이유와 목적을 이해해야 함
  • 고객이 자신을 표현하는 방식(호칭·직위·이름)을 정확히 파악해야 함
  • 예: 의사는 "의사"보다 "전문의"로 자신을 소개 → "전문의"로 검색해야 정확하고 많은 DB 획득
  • 검색이 안 되면 해당 고객이 정보를 공개하지 않는 대상인지, 아니면 다른 웹 종류에 올렸는지 확인

네이버 검색지침 7가지

디버 검색 키워드 입력창 우측의 물음표(?) 버튼을 클릭하면 아래 검색지침을 확인할 수 있습니다.

1. 검색어 구분 방법

구분 방식문법예시
띄어쓰기검색어 검색어가족 핵가족 대가족
콤마검색어, 검색어가족, 핵가족, 대가족

2. AND 검색 (모두 포함)

[검색어1 검색어2] — 두 검색어가 모두 포함된 결과만 수집

공부방 교습소 → 공부방과 교습소가 동시에 들어있는 페이지만 수집

3. 정확 일치 검색

[검색어 "정확한단어"] — 따옴표 안의 단어가 정확히 일치하는 결과만 수집

학원 "미술" → '학원' 검색 결과 중 '미술'이 정확히 일치한 결과만 수집

4. 제외 검색

[검색어 -제외어] — 제외어가 포함된 결과를 제외하고 수집

학원 -미술 → '학원' 검색 결과 중 '미술'을 제외한 결과만 수집

5. 포함 검색

[검색어 +포함어] — 포함어가 있는 결과를 반드시 포함하여 수집

애완동물 +염소 +토끼 → '애완동물' 검색 결과 중 '염소'와 '토끼'를 포함한 결과 수집

6. OR 검색 (하나 이상)

[검색어 | 검색어] — 검색어 중 하나 이상 포함된 결과 수집

학원 | 교습소 | 공부방 → 세 검색어 중 하나라도 포함된 페이지 수집

7. 결합 검색

위 기능을 조합하여 복합 검색

결합 예시의미
학원 교습소 -임대'학원 교습소' 검색 결과 중 '임대' 제외
학원 "교습소" -임대'학원' 중 "교습소" 정확 일치 + '임대' 제외
학원 | 교습소 +수학'학원·교습소' 하나 이상 + '수학' 포함

디비 수집 샘플링 (사전 모델링)

디버로 수집하기 전, 네이버 브라우저에서 먼저 검색 조건을 테스트하는 과정입니다.

📱 010 휴대폰 DB 수집 샘플링

1
수집 목적 설정
왜 DB를 수집하는지 명확히 정의
2
타겟 고객 설정
목적에 맞는 타겟 고객 정의. 어떤 상품을 선호하는 고객인지 구체화
3
폰번호 공개 가능성 검토
해당 고객이 자신의 폰번호를 웹에 공개할지 생각. 예: 약사는 구인 시에만 정보 공개
4
업로드 웹 종류 판단
고객이 어떤 웹(7가지 종류)에 정보를 올릴지 판단
5
호칭·직위·이름 형식 검토
고객이 자신을 어떤 형태로 소개할지 검토. 예: 의사 → "전문의"
6
네이버에서 실제 검색 후 결과 확인
원하는 결과가 아니면 검색어·검색기능 변경 반복

📧 이메일 DB 수집 샘플링

  1. 수집 목적 설정 — 왜 이메일을 수집하는지 정의
  2. 사용 방향 설정 — 메일 발송? 페이스북·인스타그램 매칭? (SNS 매칭 시 폰번호 수준의 효과)
  3. 타겟 고객 설정 — 상품 선호 고객 구체화
  4. 이메일 위치 검토 — 블로거는 블로그에, 일반인은 카페에 아이디 공개. 고객이 어디에 이메일을 공개했을지 판단
  5. 네이버에서 검색 후 결과 확인

검색어 설계 사례

사람 이름 수집 사례

이름 뒤에 붙는 호칭(직무·직급·직업)으로 수집합니다.

유형기본 검색어전문성 추가 검색어
직무 검색 "소장 010" 부동산 "소장 010"
전문직 검색 "변호사 010" 형사 "변호사 010"

업체 이름 수집 사례

유형기본 검색어세부 검색어
업종 검색 "식당 010" 한식 "식당 010"
세부 업종 "학원 010" 영어 "학원 010"

연락처 제시형 검색어

상담·문의·전화·연락처 등의 키워드로 연락을 기다리는 고객을 찾습니다.

기본 검색어세부 분류 검색어
"상담 010"결혼 "상담 010"
"문의 010"과외 "문의 010"
"전화 010"택배 "전화 010"

호칭·직급·업종 참고자료

분류예시
직급 회장, 부회장, 이사, 이사장, 사장, 부장, 전무, 상무, 본부장, 실장, 과장, 팀장, 대리, 주임
자격증 국가기술자격증, 국가전문자격증 (세무사, 변리사, 감정평가사, 공인중개사, 건축사, 변호사 등)
업종 업종분류자료, 네이버 업종분류 참조하여 세분화
연락처형 상담, 문의, 전화, 연락처 — 너무 광범위하므로 반드시 세부 분류 정보 추가
💡 고급 팁: 정확한 DB를 원하면 검색어를 "직업 010" 형태로 하고 이름 수집을 켜면 고객의 이메일·폰번호·이름까지 정확하게 수집 가능. 양을 늘리려면 따옴표를 빼고 이름 수집을 0으로 설정하세요.
