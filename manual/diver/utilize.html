📱 1) 폰문자(SMS)로 발송하기

디버로 수집한 주소록을 온리원 폰문자 솔루션에서 대량 문자 발송할 수 있습니다.

업로드 절차

  1. 1
    디버에서 xls 파일로 저장
    수집 완료 후 xls 확장자(Excel 97-2003)로 저장합니다. 이 형식으로 저장하면 kiam.kr 주소록 등록 시 확장자 변환 없이 업로드 가능합니다.
  2. 2
    온리원 문자사이트 접속
    https://kiam.kr
  3. 3
    문자발송하기 → 주소록 불러오기
    문자발송하기 창에서 [주소록 불러오기] 선택 후 저장된 xls 파일 업로드
  4. 4
    저장된 주소록으로 문자 발송
    불러온 주소록 선택 후 메시지 작성하여 발송
📌 주소록 업로드 시 주의: 업로드하면 소그룹명·이름·전화번호 외의 데이터는 모두 삭제됩니다. 원본 xls 파일은 별도 보관하세요.

💬 2) RCS 문자로 발송하기

디버로 수집한 휴대폰 주소록을 온리원 RCS 문자 솔루션에서 발송할 수 있습니다. RCS는 일반 SMS보다 풍부한 이미지·버튼·영상 등을 포함할 수 있는 차세대 메시지 서비스입니다.

💡 RCS 발송은 일반 SMS 대비 읽음률과 반응률이 높습니다. 브랜드 홍보·이벤트 안내에 특히 효과적입니다.

📞 3) 전화(텔레마케팅)로 활용하기

수집된 010 번호로 전화하여 텔레마케팅 형태로 사용할 수 있습니다.

⚠️ 법적 주의사항: 전화 시 반드시 폰번호 수집 출처를 먼저 고객에게 제시해야 합니다. "어디에서 연락처를 확인했다"고 알리는 것이 합법적인 텔레마케팅의 기본입니다.

📧 4) 이메일로 발송하기

방법설명비용
포털 메일 직접 발송 다음·네이버 등 포털 이메일로 광고 홍보 메시지 전송 무료 (다만 스팸함 진입 가능성)
이메일 발송 업체 위탁 전문 이메일 발송 업체에 위탁하여 대량 발송 건당 약 1원
💡 팁: 단순 메일 발송 시 상당수가 스팸함에 들어가거나 열어보지 않습니다. 본사에서 개발한 메시지 카피 기술을 활용하면 고객이 읽도록 만들 수 있습니다. 관리자에게 문의하세요.

🌐 5) SNS 채널로 홍보하기

수집된 이메일 주소록을 페이스북·인스타그램에 업로드하면 해당 SNS 회원과 매칭하여 타겟 광고를 할 수 있습니다.

SNS 매칭의 장점

  • 매칭 과정에서 이메일 소유자의 성별·직업·연령·거주지 등 확인 가능
  • 폰번호 수준의 정확한 타겟팅 결과를 얻을 수 있음
  • SNS 플랫폼의 광고 도구로 맞춤 오디언스(Custom Audience) 생성 가능

페이스북·인스타그램 타겟 광고 방법

  1. 디버에서 이메일 목록을 CSV 파일로 저장
  2. 페이스북 광고 관리자 → 오디언스 → 맞춤 오디언스 만들기
  3. 고객 목록(Customer List) 업로드 → 이메일 CSV 파일 선택
  4. 매칭 완료 후 해당 오디언스 대상 광고 캠페인 실행
더 자세한 방법은 유튜브에서 '페이스북 타겟고객 홍보' 검색하여 영상을 참고하세요.
