🔍 DB 수집 — 온리원디버

온리원디버(OnlyOneDiver)는 온라인에 공개된 데이터를 타겟별로 빠르게 수집하여 SMS·AI 메시지·원챗 퍼널 발송 대상으로 활용하는 다채널 종합 DB 수집 솔루션입니다.

온리원디버란?

온리원디버는 온리원연구소가 개발한 Windows 전용 DB 수집 프로그램(버전 1.0.1.0)으로, 네이버의 공개 웹페이지(지도, 블로그, 카페, 뉴스, 포스트, 쇼핑, 웹사이트)에서 휴대폰 번호, 이메일, 지역주소, 업체명, 담당자 이름 등을 자동으로 수집합니다.

v230911 주요 업데이트 (2023.09.11)

#변경 사항내용
1네이버 지도 010→0507네이버 지도 개인정보 보호로 010번호가 0507로 대체되어 수집량 감소
2지도 검색 지침 강화정교한 디비 수집을 위한 규칙 세분화. 지도 [검색 키워드] 옆 물음표(?) 클릭 참조
3이메일 무료 수집휴대폰 수집 시 블로그·카페·뉴스·포스트·웹사이트에서 이메일 함께 수집
4이메일 유료 수집블로그 게시자/검색자 이메일 + 카페 이메일 고속 수집 (종량제)
5이름 수집 기능사람이름(변호사·목사·강사 등 직위 앞) / 단체이름(협회·식당·회사 등) 구분 수집
6정확도 조정정확도 1(최고)~3(최저) + 이름수집 여부 조합 가능
7팝업 광고 기능우측 하단 팝업으로 업그레이드·공지·광고 제공 (광고 문의: 본사 관리자)
8수집건수 제한왼쪽 중앙 수집건수 입력 시 해당 건수 도달 시 자동 중지

디비 수집의 법적 지위

📌 수집 원칙: 온리원디버는 온라인에 공개된 데이터만 추출합니다. 비공개 데이터나 무단 접근 데이터는 수집하지 않습니다.

① 공개 정보 수집에 대한 대법원 판례

대법원(2016.08.17)은 "이미 공개된 개인정보는 동의 없이 수집·제공이 가능하다"고 판결했습니다. 영리 목적의 DB 수집과 제3자 제공에 대해서도 합법으로 판단했습니다.

판결 요지
"영리목적으로 개인정보를 수집해 제3자에게 제공했더라도 그로 인해 얻을 수 있는 '알권리'·'표현의 자유'·'영업의 자유'·'사회 전체의 경제적 효율성' 등이 정보처리를 막음으로써 얻을 수 있는 정보주체의 인격적 법익에 비해 우월하다."

"이미 공개된 개인정보를 정보주체의 동의가 있었다고 객관적으로 인정되는 범위 내에서 수집·이용·제공 등 처리를 할 때는 정보주체의 별도의 동의는 불필요하다."

② 행정안전부 '표준개인정보처리지침' (2017.7.26 시행)

조항내용
제6조①명함 및 유사한 매체로 제공받거나 이와 유사한 정황이 있다고 판단될 때 수집 가능
제6조②공개된 매체 또는 장소(홈페이지 등)에서 수집하는 경우 허용
제6조③정보주체의 동의 의사가 명확하거나 통념상 동의 의사가 있었다고 인정되는 범위 내에서만 이용 가능

③ 수집 후 발송 시 스팸법규 준수

DB 수집 자체는 합법이지만, 수집된 DB로 문자·카톡 발송 시 수신 동의가 필요합니다.

발송 채널합법 조건비고
📞 전화DB 수집 출처를 알리고 텔레마케팅합법
💬 문자·카톡수신동의 또는 거래관계 내 정보 전달공익정보도 예외적 허용
📧 이메일공개 목적에 부합하는 내용 발송공개자가 원하는 메시지 → 신고 안 함

폰문자·AI 메시지·원챗으로 발송

빠른 시작

  1. 1
    회원가입 및 로그인
    https://kiam.kr/ma.php
    kiam.kr에 회원가입 후 로그인합니다.
  2. 2
    디버 요금제 결제
    상단 메뉴 마지막 [결제페이지] → 약정결제·정기결제·디버별도 중 선택 결제
  3. 3
    디버 프로그램 설치
    https://kiam.kr/cliente_list.php?status=1&one_no=85
    [온리원디버 정규판 다운로드] 클릭 후 설치. 보안 경고 시 [추가정보] → [계속 설치]
  4. 4
    바탕화면 드럼통 아이콘으로 실행
    드럼통 아이콘 = 디버 업데이터. 항상 이 아이콘으로 실행해야 ChromeDriver 최신 상태 유지
  5. 5
    검색 조건 설정 후 수집 시작
    웹종류·검색어·기간·건수 설정 → [수집시작] 클릭
