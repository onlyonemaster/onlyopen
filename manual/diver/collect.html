📱 1) 휴대폰 번호 (010) 수집

지도에서 휴대폰 번호 수집

⚠️ 주의: 네이버 지도의 010 번호는 약 25만 개로, 오랫동안 모든 DB 수집 솔루션에 의해 수집되어 대부분 마케팅 회사에 공급된 상태입니다. 스팸 신고율이 높은 DB이므로 주의하세요.
또한 230911 버전부터 네이버가 개인정보 노출 방지를 위해 010 번호를 0507로 지원하면서 지도의 010 번호가 크게 줄었습니다.

지도 외 페이지에서 휴대폰 번호 수집

블로그·카페·뉴스·포스트·쇼핑·웹사이트에서는 휴대폰 번호와 함께 이메일·지역주소·웹주소·고객 이름 등을 함께 수집할 수 있습니다.

웹종류수집 가능 정보특징

💡 정확한 수집: 검색어를 "직업 010" 형태로 하고 이름 수집을 켜면 고객의 이메일·폰번호·이름까지 정확하게 수집 가능
💡 많은 양: 따옴표를 빼고 검색어만 입력 + 이름 수집을 0으로 설정

📧 2) 이메일 수집 — 6가지 방법

이메일 수집은 크게 무료 수집과 종량제(유료) 수집으로 나뉩니다.

이메일 무료 수집 방법

#방법대상설명
①휴대폰과 함께 수집블로그·카페·뉴스·포스트휴대폰 번호 수집 시 기본적으로 이메일도 함께 수집 (지도·동영상 제외)
②블로그 게시자 이메일블로그글을 올린 게시자의 이메일. 게시자는 휴대폰 공개 가능
③블로그 검색자 이메일블로그게시자의 글을 검색한 사람의 이메일. 검색자는 휴대폰 비공개
④카페 이메일 (일반)카페카페에 글을 올린 게시자의 이메일 수집
⑤단일 카페 키워드 이메일단일 카페특정 카페 주소 입력 + 검색어로 연관 이메일 저속 수집
⑥단일 카페 전체 이메일단일 카페카페 주소 입력 + "이메일" 검색 → 카페 전체 회원 이메일 고속 수집

이메일 종량제 (유료) 수집 방법

종류설명과금
블로그 고속 이메일 추출블로그에서 이메일만 대량 추출유료 카운트
블로그 검색자 이메일 추출블로그 검색자의 이메일 추출유료 카운트
단일 카페 이메일 추출특정 카페의 이메일 추출유료 카운트
📌 무료 vs 유료 구분: 카페·뉴스·포스트·웹사이트에서 수집하는 이메일은 무제한 무료. 블로그 고속·검색자·단일카페 이메일 추출은 종량제 유료입니다.

☎️ 3) 지역 전화번호 수집

항목내용
수집 위치네이버 지도에서만 수집 가능
선택 방법지도 디버에서 지역번호 선택 → 검색어 또는 지역 고유번호(예: 02) 입력
비용무료 수집
제한지도 외 웹페이지에서는 지역 전화번호 수집 불가

👤 4) 이름 수집 기능

구분대상사용 방법예시
사람 이름 변호사·목사·강사 등 직위 앞에 이름이 나오는 경우 좌측 [사람이름] 버튼 클릭 "김철수 변호사" → 김철수 수집
단체 이름 협회·식당·회사 등 단체명이 나오는 경우 우측 [단체이름] 버튼 클릭 "맛있는한식당" → 맛있는한식당 수집
⚠️ 이름 수집 시 이름이 없는 단체는 제외되므로 전체 수집 건수가 줄어듭니다. 꼭 필요한 경우가 아니라면 사용하지 않는 것이 좋습니다.

🎯 5) 정확도 조정 기능

메인 디버 왼쪽 하단의 정확도 설정에서 조정합니다.

정확도 값의미수집 결과
1가장 정확한 정보건수 적음, 품질 높음
2중간 정확도균형
3낮은 정확도건수 많음, 품질 낮음

정확도와 이름 수집 여부를 조합하여 수집 품질을 세밀하게 제어할 수 있습니다.

🗺️ 6) 지도 정보 수집 안내

지도 수집은 다른 웹종류와 달리 별도 창이 열리며, 전용 옵션이 있습니다.

  1. DB 구분 선택 — 휴대폰·지역번호·050X번호 중 하나 또는 다중 선택
  2. 지역 선택 — 광역/도 → 시군구 → 읍면동 순으로 세분화
  3. 검색 키워드 입력 — 업종(식당·카페·놀이방 등) 또는 디비종류(010·070·031 등)
  4. 수집 건수 설정 — 원하는 건수 입력
📌 지도에서는 이메일 수집 불가합니다. 또한 지도 검색 지침이 세분화되었으니 반드시 물음표(?) 버튼을 클릭하여 확인하세요.

🚀 7) 디버로 실제 수집하기 (Step by Step)

  1. 1
    네이버 로그인 확인
    네이버에 자신의 아이디로 로그인되어 있어야 합니다.
  2. 2
    수집 승인 잔량 확인
    우측 상단에서 폰건수·이메일 잔량 확인. 부족 시 관리자에게 유료 추가 요청 (1,000건당 10,000원, 건당 10원)
  3. 3
    웹종류 선택
    지도 외 웹종류는 다중 선택 가능하나, 가능하면 단일 종류로 사용 권장
  4. 4
    검색 기간 입력
    예: 20190101 형식으로 시작일·종료일 입력
  5. 5
    검색어 입력
    네이버에서 샘플링한 검색어를 그대로 입력
  6. 6
    이름 수집·정확도·수집건수 설정
    필요에 따라 선택. 이름 수집은 꼭 필요할 때만 사용
  7. 7
    [수집시작] 버튼 클릭
    수집이 자동으로 진행됩니다. 다른 작업을 하면서 기다리세요.

검색 결과와 수집 결과의 차이

네이버 페이지 검색 결과가 500개인데 실제 수집 건수는 다른 이유:
  • 검색 결과 = 네이버의 페이지 수
  • 수집 결과 = 페이지에 들어있는 실제 DB 건수
  • 한 페이지 내: 오류 표기·2개 이상·중복 데이터 존재
  • 예상 시간과 실제 시간 차이: 각 페이지마다 DB 형태가 달라 검색 시간이 달라짐
