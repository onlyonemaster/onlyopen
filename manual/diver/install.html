💿 디버 설치 및 시작하기

온리원디버의 작동 환경 확인, 회원가입, 결제, 프로그램 설치, 실행까지 모든 준비 과정을 안내합니다.

작동 환경 안내

구분요구 사항상세
① 윈도우 버전 Windows 10 이상 + 64비트 Windows 7은 2020년 1월 14일 지원 종료. 반드시 Windows 10 64비트 이상 환경에서 사용
② 인터넷 환경 안정적인 인터넷 연결 와이파이 불안정 시 페이지 패스 → 수집 누락. 여러 명이 같은 와이파이 사용 시 접속 제한 가능
③ 브라우저 Chrome 브라우저 설치 필수 온리원디버는 크롬 기반 수집. 미설치 시 자동 설치 안내
④ 컴퓨터 접속 무제한 버전 외 모든 컴퓨터에서 작동 무제한 버전은 계약된 PC에서만 사용 가능
⑤ 컴퓨터 속도 적절한 처리 속도 컴퓨터가 느리면 페이지 검색 지연 → 수집 누락. 페이지 수는 증가하는데 수집 건수가 안 늘면 속도 문제
⑥ MS Excel Microsoft Excel 설치 수집 결과를 xls/csv로 저장하므로 Excel 프로그램 필요
💡 권장 사양: Windows 10/11 64비트, 8GB 이상 RAM, 안정적인 유선 인터넷, 최신 Chrome 브라우저, MS Excel 2010 이상

https://kiam.kr/cliente_list.php?status=1&one_no=85
  1. 1
    [온리원디버 정규판 다운로드] 버튼 클릭
    설치 파일 다운로드 시작
  2. 2
    설치 파일 실행
    다운로드된 설치 파일을 실행하여 설치 진행

설치 시 PC 보호 알림 대처법

상황대처 방법
Windows Defender 경고 화면의 [추가 정보] 클릭 → 하단 [계속 설치] 선택
기타 보안 프로그램 차단 해당 컴퓨터의 보안 장치를 잠시 중지하고 설치 후 다시 활성화
⚠️ 주의: 온리원디버는 관리자 권한(requestedExecutionLevel: requireAdministrator)으로 실행됩니다. 설치 중 권한 요청이 나타나면 [예]를 선택하세요.

⑤ 디버 실행 방법

  1. 1
    바탕화면에서 드럼통 아이콘 찾기
    설치 완료 후 바탕화면에 드럼통 모양 아이콘이 생성됩니다.
  2. 2
    드럼통 아이콘 더블클릭으로 실행
    드럼통 아이콘 = 디버 업데이터(DberUpdater). 항상 이 아이콘으로 실행해야 합니다.
  3. 3
    업데이트 확인 자동 진행
    실행 시 https://www.kiam.kr/downloads/update.xml에서 최신 파일 목록을 받아와 MD5 해시 비교 후 필요한 파일만 자동 다운로드
  4. 4
    업데이트 완료 → 온리원.exe 자동 실행
    모든 파일이 최신 상태이면 메인 디버 프로그램(온리원.exe)이 자동으로 실행됩니다.

왜 드럼통 아이콘으로 실행해야 하나요?

🥁 드럼통 아이콘은 디버 업데이터(DberUpdater)입니다. 이 프로그램이 하는 일:
  • ChromeDriver 버전 확인 및 자동 업데이트 — PC에 설치된 Chrome 브라우저 버전을 읽고 호환되는 ChromeDriver를 자동 다운로드
  • 프로그램 파일 무결성 검증 — MD5 해시로 모든 프로그램 파일의 변조·손상 여부 확인
  • 구버전 프로세스 종료 — 기존에 실행 중인 온리원.exe를 종료하고 새 버전으로 교체
⚠️ 온리원.exe를 직접 실행하면 ChromeDriver 불일치로 수집 오류가 발생할 수 있습니다. 반드시 드럼통 아이콘으로 실행하세요.
