🛠️ 문제 해결 (Troubleshooting)

온리원디버 사용 중 발생할 수 있는 주요 문제와 해결 방법, 검색 기술 교육, 위탁 수집 옵션을 안내합니다.

자주 묻는 질문 (FAQ)

❓ 수집은 되는데 원하는 디비가 아닙니다. 왜 그런가요?

온리원디버는 고객이 입력한 검색어에 의해 작동하는 솔루션입니다. 원하는 DB가 나오지 않는 이유는 대부분 검색 기술 부족 때문입니다.

  • DB 공개자가 자신을 소개하는 방식(호칭·직위)을 정확히 이해해야 함
  • 예: 의사는 "의사"보다 "전문의"로 소개 → "전문의"로 검색
  • 네이버에서 먼저 검색어를 테스트(샘플링)한 후 디버에 입력하세요
  • → 검색 기술 가이드 보기
❓ 페이지 수는 늘어가는데 수집 건수가 안 늘어요.
  • 컴퓨터 속도 문제: 컴퓨터가 느리면 페이지 로딩이 지연되어 수집이 누락됩니다.
  • 인터넷 불안정: 와이파이가 불안정하면 페이지를 패스하게 됩니다.
  • 해결: 유선 인터넷 사용, 불필요한 프로그램 종료, Chrome 캐시 정리
❓ 검색 결과가 500개인데 실제 수집된 건수는 왜 다른가요?

검색 결과 수는 네이버의 페이지 수이고, 수집 결과 수는 그 페이지들 안에 있는 실제 DB의 건수입니다. 한 페이지 내에 오류 표기·중복·2개 이상의 DB가 있을 수 있어 차이가 발생합니다. 이는 정상적인 현상입니다.

❓ 예상 수집 시간과 실제 시간이 너무 차이나요.

예상 시간은 단순히 "검색건수 × 검색시간"으로 계산되지만, 실제로는 각 페이지마다 포함된 DB의 형태가 달라 검색 시간이 달라집니다. 페이지에 DB가 많거나 복잡하면 더 오래 걸립니다.

❓ 저장이 안 되거나 오류가 발생해요.
  • MS Excel 정식판 확인 문제: 2016 이상 버전에서 xls 저장 시 오류 발생 가능 → csv로 저장 후 변환
  • 저장 창을 못 찾는 경우: Alt+Tab을 눌러 저장 창을 찾으세요
  • 저장 중 창을 닫지 마세요: xls는 내부 처리량이 많아 시간이 더 걸립니다
  • 컴퓨터를 끄거나 절전 모드로 전환하지 마세요
❓ 디버 업데이터 실행 시 "실행파일을 찾을 수 없습니다" 오류가 떠요.

업데이트 완료 후 온리원.exe가 존재하지 않을 때 발생합니다.

  • 디버 설치 폴더에 온리원.exe 파일이 있는지 확인
  • 없으면 디버를 재설치하거나 관리자에게 문의
  • 바이러스 백신이 파일을 삭제했을 가능성도 확인
❓ ChromeDriver 관련 오류가 발생합니다.

Chrome 브라우저와 ChromeDriver 버전 불일치가 주요 원인입니다.

  • Chrome을 최신 버전으로 업데이트하세요
  • 드럼통 아이콘으로 실행하면 ChromeDriver 자동 업데이트
  • Chrome 115+ 사용 시 업데이터 매뉴얼 참조

디버 사용 꿀팁

  • 네이버 로그인 유지 — 디버 실행 전 네이버에 항상 로그인해 두세요
  • 웹종류는 단일로 — 여러 웹종류 동시 선택보다 한 종류씩 순차적으로 수집하는 것이 정확도가 높습니다
  • 검색 기간 활용 — 최근 데이터가 필요하면 검색 기간을 좁게 설정하세요
  • 정확도보다 양 — 따옴표 제거 + 이름 수집 OFF = 많은 건수
  • 양보다 정확도 — "직업 010" + 이름 수집 ON + 정확도 1 = 정밀 타겟
  • 데이터 마이닝 — 수집 후 엑셀에서 잘못된 결과를 제거하고 필요에 맞게 정리하세요
  • CSV 먼저 저장 — xls 저장 오류 시 CSV로 저장 후 xls 변환하여 업로드
  • 주기적 Chrome 업데이트 — Chrome을 항상 최신으로 유지하면 ChromeDriver 호환성 문제 예방
