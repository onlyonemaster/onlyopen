📢 공지사항

kiam.kr 서비스 업데이트, 점검 안내, 정책 변경 등 중요 소식을 공지합니다.

📌 최신 공지: 실시간 공지사항은 kiam.kr 공지사항 페이지에서 확인하세요.

공지 유형 안내

유형내용확인 위치
🛠️ 서비스 점검 정기·비정기 서비스 점검 시간 안내 공지사항 / 문자 알림
✨ 기능 업데이트 신규 기능 추가, 기존 기능 개선 사항 공지사항 / 매뉴얼 업데이트
📋 정책 변경 이용 정책, 요금 정책 변경 사항 공지사항 / 이메일 알림
🚨 긴급 안내 서비스 장애, 보안 패치 등 긴급 사항 공지사항 / SMS 알림

공지사항 확인 방법

  1. 1
    kiam.kr 로그인 후 공지사항 메뉴를 클릭합니다.
  2. 2
    목록에서 확인하고 싶은 공지를 클릭하여 상세 내용을 읽습니다.
  3. 3
    중요 공지는 팝업이나 상단 알림으로 자동 표시됩니다.

다른 회원들의 사용 후기도 공지사항 페이지에서 함께 확인할 수 있습니다.
