❓ 자주 묻는 질문 (FAQ)

🔑 회원 가입 / 로그인

비밀번호를 잊어버렸어요.
아이디/비밀번호 찾기 페이지에서 가입 시 등록한 이메일로 비밀번호를 재설정할 수 있습니다.
회원가입 후 로그인이 안 돼요.
가입 시 입력한 아이디/비밀번호를 확인하세요. 대소문자를 구별합니다. 문제가 지속되면 카카오 상담으로 문의하세요.

📱 폰문자 SMS

문자가 발송되지 않아요.
다음 사항을 확인하세요:
1. 온리원문자 앱이 실행 중인지 확인
2. 스마트폰 인터넷 연결 상태 확인 (WiFi보다 LTE/5G 권장)
3. 발신번호가 정상 등록되어 있는지 확인
4. 일별 발송 한도를 초과하지 않았는지 확인
하루 발송 가능 건수가 얼마인가요?
폰 1대당 기본 설정에 따라 다르며, 마이페이지 → 폰 관리에서 폰별 최대 발송 건수를 확인합니다. 무료 제공 건수는 회원가입일 기준으로 산정됩니다.
수신거부 처리는 어떻게 하나요?
수신거부 관리 페이지를 참고하세요. 수신거부 요청 번호는 자동으로 발송 대상에서 제외됩니다.

💬 웹문자·RCS

웹문자 잔액이 부족해요.
마이페이지 → 포인트·결제에서 포인트를 충전하세요.
RCS 발송이 안 돼요.
RCS 발송은 사전에 RCS 발신번호를 등록해야 합니다. '-- RCS 발신번호 없음 --'이 표시되면 통신사에 RCS 채널을 신청하세요.

🔀 원퍼널문자

이벤트 신청 고객에게 메시지가 발송되지 않아요.
AI 퍼널 설계가 올바르게 등록되어 있는지, 발송 채널 잔액이 충분한지 확인하세요. → AI 퍼널 설계 안내
인포랜딩 페이지 링크가 작동하지 않아요.
랜딩 페이지 상태가 '노출' 상태인지 확인하세요. → 인포랜딩페이지 안내

💳 결제·포인트

정기결제를 해지하고 싶어요.
포인트·결제 페이지를 참고하여 마이페이지 → 포인트·결제에서 [정기결제해지] 버튼을 클릭하세요.
세금계산서 발급이 가능한가요?
사업체 정보를 먼저 등록한 후 1:1 문의로 세금계산서 발급을 요청하세요.
