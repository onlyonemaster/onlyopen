PWA란?

PWA(Progressive Web App)는 웹사이트를 스마트폰·PC 앱처럼 설치하는 기술입니다. 별도의 앱 스토어 없이 브라우저에서 바로 설치하고, 홈 화면에 아이콘이 추가됩니다.

⚡
빠른 실행
앱처럼 즉시 실행, 로딩 속도 향상
🔔
푸시 알림
새 메시지·방문자 실시간 알림 수신
📴
오프라인 지원
인터넷 없이도 일부 기능 사용 가능
🆓
무료 설치
앱 스토어 불필요, 저장 공간 최소 사용

Android에서 설치

Chrome 브라우저 (권장)

  1. 1
    Chrome으로 https://kiam.kr 접속 후 로그인
  2. 2
    주소창 아래 "홈 화면에 추가" 배너가 나타나면 탭
  3. 3
    배너가 없으면: 우측 상단 ⋮ 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
  4. 4
    [설치] 확인 → 홈 화면에 kiam.kr 아이콘 생성
원챗 고객(방문자)도 동일한 방법으로 설치 가능합니다. 수신탭 → PWA 설치 유도 버튼을 활용하세요.

iPhone(iOS)에서 설치

⚠️ Safari 브라우저 필수: iOS에서는 Safari에서만 PWA 설치가 가능합니다.
  1. 1
    Safari로 https://kiam.kr 접속
  2. 2
    하단 공유 버튼(□↑) 탭
  3. 3
    스크롤 → "홈 화면에 추가" 선택
  4. 4
    앱 이름 확인 → [추가] 탭
  5. 5
    홈 화면에 kiam.kr 아이콘 생성 완료

PC에서 설치

  1. 1
    Chrome 또는 Edge 브라우저로 https://kiam.kr 접속
  2. 2
    주소창 우측 설치 아이콘(⊕) 클릭
  3. 3
    [설치] 클릭 → 바탕화면/시작 메뉴에 앱 추가

알림 설정

PWA 설치 후 푸시 알림을 허용하면 다음 이벤트 발생 시 알림을 받습니다:

알림 유형발생 조건
새 방문자챗봇에 새 방문자가 입장했을 때
직접 대화 요청고객이 사람 상담원을 요청했을 때
DM 메시지원챗 DM에 새 메시지가 왔을 때
발송 완료AI 메시지·문자 발송이 완료됐을 때

알림 허용: 브라우저 팝업에서 [허용] 클릭 또는 브라우저 설정 → kiam.kr → 알림 허용

앱 삭제

  • Android: 홈 화면 아이콘 길게 누르기 → [삭제] 또는 [앱 정보 → 삭제]
  • iOS: 홈 화면 아이콘 길게 누르기 → [앱 제거] → [홈 화면에서 제거]
  • PC: 시작 메뉴 또는 바탕화면 아이콘 우클릭 → [제거]
앱을 삭제해도 kiam.kr 계정과 데이터는 유지됩니다.
