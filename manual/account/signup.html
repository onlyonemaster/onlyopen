회원가입 & 로그인

kiam.kr의 모든 서비스를 이용하려면 먼저 회원가입이 필요합니다. 가입 방법과 로그인 절차를 단계별로 안내합니다.

회원가입

  • 1
    kiam.kr에 접속합니다
    웹 브라우저 주소창에 아래 주소를 입력하세요. PC · 스마트폰 모두 지원합니다.
    https://kiam.kr
  • 2
    우측 상단 [회원가입] 버튼을 클릭합니다
    또는 아래 주소로 직접 이동할 수 있습니다.
    https://kiam.kr/join.php
  • 3
    필수 정보를 입력합니다
    아래 항목을 모두 입력해야 가입이 완료됩니다.
    항목설명필수 여부
    아이디영문·숫자 조합, 4~20자. 가입 후 변경 불가필수
    비밀번호영문+숫자+특수문자 포함 8자 이상 권장필수
    이름실명 또는 닉네임필수
    이메일비밀번호 찾기에 사용됩니다필수
    휴대폰 번호SMS 서비스 이용 시 필요선택
    사업체명·업종AI 메시지 자동 생성 시 활용선택
  • 4
    이용약관 동의 후 [가입하기]를 클릭합니다
    서비스 이용약관과 개인정보 처리방침에 동의해야 가입이 완료됩니다. 가입 즉시 로그인 상태가 됩니다.
💡 구글 계정으로 빠른 가입
회원가입 화면에서 [Google로 시작하기] 버튼을 클릭하면 구글 계정으로 간편 가입·로그인이 가능합니다. 별도의 아이디·비밀번호 없이 사용할 수 있습니다.

로그인

  • 1
    kiam.kr 상단 [로그인]을 클릭합니다
    또는 아래 주소로 직접 이동할 수 있습니다.
    https://kiam.kr/id_pw.php
  • 2
    아이디와 비밀번호를 입력합니다
    자동 로그인 체크박스를 선택하면 다음 방문 시 자동으로 로그인됩니다. 공용 PC에서는 사용을 권장하지 않습니다.
  • 3
    로그인 완료 — kiam.kr 메인 화면으로 이동합니다
    상단 우측에 내 아이디가 표시되면 정상 로그인된 상태입니다.

아이디 · 비밀번호 찾기

🔑
아이디 찾기
가입 시 등록한 이메일 주소를 입력하면 해당 이메일로 아이디를 알려줍니다.
🔒
비밀번호 찾기
아이디와 이메일을 입력하면 임시 비밀번호를 이메일로 발송합니다. 로그인 후 즉시 변경하세요.
📌 이메일을 등록하지 않은 경우
아이디·비밀번호 찾기가 불가능합니다. 카카오 상담 채널(우측 하단 버튼)로 문의해 주세요.

구글 계정 연동 로그인

Google OAuth를 지원하며, 아래 주소로 직접 구글 로그인을 시작할 수 있습니다.

https://kiam.kr/api/google_oauth_start.php?purpose=login
💡 최초 구글 로그인 시 kiam.kr 계정이 자동 생성됩니다. 이후에는 구글 계정으로 클릭 한 번에 로그인됩니다.

로그아웃

상단 우측 내 아이디를 클릭 → 드롭다운에서 [로그아웃]을 선택합니다. 원챗(OneChat)에서는 아바타 이미지 클릭 → [로그아웃]을 사용합니다.

⚠️ 공용 PC 사용 시
반드시 로그아웃 후 브라우저를 종료하세요. 자동 로그인을 설정한 경우에도 로그아웃하면 세션이 초기화됩니다.
